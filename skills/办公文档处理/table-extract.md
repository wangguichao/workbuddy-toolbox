# 批量提取表格汇总

扫描指定文件夹里所有 Word 和 PDF 文档，自动识别并提取每个文件内的全部表格，按来源归类后汇总成一份带来源信息的 Excel 总台账。

## 适用场景

- 手头有几十上百份报表（Word / PDF），需要把里面的表格集中到一份 Excel 里统一统计
- 多个部门/供应商发来的表格格式各不相同，想合并成同一份台账方便对比核对
- 定期接收新增报表，需要增量提取并更新总台账，免去逐个复制粘贴

## 向 Workbuddy 发送的指令

"把 D:\报表\ 下所有 Word 和 PDF 里的表格提取出来，汇总到一个 Excel 总台账，每个源文件一个 Sheet，并保留来源文件名和页码信息，保存到 D:\报表台账\。"

## 处理要点

- 同时扫描文件夹里的 Word(.docx) 和 PDF 文件，自动识别文档内所有表格区域；扫描版 PDF 先做文字识别再定位表格。
- 表格结构识别与字段对齐：以首行或最完整的表头行为准对齐各列；合并单元格、跨页表格按逻辑拆解重排，保证提取后的数据与原表一致。
- 每个表格按来源文件归类，并附加「来源文件、所在路径、页码」列，方便回溯核对。
- 汇总规则与用户确认：表头相同的表格自动合并到同一张 Sheet，表头不同的异构表格单独分 Sheet 存放；提取前先说明去重、空行与数字格式的处理口径。
- 自动完成去重、删除空行、数字格式化（金额列统一保留两位小数），并设置冻结首行、列宽自适应。
- 异常处理：识别出乱码、表格错位或空表的文件单独列出，不强行写入台账，标记为待人工核对。

## 输出要求

- 输出一份 Excel 总台账，默认保存到指定输出目录（如 D:\报表台账\），文件名按内容命名（如 报表台账-2026年08月.xlsx）。
- Sheet 组织：表头相同的表格合并进同一张 Sheet；表头不同或无法对齐的表格按文件单独成 Sheet，全部表格可另建一张「全量明细」总表。
- 字段规则：每个 Sheet 至少保留原表头，并附加「来源文件、页码」两列用于追溯；金额、数量等数值列统一格式化，合计行自动求和。
- 生成处理报告：成功提取的文件数、每个 Sheet 的来源文件清单，以及提取失败的表格和原因。

## 注意事项

- 不同文档表格格式差异较大（有无表头、合并单元格、横版竖版、扫描件），提取结果按"尽量保真"处理，抽查核对以原表为准。
- 数据校验：核对金额、日期、编号等关键字段与源文件是否一致；金额合计与源表合计对不上时，让 Workbuddy 重新提取该文件。
- 扫描版 PDF 表格可能存在识别偏差，涉及金额、编号等关键数据的表格务必人工复核。
- 汇总规则（按表头合并、只提跨页表、是否去重）可直接向 Workbuddy 说明，先指定规则再跑，避免反复返工。
- 需要长期更新时告诉 Workbuddy 定期扫描文件夹并增量追加到总台账，不覆盖已确认的数据。
