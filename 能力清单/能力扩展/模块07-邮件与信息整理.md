### 8. 将浏览器200个收藏夹的网页去重、按主题分类

**细分能力点（5 条）**

1. 支持 Chrome/Edge 书签管理器一键导出 HTML 文件，兼容旧版 Netscape 书签格式。
2. 用 BeautifulSoup 解析 HTML，提取每条书签的标题、URL 和所在文件夹层级。
3. 按 URL 规范化去重：去掉 ?utm_source 等追踪参数、统一协议与域名大小写、折叠 http/https 与 www。
4. 基于标题分词和域名关键词自动打主题标签（编程、新闻、购物、工作、娱乐等）。
5. 生成分类后的目录结构并导出新 HTML，可重新导入浏览器，同时输出 CSV 清单便于核对。

**可执行提示词（5 条）**

1. "读取 D:\浏览器备份\bookmarks.html，把这 200 条收藏去重、按主题自动分类，输出整理后的清单给我。"
2. "把这批书签按编程、新闻、购物、工作、娱乐、学习六个主题分类，统计每个主题的条数。"
3. "去重时忽略 URL 里的追踪参数（如 utm_source、from），同一个网页保留最早收藏的那条。"
4. "分类后生成新的 bookmarks.html 方便重新导入浏览器，同时导出一份 CSV 汇总表给我核对。"
5. "每周日晚自动整理本周新增收藏，去重分类后更新书签文件并总结变化。"

**操作步骤（6 步）**

1. 向 Workbuddy 发送指令：「读取 D:\浏览器备份\bookmarks.html，把 200 条收藏去重、按主题分类，输出整理后的清单。」
2. Workbuddy 确认细节：去重规则（是否忽略 utm_source 等追踪参数）、按常用主题还是自动识别分类、清单输出格式与保存路径。
3. 你补充信息，如「按编程、新闻、购物、工作、娱乐、学习六个主题分类，保留最早收藏的 1 条，清单保存到 D:\浏览器整理\」。
4. 确认后，Workbuddy 自动完成书签解析、去重、打标签、生成新书签文件和 CSV 汇总表，你无需手动安装任何工具或写代码。
5. 你打开 CSV 检查分类是否正确，把分错的条目直接指出（如「把购物类下的『Java 教程』移到编程类」），Workbuddy 立即修正。
6. 后续管理：告诉 Workbuddy「每周日 21:00 自动整理本周新增书签，去重分类后更新书签文件」，之后每周自动执行。

### 10. 管理qq邮箱邮件，按发件人、主题关键词分类归档，垃圾邮件批量标记

**细分能力点（5 条）**

1. 在 QQ 邮箱设置中开启 IMAP/SMTP 服务，用 16 位授权码登录（非邮箱登录密码）。
2. 自动批量读取收件箱邮件信息（发件人、主题、日期），支持按日期范围增量获取。
3. 按发件人域名/地址和主题关键词建立规则表，自动打标签并归档到不同文件夹。
4. 识别标题/正文含"中奖、发票代开、兼职刷单"等特征的垃圾邮件，批量标记或删除。
5. 自动生成邮件分类统计报告（发件人 Top20、各分类数量），核对后再执行移动。

**可执行提示词（5 条）**

1. "登录我的 QQ 邮箱，把收件箱最近 3 个月的邮件（发件人、主题、日期）拉下来整理成清单。"
2. "把 QQ 邮箱里来自群发、订阅号、同事、客户的邮件按发件人自动分类归档到不同文件夹。"
3. "标题或正文含『中奖、发票代开、兼职刷单、退订』的邮件先标记为垃圾邮件，列清单给我确认后再删。"
4. "按主题关键词（报价、合同、发票、周报）把匹配邮件自动移入对应文件夹，每周一早上执行一次。"
5. "整理完成后生成邮件分类统计表：发件人前 20、每天收发量、各分类数量，导出 Excel 发我。"

**操作步骤（7 步）**

1. 告诉 Workbuddy：「管理我的 QQ 邮箱，把收件箱最近 3 个月的邮件分类归档，垃圾邮件批量清理。」
2. Workbuddy 引导你完成邮箱授权：告诉你如何开启 IMAP/SMTP 服务并获取 16 位授权码，你按提示把授权码告诉它，由 Workbuddy 完成登录连接。
3. Workbuddy 询问归档规则：按发件人还是主题关键词分类、垃圾邮件的判定词、是否先确认再删除。
4. 你补充：「按发件人和主题关键词分类；含中奖、兼职刷单的先标为垃圾邮件，给我清单确认后再删。」
5. Workbuddy 自动完成邮件拉取、分类、标记，并生成分类统计表和待删垃圾邮件清单，全程无需你安装环境或写脚本。
6. 你核对清单与统计表，确认后让 Workbuddy「按清单删除垃圾邮件」，它立即执行。
7. 后续管理：告诉 Workbuddy「每周一 9:00 自动整理本周新邮件并发我分类报告」，或「暂停自动归档」随时控制开关。

### 11. 管理百度网盘文件，按文件名分类整理

**细分能力点（5 条）**

1. 通过百度网盘开放平台 API（或第三方 CLI 工具）获取指定目录下的完整文件列表。
2. 按扩展名建立类型映射（pdf/doc→文档、jpg/png→图片、mp4→视频、zip/rar→压缩包、py/js→代码）。
3. 结合文件名关键词（合同、报表、照片、课程）二次补充分类规则，提高归类准确率。
4. 支持批量重命名统一规范（日期_项目_类型），并自动创建分类文件夹移动文件。
5. 计算文件 md5 识别重复文件，生成"重复清单"待人工确认，并输出整理前后路径对比报告。

**可执行提示词（5 条）**

1. "扫描我百度网盘根目录下所有文件，按文档、图片、视频、压缩包分类，统计每类数量。"
2. "按文件名关键词（合同、报表、照片、课程、简历）把网盘文件自动分类到对应文件夹，先给方案再执行。"
3. "把网盘文件名统一改成『日期_项目名_类型』格式，批量重命名，重名的加 _1、_2 后缀。"
4. "找出网盘里内容重复的文件，列出重复清单（含大小、时间）等我确认后再处理。"
5. "整理完成后生成分类汇总报告（每个文件夹的文件数和总大小），导出 Excel 发我。"

**操作步骤（7 步）**

1. 向 Workbuddy 发送指令：「帮我整理百度网盘，按文件名把文件分类归档。」
2. Workbuddy 引导你完成网盘授权：你登录后按提示完成授权确认，Workbuddy 通过授权接口自动读取你的网盘文件列表。
3. Workbuddy 给出初步分类方案：按扩展名（文档/图片/视频/压缩包）加文件名关键词（合同、报表、课程等），询问你确认。
4. 你确认或调整：「合同、报表、照片、课程分别建文件夹，执行前先给我完整清单和方案。」
5. 确认后，Workbuddy 自动创建分类文件夹并把文件移动到位，重名的统一规范命名，整个过程无需你手动操作。
6. 你检查整理报告，指出需要调整的地方，Workbuddy 立即修正；重复文件另列清单等你确认处理。
7. 后续管理：告诉 Workbuddy「以后上传的新文件也按这套规则自动分类」，让它持续帮你整理。

### 31. 自动同步多平台待办清单（飞书、钉钉、备忘录），汇总统一视图

**细分能力点（5 条）**

1. 通过飞书开放平台自建应用 API 拉取"我的待办"任务（标题、截止时间、状态、优先级）。
2. 通过钉钉开放平台 API 拉取任务/待办接口，处理 access_token 的获取与刷新。
3. 解析 Windows 备忘录/日历（或 Wunderlist、微软 To Do 的导出数据）作为第三数据源。
4. 按"标题相似度 + 截止日期"做跨平台去重合并，同一条只保留一条并标注来源平台。
5. 生成统一视图（Excel 或 HTML），用任务计划程序定时同步并推送汇总结果。

**可执行提示词（5 条）**

1. "把飞书『我的待办』、钉钉待办和微软备忘录里的任务合并成一张总清单。"
2. "合并时标题相似且截止日期相同的判定为同一条，只保留一条并标注来源平台。"
3. "把合并后的清单按截止时间排序，今天到期和已逾期的排最前并标红。"
4. "生成 Excel 汇总表，列包含来源平台、标题、截止时间、状态、优先级、是否重复，发我。"
5. "每天早 8 点自动同步一次飞书、钉钉、备忘录的待办，把汇总清单发到我邮箱。"

**操作步骤（7 步）**

1. 向 Workbuddy 发送指令：「把飞书、钉钉、备忘录的待办同步成一张总清单。」
2. Workbuddy 引导你完成各平台授权：飞书、钉钉需要你在对应平台确认授权，Workbuddy 负责后续自动拉取数据。
3. Workbuddy 询问合并规则：是否按标题相似度去重、排序方式、汇总表格式与推送方式。
4. 你补充：「标题相似且截止日期相同算同一条；按截止时间排序，逾期标红；汇总表发我邮箱。」
5. 确认后，Workbuddy 自动完成三个平台的待办拉取、去重合并、排序标色，生成 Excel 汇总表发给你。
6. 你检查汇总表并反馈问题（如「这条重复了」「这个来源平台标错了」），Workbuddy 调整规则后重新生成。
7. 后续管理：告诉 Workbuddy「每天 8 点自动同步并发我汇总」，之后每天自动执行，无需再管。

### 38. 自动整理聊天记录，提取客户需求、订单信息归档存档

**细分能力点（5 条）**

1. 用 WeChatMsg 等工具把微信电脑版聊天记录导出为文本或 SQLite 数据库。
2. 按会话/联系人分组，识别客户身份并建立客户档案字段（昵称、备注、联系方式）。
3. 用正则和关键词词典提取订单号、金额、商品名、交货日期等结构化信息。
4. 识别客户"需求句"（含"需要、希望、麻烦、尽快"等意图词），按客户汇总成需求清单。
5. 生成订单台账与客户跟进报告，按月份归档并建立可检索的索引表。

**可执行提示词（5 条）**

1. "把微信电脑版导出的聊天记录读进来，按联系人分组统计每人消息数和最近聊天时间，生成统计表。"
2. "从聊天记录里提取订单信息：订单号、金额、商品名、交货日期、下单人，整理成订单台账。"
3. "识别聊天中客户明确表达需求的句子（含需要、希望、尽快等），按客户汇总成需求清单，注明原文和日期。"
4. "提取聊天记录里出现的手机号、微信号、邮箱、地址等联系方式，去重后建立客户通讯录。"
5. "每周日晚自动整理本周新增聊天，更新订单台账和客户跟进报告，发我邮箱。"

**操作步骤（6 步）**

1. 向 Workbuddy 发送指令：「整理我的微信聊天记录，提取客户需求和订单信息归档。」
2. 你提供聊天记录文件（用微信自带导出功能导出后，把文件路径告诉 Workbuddy），Workbuddy 确认数据范围和格式。
3. Workbuddy 询问提取内容：订单信息字段、需求句判定词、联系方式、归档方式。
4. 你补充：「按联系人建立客户档案，订单和需求单独成台账，联系方式去重建通讯录。」
5. 确认后，Workbuddy 自动完成记录解析、信息提取、去重汇总，生成订单台账、客户需求清单和客户通讯录，无需你安装环境或写脚本。
6. 你核对成果，指出漏提或错提的条目，Workbuddy 修正；最后告诉它「每周日晚自动整理本周新增，更新台账发我邮箱」，实现持续管理。

### 43. 监控邮箱新消息，关键词匹配自动回复预设模板邮件

**细分能力点（5 条）**

1. 自动监控收件箱新邮件，记录已处理状态避免重复回复。
2. 对主题和正文做关键词匹配，命中预设规则（报价、发票、物流、招聘等）。
3. 从模板库中选择对应回复内容，按发件人、邮件主题做变量替换（如称呼、询价单号）。
4. 按模板自动发送回复邮件，并记录发送日志。
5. 设置白名单（重要客户必回）与黑名单（广告免回）、一键暂停开关，避免误发。

**可执行提示词（5 条）**

1. "监控我的 QQ 邮箱收件箱，有新邮件先整理成摘要通知我，告诉我每封邮件的主题和发件人。"
2. "邮件主题含『报价』的，自动回复模板『报价单已收到，我们将在 1 个工作日内回复』，回复中带上对方姓名。"
3. "发件人在白名单且正文含『发票』的，自动回复发票模板并抄送财务邮箱。"
4. "命中垃圾关键词（中奖、兼职、推广）的邮件不自动回复，只记录日志；白名单重要客户保证必回。"
5. "工作日 9:00-18:00 自动处理新邮件并按规则回复，其余时间只记录不回复，处理日志定期发我。"

**操作步骤（7 步）**

1. 告诉 Workbuddy：「监控我的 QQ 邮箱，有新邮件按模板自动回复。」
2. Workbuddy 引导你完成邮箱授权（开启 IMAP/SMTP 服务并获取 16 位授权码），你按提示提供授权码，由 Workbuddy 完成登录连接。
3. Workbuddy 询问自动回复规则：触发关键词、对应模板、白名单/黑名单、处理时间段。
4. 你补充规则：「主题含报价回报价模板；发票类抄送财务；垃圾关键词只记录不回复；白名单客户必回。」
5. Workbuddy 先以"只记录不真发"的试运行模式跑一轮，把命中情况给你确认，避免误发。
6. 你确认试运行结果无误后，Workbuddy 开启真实自动回复，并把每次触发的日志记录下来。
7. 后续管理：告诉 Workbuddy「工作日 9 点到 18 点自动处理，其他时间只记录」「把处理日志每周发我」或「暂停自动回复」，随时调整。
