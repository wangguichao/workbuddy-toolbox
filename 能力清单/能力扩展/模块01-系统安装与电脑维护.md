### 1. 下载 Steam，它可以自动帮你找到官网、下载、安装

**细分能力点（5 条）**

1. 识别并校验 Steam 官方网址（store.steampowered.com），避免误入假冒下载站。
2. 自动选择与系统匹配的 Windows 64 位官方安装包 SteamSetup.exe 下载。
3. 下载完成后校验安装包数字签名，确认为 Valve Corp. 官方签名。
4. 可带参数静默安装，自定义安装路径（如 D:\Steam），控制是否创建桌面快捷方式。
5. 安装完成后自动验证版本、调整下载区（中国上海）、关闭开机自启。

**可执行提示词（5 条）**

1. "帮我下载 Steam 官方 Windows 版安装包，保存到 D:\Downloads\Steam，完成后告诉我文件位置、大小，并校验是官网正版。"
2. "帮我确认 Steam 官方网址（区分 store.steampowered.com 与仿冒站），再下载适合我系统的安装包。"
3. "安装 Steam 到 D:\Steam，不创建桌面快捷方式，不勾选开机自启，装完自动验证能否正常打开。"
4. "Steam 装好后帮我在设置里把下载区改成中国（上海），关闭『启动时自动登录』和开机自启，并确认商店能打开。"
5. "校验我下载的 SteamSetup.exe 是否为 Valve 官方正版，防止下载到捆绑病毒的假安装包。"

**操作步骤（6 步）**

1. 向 Workbuddy 发送：「我要装 Steam，帮我在官网下载安装包并安装好。」Workbuddy 先确认你的系统是 64 位 Windows，并核对官方网址，避免下到仿冒站。
2. Workbuddy 自动从官网 store.steampowered.com 下载官方安装包到 D:\Downloads\Steam，下载完成后报给你文件位置和大小，并校验数字签名确认为 Valve 官方出品。
3. Workbuddy 询问安装偏好：安装路径、是否创建桌面快捷方式、是否开机自启。你回复「装到 D:\Steam，不要快捷方式，关掉自启」。
4. Workbuddy 自动完成静默安装并验证安装结果，无需你手动双击安装包、点下一步。
5. 你打开 Steam 检查能正常登录商店；想调整就直接说：「把下载区改成中国上海，关闭启动时自动登录」，Workbuddy 在设置里帮你改好。
6. 后续管理继续在对话里说，例如「取消 Steam 开机自启」「重新生成桌面快捷方式」，Workbuddy 直接调整。

### 2. 下载 idea，vscode，pycharm等等IDE，配置 sql server，jdk，python，maven等各种环境

**细分能力点（5 条）**

1. 从官方源（JetBrains 官网、code.visualstudio.com、python.org、Oracle/Temurin 官网）下载并安装各 IDE 与运行时。
2. 配置 JDK：设置 JAVA_HOME 环境变量并加入 Path，用 java -version 验证。
3. 配置 Python：安装时勾选 Add to PATH，设置 pip 国内镜像源。
4. 配置 Maven：解压、设置 MAVEN_HOME，修改 settings.xml 的本地仓库路径和阿里云镜像。
5. 安装 SQL Server Express 并配置 sa 密码、开启 TCP/IP 端口 1433，用 SSMS 连接测试。

**可执行提示词（5 条）**

1. "帮我下载安装 IntelliJ IDEA Community 版到 D:\JetBrains\IDEA，装好后告诉我怎么新建第一个 Java 项目。"
2. "帮我装好 VS Code，配上中文界面、Python 与 Java 插件、远程开发功能和自动保存，字体调到适合我的显示。"
3. "帮我配置 Java 开发环境（JDK 17）到 D:\Java\jdk-17，自动设置好环境变量，装完验证 java -version 能正常输出。"
4. "帮我配置 Python 开发环境到 D:\Python311，配好国内加速源，并安装好我平时处理表格、访问网络会用到的常用库。"
5. "帮我安装 SQL Server Express 2022 到 D:\MSSQL，设置好数据库密码、开启 1433 端口，装好管理工具并测试能连上。"

**操作步骤（9 步）**

1. 向 Workbuddy 发指令：「帮我把新电脑的开发环境配好：IDEA、VS Code、JDK、Python、Maven、SQL Server 都装上。」Workbuddy 先确认你的开发方向（Java 后端 / Python 数据分析等）和系统是 64 位 Windows。
2. Workbuddy 列出安装清单与版本建议，询问安装路径偏好，你统一回复「都装到 D:\Dev 对应的子目录」。
3. Workbuddy 从各软件官方源下载安装包并校验签名，逐个静默安装：IDEA Community、VS Code、Temurin JDK 17、Python 3.11、SQL Server Express 2022。
4. Workbuddy 自动配置环境变量（JAVA_HOME、MAVEN_HOME、Path 中的 Java/Python 等），无需你手动打开系统属性；配置完运行 java -version、python --version、mvn -version 自检并汇报结果。
5. 需要你决策的部分 Workbuddy 会单独询问，例如 SQL Server 的数据库密码——你设置一个强密码告诉它，它负责写入配置并开启 TCP/IP 1433 端口。
6. Workbuddy 装好 VS Code 常用扩展、设置中文界面与自动保存；Maven 配好本地仓库路径和国内镜像源，加快依赖下载。
7. 装完后 Workbuddy 帮你打开 IDEA 新建一个测试工程、运行一段示例代码，验证整套环境跑通。
8. 你打开 IDEA / VS Code 实际敲两行代码确认无误；有问题直接说「IDEA 新建工程报错」，Workbuddy 定位并修复。
9. 后续管理继续对话：如「把 Python 升到 3.12」「给 VS Code 换个主题」，Workbuddy 直接调整，无需手动操作。

### 6. 扫描系统文件，管理开机自启软件，协助清理电脑

**细分能力点（5 条）**

1. 扫描并统计磁盘占用，定位大文件、临时文件、缓存与更新残留。
2. 管理开机启动项：查看任务管理器"启动应用"、注册表 Run 键和启动文件夹中的自启软件。
3. 一键清理系统临时目录（temp、%temp%、prefetch）和 Windows 更新缓存（SoftwareDistribution）。
4. 使用系统磁盘清理（cleanmgr）与存储感知释放空间，识别可压缩、可移动的文件。
5. 生成清理报告：列出被清理的项目、释放的空间，以及建议手动确认的疑似可删项。

**可执行提示词（5 条）**

1. "扫描 C 盘占用最大的前 20 个文件/文件夹，按大小排序，列出路径和占用空间，标出哪些是临时文件。"
2. "列出我电脑全部开机自启项目（含注册表启动项和启动文件夹），标出可疑项，给出该禁用的建议。"
3. "帮我清理系统临时文件、Windows 更新缓存和缩略图缓存，先估算能释放多少空间，再执行清理。"
4. "清理 D:\Temp 下 7 天前创建的临时文件，删除前把清单保存到 D:\清理记录.txt。"
5. "用 Windows 磁盘清理功能清一遍『更新清理』和『以前的 Windows 安装』，然后告诉我释放了多少空间。"

**操作步骤（8 步）**

1. 向 Workbuddy 发指令：「帮我清理电脑，扫描 C 盘占用并清理没用的临时文件。」Workbuddy 先扫描磁盘占用，把大文件、临时文件和缓存分布汇总给你看。
2. Workbuddy 估算可释放空间后询问你确认：「以下缓存共可释放约 X GB，是否执行清理？」你确认后它自动清理系统临时目录与更新缓存。
3. 想清理得更细就补充：「帮我删掉 D:\Temp 里 7 天前创建的临时文件，先出清单」，Workbuddy 列清单给你核对后再删。
4. Workbuddy 列出全部开机自启项，标出可疑或建议禁用的项，问你哪些要禁；你勾选后它直接改好注册表和启动项，无需你手动进注册表编辑器。
5. Workbuddy 跑一遍 Windows 磁盘清理（含「Windows 更新清理」「以前的 Windows 安装」），完成后汇报释放空间。
6. 你抽查确认常用软件仍能正常打开、开机速度是否有改善；有异常就反馈，Workbuddy 会检查是否有误删项并处理。
7. Workbuddy 生成清理报告保存到 D:\清理报告，列出清了什么、释放多少、哪些是疑似可删项建议你人工确认。
8. 后续可设置定时：「每周日晚上自动清理一次临时文件并汇报」，Workbuddy 帮你挂上定时任务；想停就说「暂停每周清理」。

### 20. 协助排查网络问题，优化家庭网络速率

**细分能力点（5 条）**

1. 用 ipconfig / ping / nslookup 定位是局域网、外网还是 DNS 解析故障。
2. 重置网络栈：刷新 DNS、Winsock、TCP/IP 协议栈，修复常见连接问题。
3. 优化 DNS 配置：切换到阿里 223.5.5.5 / 腾讯 119.29.29.29 / 谷歌 8.8.8.8。
4. 检查网卡驱动版本，更新到官网最新版；区分 2.4G / 5G 频段并选择干扰小的信道。
5. 用在线测速工具对比有线与无线速率，定位家庭网络瓶颈并给出优化建议。

**可执行提示词（5 条）**

1. "帮我排查网络连不上的原因：依次测网关、外网和 DNS，把每步结果贴出来，告诉我故障出在哪一段。"
2. "我的网总是一会儿断一次，帮我查网卡驱动版本，给出对应官方驱动下载地址。"
3. "帮我把 DNS 改成阿里 223.5.5.5 和腾讯 119.29.29.29，刷新缓存，并告诉我每步做了什么。"
4. "帮我一键重置网络：刷新 DNS、重置 Winsock 和 TCP/IP 协议栈，完成后提示我是否需要重启电脑。"
5. "我家宽带 500M 但下载只有 30MB/s，帮我分析原因，并教我把路由器切到 5G 信道、开启 QoS。"

**操作步骤（8 步）**

1. 向 Workbuddy 发指令：「网连不上了，帮我排查。」Workbuddy 依次测试本机网络、网关连通性、外网和 DNS 解析，把每一步结果整理给你。
2. Workbuddy 根据结果判断故障段：若网关不通就提示检查网线和路由器，若是 DNS 问题则直接给出修复方案。
3. 你回复「那你帮我修」，Workbuddy 自动刷新 DNS、重置 Winsock 与 TCP/IP 协议栈，改完提示你是否需要重启电脑。
4. 如果 DNS 配置有问题，Workbuddy 直接帮你把首选/备用 DNS 改为 223.5.5.5 与 119.29.29.29，系统网络设置由它完成。
5. Workbuddy 检查网卡驱动版本是否过旧，给出官方下载地址；需要更新时它负责下载安装并重启网卡验证。
6. 想优化家庭网络就继续：「帮我把路由器无线切到 5G、选个干扰小的信道、开 QoS。」Workbuddy 给出登录路由器的具体步骤，你按提示在路由器后台确认（登录账号密码需你自己输入）。
7. Workbuddy 引导你用测速网站分别测有线与无线，对比结果定位瓶颈在网卡、路由器还是宽带线路。
8. 后续优化持续对话：如「再帮我测一次网速」「把下载限速改大」，Workbuddy 随时调整并解释。

### 46. 清理微信缓存、重复文件，筛选大体积无用文件一键删除

**细分能力点（5 条）**

1. 使用微信"设置 -> 存储空间"管理缓存、聊天文件和表情包占用。
2. 定位微信数据目录（Documents\WeChat Files）并统计各账号、各类型文件占用。
3. 按 MD5/SHA1 哈希扫描全盘重复文件，先预览后删除，避免误删照片和文档。
4. 按大小和最后访问时间筛选大体积无用文件（视频缓存、下载残留、旧压缩包）。
5. 生成清理报告并支持"一键删除"清单：先移入回收站，确认无影响后再彻底删除。

**可执行提示词（5 条）**

1. "打开微信存储空间管理，看看缓存和聊天文件各占多少，把能安全清理的缓存清掉，不删聊天记录。"
2. "扫描 D:\ 和 E:\ 找出所有大于 1GB 的文件，列出路径、大小和修改时间，标出像是视频缓存或安装包的。"
3. "找出 F:\ 下文件名相同但大小不同的重复文件，按组列出来，先给我确认再删。"
4. "分析 C:\Users\我的用户名\Documents\WeChat Files 的占用，把 1 年没打开过的群聊图片和视频缓存清理掉。"
5. "扫描全盘重复文件，用内容比对找出相同的文件，把重复的整理到 D:\重复文件待删 文件夹，并出个报告。"

**操作步骤（7 步）**

1. 向 Workbuddy 发指令：「帮我清理微信缓存，但别删聊天记录。」Workbuddy 打开微信存储空间管理，统计缓存与聊天文件占用给你看。
2. Workbuddy 询问清理范围（只清缓存 / 连旧聊天文件一起），你回复「只清缓存」，它自动清掉安全缓存并汇报释放空间。
3. 继续发：「扫描 D:\ 和 E:\ 找出大于 1GB 的文件」，Workbuddy 按大小列出文件并标出疑似视频缓存和安装包，等你确认。
4. 对于重复文件，Workbuddy 用内容比对扫描 F:\，按组列出重复项；你勾选要删的，它把冗余副本移入 D:\重复文件待删，而非直接删除。
5. 涉及微信历史文件的深度清理，Workbuddy 会先提醒你在微信设置里备份重要聊天记录，再清理 1 年未打开的群聊图片与视频缓存。
6. Workbuddy 生成清理报告：清理了哪些、释放多少空间、哪些是"疑似可删"建议你确认；你在对话里一句句确认即可。
7. 后续管理：观察几天没问题，就让 Workbuddy「把 D:\重复文件待删 彻底清空」；想定期就设「每周自动扫描一次重复文件并汇报」。

### 73. 清理浏览器缓存、Cookie，批量导出备份账号书签

**细分能力点（5 条）**

1. 分浏览器（Chrome/Edge/Firefox）清理缓存、Cookie 与站点数据，可只清缓存保留登录态。
2. 批量导出书签：Chrome/Edge 导出 HTML，Firefox 导出 JSON，统一备份。
3. 导出密码/登录信息：Edge 密码导出 CSV，Chrome 用扩展或"从 Google 导入"方式备份。
4. 定期备份到本地目录并压缩，可同步到网盘，支持重装系统后导入恢复。
5. 支持设置定期清理与备份提醒，减少 Cookie 泄露与缓存膨胀风险。

**可执行提示词（5 条）**

1. "帮我清理 Chrome 的缓存和 Cookie，保留已保存的密码和书签，只清最近 1 个月的数据。"
2. "把 Chrome 书签导出成 HTML，存到 D:\浏览器备份\Chrome书签_20260819.html。"
3. "把 Edge 的书签和密码一起备份：书签导出 HTML，密码导出 CSV，压缩后放到 D:\浏览器备份。"
4. "帮我清理电脑上所有浏览器（Chrome、Edge、Firefox）的缓存和临时文件，先估算释放空间再执行。"
5. "设置每周定时：周一提醒我清理浏览器缓存，并把最新书签备份到 D:\浏览器备份 和网盘。"

**操作步骤（7 步）**

1. 向 Workbuddy 发指令：「帮我清理所有浏览器的缓存和 Cookie，保留密码和书签。」Workbuddy 分浏览器统计各自缓存占用，先给你看能释放多少。
2. Workbuddy 询问清理范围（时间范围、是否连 Cookie 一起清），你补充「只清最近 1 个月、保留登录状态」，它逐浏览器执行清理。
3. 想备份书签就说：「把 Chrome、Edge 的书签和密码备份到 D:\浏览器备份。」Workbuddy 自动导出书签 HTML/JSON 和密码 CSV，并压缩成一个 zip。
4. 涉及密码导出时，Workbuddy 提醒你按浏览器提示完成身份验证（系统 PIN），之后自动生成 CSV 并妥善保存，不会传到别处。
5. 你打开 D:\浏览器备份 检查压缩包内容齐全；漏了就让 Workbuddy「把 Firefox 书签也加进去」。
6. 想定期做就说：「每周一提醒我清理缓存，并备份最新书签到 D:\浏览器备份 和网盘。」Workbuddy 挂上每周定时任务。
7. 后续不想被提醒就说「暂停这个每周提醒」，Workbuddy 直接关闭；重装系统需要恢复时，让它「按备份恢复书签」即可。

### 82. 自动检测电脑驱动缺失，一键下载安装适配驱动程序

**细分能力点（5 条）**

1. 通过设备管理器识别带黄色感叹号的异常设备，定位缺失/损坏驱动。
2. 通过硬件 ID（VEN_xxx&DEV_xxx）精确匹配对应驱动的官方下载源。
3. 使用 Windows 更新、厂商官网或驱动工具（驱动精灵/360 驱动大师）一键安装适配驱动。
4. 安装前备份现有驱动，支持重装系统后一键恢复驱动。
5. 检测 GPU、声卡、网卡驱动版本是否过旧，给出更新建议并验证安装后设备状态。

**可执行提示词（5 条）**

1. "检查设备管理器里所有带黄色感叹号的设备，逐个列出名称和硬件 ID，告诉我缺哪个驱动。"
2. "我的显卡是 NVIDIA RTX 3060，帮我找到官网最新驱动，说明装 Game Ready 还是 Studio 版。"
3. "帮我把全部已安装驱动备份到 D:\驱动备份，并说明重装系统后怎么恢复。"
4. "检测我网卡和声卡驱动是否过时，给出官方下载地址和安装说明。"
5. "帮我自动更新所有有问题的驱动，完成后验证是否还有黄色感叹号。"

**操作步骤（7 步）**

1. 向 Workbuddy 发指令：「帮我检查电脑有没有驱动没装好。」Workbuddy 扫描设备管理器，列出带黄色感叹号的设备、名称和硬件 ID，说明缺的是哪个驱动。
2. Workbuddy 对每个缺失驱动给出适配方案（系统更新自动搜索 / 厂商官网 / 驱动工具），并说明推荐哪种。
3. 你回复「那你直接帮我装」，Workbuddy 优先从官方源下载匹配驱动并安装，装完自动验证设备状态是否恢复正常。
4. 涉及驱动工具（如驱动精灵、360 驱动大师）时，Workbuddy 只在你同意、且能避开捆绑软件的前提下使用，并提示你哪些推广项不勾选。
5. 装驱动前 Workbuddy 先做备份：「我把现有驱动备份到 D:\驱动备份，防止新驱动不兼容」，并说明重装系统后如何恢复。
6. 安装完成 Workbuddy 提醒你重启电脑，重启后再检测一遍确认没有黄色感叹号，并验证显卡、声卡识别正常。
7. 后续维护继续对话：如「每季度帮我检查一次驱动更新」或「帮我更新显卡驱动」，Workbuddy 定期提醒或直接帮你更新。

### 88. 扫描磁盘冗余安装包、压缩包，筛选长期未使用文件清理

**细分能力点（5 条）**

1. 全盘扫描冗余安装包（.exe/.msi/.iso）和压缩包（.zip/.rar/.7z），按大小排序。
2. 结合"最后访问时间"筛选长期未使用的文件（如 180 天未打开）。
3. 识别已卸载软件的残留安装包，与已安装程序清单比对后标记清理。
4. 生成磁盘占用与可清理清单报告（可导出 Excel），供人工确认。
5. 清理前将文件移入回收站/待删目录，确认软件无影响后再彻底删除。

**可执行提示词（5 条）**

1. "扫描 C 盘和 D 盘所有 .exe、.msi、.iso、.zip、.rar、.7z 文件，按大小列出前 50 个，标出完整路径。"
2. "找出 C 盘和 D 盘超过 1 年没打开、且大于 500MB 的文件，列出路径、大小和最后访问时间，供我确认是否删除。"
3. "清理下载文件夹 C:\Users\我的用户名\Downloads 里超过 3 个月的安装包和压缩包，先出清单再删。"
4. "扫描全盘找出已卸载软件留下的安装包残留（比如已卸载 Steam 但还留着 SteamSetup.exe），列出待删清单。"
5. "扫描全盘统计大文件分布（按类型和文件夹归类），整理成报告给我看。"

**操作步骤（7 步）**

1. 向 Workbuddy 发指令：「帮我看看哪些安装包和压缩包占地方，清理掉没用的。」Workbuddy 扫描全盘 .exe/.msi/.iso/.zip/.rar/.7z 文件，按大小列出前若干名和路径。
2. Workbuddy 结合"最后访问时间"筛出长期未用的大文件，标注哪些疑似可以删除、哪些是已卸载软件残留。
3. 你确认删除范围（如"下载文件夹里超过 3 个月的安装包"），Workbuddy 先出待删清单，等你确认后再处理。
4. 删除前 Workbuddy 把文件先移入 D:\待删除 文件夹（相当于缓冲），不直接清空，避免误删。
5. Workbuddy 生成磁盘占用与可清理报告（可导出 Excel），列明清理项、占用大小、建议保留项。
6. 正常运行一段时间确认无误后，你告诉 Workbuddy「把 D:\待删除 彻底清空」，它再彻底删除。
7. 后续定期维护：「每月自动扫描一次冗余安装包并汇报」，Workbuddy 挂上定时任务，想暂停随时说。
