### 9. 将一百张图片的尺寸统一为800x800，文件重命名为sku编号

**细分能力点（5 条）**

1. 支持 JPG/PNG/WEBP 等常见格式图片批量读取与统一输出。
2. 支持两种统一方式：保持纵横比补白边填充至 800x800，或居中裁剪至 800x800。
3. 读取 Excel/CSV 中的 SKU 编号列表，按文件排序顺序逐一重命名。
4. 自动校验图片数量与 SKU 编号数量是否一致，不一致时停止并提示。
5. 输出处理报告（Excel），列出每张图片处理前后的文件名与尺寸，标记失败项。

**可执行提示词（5 条）**

1. "把 D:\产品图\原图 里的所有图片统一为 800x800，保持纵横比补白边，输出到 D:\产品图\成品。"
2. "批量处理 D:\产品图\原图 的全部图片，按 D:\产品图\sku清单.xlsx 第一列的 SKU 编号顺序重命名为『编号.jpg』。"
3. "处理前先核对图片数量与 SKU 编号数量是否一致，不一致就列出差异，等我说继续再处理。"
4. "重命名对应规则：图片按名称排序后与 SKU 清单逐行对应，统一输出 JPG、质量 90%。"
5. "全部完成后生成对照表 Excel，列出每张图的原始文件名、SKU编号、处理前后尺寸、是否成功；以后每周自动处理新增图片并更新对照表。"

**操作步骤（7 步）**

1. 打开 D:\产品图\原图 文件夹，把 100 张待处理图片放进去，同时准备好 SKU 编号清单（Excel 第一列）。
2. 向 Workbuddy 发送指令：「把 D:\产品图\原图 里的图片统一为 800x800，按 sku清单.xlsx 的编号顺序重命名，输出到 D:\产品图\成品。」
3. Workbuddy 会先确认处理方式：保持纵横比补白边还是居中裁剪？回复选择（如"补白边"）。
4. Workbuddy 自动校验图片数量与 SKU 编号数量是否一致，不一致时会列出差异，按提示补齐或确认继续。
5. 确认后 Workbuddy 自动完成缩放、命名、保存，全部技术实现由 Workbuddy 完成，你无需手动安装软件或写脚本。
6. 打开 D:\产品图\成品 抽查几张，确认尺寸与命名无误，有问题的直接告诉 Workbuddy 重新处理。
7. 若后续有新增图片，告诉 Workbuddy：「每周一自动处理原图文件夹里的新增图片，并更新对照表 Excel。」

### 26. 整理手机相册，按拍摄日期、人物、场景自动分文件夹归档

**细分能力点（5 条）**

1. 读取照片 EXIF 拍摄日期（DateTimeOriginal），无 EXIF 时用文件修改时间兜底。
2. 按"年-月"或"年-月-日"自动创建文件夹并移动归档。
3. 基于人脸识别（face_recognition/OpenCV）对同一人物的照片聚类归入同名文件夹。
4. 基于内容分类区分风景、美食、宠物、截图、文档等场景类别。
5. 自动识别截图与重复照片（哈希比对），移入待删除文件夹而非直接删除。

**可执行提示词（5 条）**

1. "把 D:\手机相册导出 里的照片按拍摄年份和月份归类，自动创建『年-月』文件夹并移动进去。"
2. "把同一人物出现的照片自动归入同一文件夹，人物先命名为『人物1、人物2』，最后生成名单给我确认。"
3. "自动区分截图和重复照片，移到 D:\待删除 文件夹，不要直接删除，并给我一份待删清单。"
4. "没有拍摄日期的照片按文件修改时间归档，并在文件名加『无EXIF』标记。"
5. "整理完成后生成归档说明表（原始路径→新路径→归类依据），并设置每月自动整理一次新增照片。"

**操作步骤（8 步）**

1. 把手机相册导出到 D:\手机相册导出，保持原有目录结构不破坏。
2. 向 Workbuddy 发送指令：「整理 D:\手机相册导出 里的照片，按拍摄日期归入『年-月』文件夹，人物和场景也分开。」
3. Workbuddy 会确认归档规则：按月份还是按天？人物需要识别到什么程度？按需回答（如"按月就行"）。
4. Workbuddy 自动读取每张照片的拍摄信息完成日期归档，并用人脸识别按人物聚类、按内容区分场景，无需你手动安装软件。
5. 人物名单生成后，Workbuddy 会把聚类结果发给你，回复把『人物1』改成具体姓名即可。
6. 截图与重复照片由 Workbuddy 识别后移入 D:\待删除 并给出清单，你确认后它才执行删除。
7. 打开归档目录抽查分类是否正确，有误的分类直接告诉 Workbuddy 调整。
8. 想长期维护就告诉 Workbuddy：「每月 1 号自动整理新增照片，并按同样规则归档。」

### 30. 批量去除图片水印、多余边框，统一白底背景

**细分能力点（5 条）**

1. 支持文字水印与 Logo 水印两种去除方式。
2. 支持按固定位置/区域批量去除（如右下角固定位置）。
3. 自动检测并裁剪图片四周多余黑边、白边。
4. 将裁剪后背景统一填充为纯白色（RGB 255,255,255）。
5. 去除效果不佳的图片自动单独标记，供人工复核或补裁。

**可执行提示词（5 条）**

1. "去掉 D:\图片目录 里所有图片右下角约 200x80 区域的文字水印，输出到成品文件夹。"
2. "自动裁剪每张图片四周多余黑边/白边，再统一把背景填充成纯白色。"
3. "处理前先用 3 张样图自动检测水印位置和大小，把预览发给我确认后再全量处理。"
4. "水印去除后仍模糊或有残留的图片单独放入 D:\待人工处理，并附处理前后对比图。"
5. "所有图片统一输出 JPG、尺寸不变、质量 95%；以后每周自动处理新增图片。"

**操作步骤（7 步）**

1. 把待处理图片放入 D:\图片目录。
2. 向 Workbuddy 发送指令：「批量去掉 D:\图片目录 里图片右下角的水印，裁剪多余边框，统一白底，输出 JPG 质量 95%。」
3. Workbuddy 会确认水印位置和大小，或先自动检测并把预览图发给你，你确认无误后继续。
4. Workbuddy 自动完成水印去除、边框裁剪、白底填充，技术实现全部由它完成，无需手动安装或写脚本。
5. 打开成品目录抽查处理效果，残留明显的图片直接指出来让 Workbuddy 重新处理。
6. 处理效果不佳的图片，Workbuddy 会单独挑出放到 D:\待人工处理 并附对比图，你只需浏览确认。
7. 想持续维护就告诉 Workbuddy：「每周五定时处理新增图片，按同样规则输出。」

### 37. 批量生成证件照，切换白底 / 蓝底 / 红底，调整标准尺寸

**细分能力点（5 条）**

1. 用 rembg 自动去除人像背景，得到透明底图。
2. 一键填充白底、蓝底、红底三种底色。
3. 支持标准证件照尺寸：1 寸（295×413）、2 寸（413×579）、护照等。
4. 自动居中定位人脸并调整头部留白比例。
5. 支持排版打印：把多张证件照排版到一张 6 寸相纸上。

**可执行提示词（5 条）**

1. "把 D:\证件照\原图 里每个人的照片自动抠出人像，生成 1 寸白底证件照 295×413，输出到成品文件夹。"
2. "同一张人像同时生成白底、蓝底、红底三个版本，文件名带底色后缀（如 张三_白底.jpg）。"
3. "把 8 张 1 寸证件照排版到一张 6 寸相纸（300dpi）上，方便打印后裁剪。"
4. "处理前先检测每张图是否有人脸，没有脸或脸不完整的放到问题文件夹。"
5. "批量处理 D:\员工照片，全部统一成 2 寸蓝底证件照 413×579，完成后生成尺寸与底色清单。"

**操作步骤（8 步）**

1. 把每个人的人像照片放入 D:\证件照\原图。
2. 向 Workbuddy 发送指令：「批量生成证件照，抠出人像，白底 1 寸 295×413，输出到成品文件夹。」
3. Workbuddy 会确认底色、尺寸和是否需要三种底色版本，按需补充（如"白蓝红三版都要"）。
4. Workbuddy 自动完成抠图、换底、缩放、人脸居中，全部技术实现自动完成。
5. 处理前 Workbuddy 会先检测人脸，没有脸或不完整的图片会单独挑出提醒你补充。
6. 如需打印，告诉 Workbuddy：「把 8 张 1 寸照排版到一张 6 寸相纸上」，它自动完成排版输出。
7. 打开成品检查边缘是否有残影，有问题的图让 Workbuddy 重新处理。
8. 若发现某批尺寸或底色有误，直接告诉 Workbuddy 按对应规则重跑。

### 42. 批量识别图片文字，导出可编辑 Word 文档，修正识别错别字

**细分能力点（5 条）**

1. 支持中英文混排图片文字识别，自动适配最佳识别方案。
2. 按"从上到下、从左到右"的阅读顺序还原排版，分段落写入 Word。
3. 自动修正常见错别字（同音字、形近字，如"已/己/巳"、"未/末"）。
4. 支持按置信度标记低可信度文字，方便人工复核。
5. 输出可编辑 docx 文档，并可附带原文截图对照。

**可执行提示词（5 条）**

1. "批量识别 D:\扫描件 里所有图片上的文字，按阅读顺序合并，导出为可编辑的 Word 文档。"
2. "每张图片识别的内容单独成一个段落，文档开头加目录索引，便于检索。"
3. "识别后自动修正常见错别字（如 巳/已、未/末），修正处用黄色高亮标出。"
4. "识别后把把握不高的文字标黄加下划线，单独列一张清单让我人工核对。"
5. "在每段识别文字下方插入对应原图截图对照；并设置每周自动识别新增扫描件并导出。"

**操作步骤（7 步）**

1. 把待识别的图片按页顺序命名放入 D:\扫描件。
2. 向 Workbuddy 发送指令：「识别 D:\扫描件 里图片上的文字，按阅读顺序导出成可编辑 Word 文档。」
3. Workbuddy 会确认输出格式：是否需要目录、段落如何分隔、字体样式，按需回复。
4. Workbuddy 自动完成文字识别、顺序还原、写入 Word，无需手动安装识别软件或写脚本。
5. 识别完成后 Workbuddy 自动修正常见错别字，并把把握不高的文字标黄加下划线。
6. 打开 Word 核对标黄处，把需要改的地方直接指出来让 Workbuddy 修正。
7. 想定时处理就告诉 Workbuddy：「每周一自动识别新增扫描件，追加到同一个 Word 并高亮新增部分。」

### 70. 批量给图片添加统一品牌水印，调整水印位置透明度

**细分能力点（5 条）**

1. 支持 PNG Logo 水印与文字水印两种类型。
2. 支持九宫格任意位置（左上/右上/居中/右下等）加边距控制。
3. 支持透明度调节（alpha 通道）与平铺水印效果。
4. 批量应用同一套水印参数，保证全批次风格统一。
5. 先输出预览图确认效果，再全量处理，原图自动备份。

**可执行提示词（5 条）**

1. "给 D:\产品图 里所有图片添加 D:\素材\品牌logo.png 水印，右下角、边距 20、透明度 60%。"
2. "用文字水印『XX科技 © 2026』，字体大小自适应图片宽度 8%，透明度 30%，右下角。"
3. "把文字水印做成平铺背景效果，间隔 200 像素，整体透明度 10%，不遮挡主要内容。"
4. "先只处理前 3 张生成预览，我确认大小位置满意后再批量处理剩余图片。"
5. "处理前先把原图备份到 D:\原图备份，处理后统一输出 JPG 质量 90%；以后新增图片自动加同款水印。"

**操作步骤（7 步）**

1. 准备好水印素材（透明底 Logo 或文字内容），把待加水印的图片放入 D:\产品图。
2. 向 Workbuddy 发送指令：「给 D:\产品图 里所有图片加 D:\素材\品牌logo.png 水印，右下角、透明度 60%。」
3. Workbuddy 会确认水印位置、大小、透明度参数，按需补充（如"边距 20 像素"）。
4. Workbuddy 先处理 3 张预览图发给你，确认水印位置是否遮挡主体，满意后再全量处理。
5. 确认后 Workbuddy 自动为全部图片加水印并统一输出 JPG 质量 90%，原图自动备份到 D:\原图备份。
6. 打开成品抽查效果，有问题的图片告诉 Workbuddy 单独重做。
7. 想保持风格统一就告诉 Workbuddy：「以后新增图片自动加同款水印并备份原图。」

### 79. 识别票据二维码，批量读取信息录入电子台账表格

**细分能力点（5 条）**

1. 用 pyzbar 识别票据上的二维码与条形码。
2. 自动解析二维码内容（纯文本、URL、JSON 等格式）。
3. 自动定位票据中的二维码区域，倾斜或过小时先校正放大再识别。
4. 识别结果批量写入 Excel 台账，按票据号自动去重。
5. 识别失败或模糊的票据单独标记原因，支持人工补录。

**可执行提示词（5 条）**

1. "批量扫描 D:\票据 里所有票据图片上的二维码，把内容逐条录入台账 Excel。"
2. "识别发票右下角二维码，解析出票据号、金额、开票日期、销售方，填入台账对应列。"
3. "识别前自动定位二维码区域，倾斜的校正、过小的放大，保证清晰可读。"
4. "识别失败的票据单独放一个 Sheet 并标注失败原因，方便人工补录。"
5. "写入台账时按票据号去重，同一票据号只保留第一条，重复的单独列出提醒；以后每天自动扫描新增票据并更新台账。"

**操作步骤（7 步）**

1. 把待录入的票据扫描/拍照图片放入 D:\票据。
2. 向 Workbuddy 发送指令：「批量扫描 D:\票据 里的二维码，把票据号、金额、开票日期、销售方录入台账 Excel。」
3. Workbuddy 会确认台账格式：列名、保存路径、是否按票据号去重，按需回复。
4. Workbuddy 自动完成二维码定位、校正、识别与字段解析，技术实现全部自动完成。
5. 识别失败的票据由 Workbuddy 单独放入一个 Sheet 并标注原因，你只需补充人工录入。
6. 打开台账抽查识别率，字段有误的地方直接指出让 Workbuddy 修正。
7. 想持续维护就告诉 Workbuddy：「每天 17:00 自动扫描新增票据，更新台账并发我新增清单。」
