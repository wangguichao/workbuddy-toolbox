### 16. 搭建一个本地的管理系统：如库存管理系统，家庭图书管理系统。

**细分能力点（5 条）**

1. 用 SQLite 数据库存储条目，本地零配置、数据不出本机。
2. 支持增删改查：录入、修改、删除、按关键词/分类检索。
3. 库存管理：记录商品名称、数量、单价、入库/出库时间、供应商、预警阈值。
4. 家庭图书管理：记录书名、作者、ISBN、分类、书架位置、借出状态。
5. 用 Streamlit 或 Flask 做可视化界面，配 Excel 导入导出和 CSV 备份。

**可执行提示词（5 条）**

1. "帮我用 Python + SQLite 搭建一个家庭图书管理系统，字段包含书名、作者、ISBN、分类、书架位置、借出状态，用 Streamlit 做界面，放在 D:\family-library 目录。"
2. "给这个库存管理系统加一个功能：当某商品数量低于设定的预警阈值时，在首页用红色高亮提醒我补货。"
3. "写一段脚本，把 D:\books.csv 里的图书数据导入 SQLite 数据库，遇到重复 ISBN 就更新不新增。"
4. "为库存系统增加『出库』操作，选择商品后输入数量，自动扣减库存并记录出库时间和用途。"
5. "给系统加一个按分类统计的图表，统计各分类图书数量和各商品库存金额占比。"

**操作步骤（7 步）**

1. 安装 Python 及依赖库：`pip install streamlit pandas openpyxl`（SQLite 为 Python 内置模块）。
2. 新建项目目录，用 SQLite 建表：books 表（图书）或 inventory 表（商品），字段按需求定义。
3. 编写数据库封装层，提供 add/update/delete/query 函数，供界面调用。
4. 用 Streamlit 写界面：搜索框、新增/编辑表单、表格展示、删除按钮。
5. 增加导入导出：用 pandas 读取 CSV/Excel 批量入库，导出时把表内容写成 xlsx。
6. 加入低库存预警逻辑：查询数量低于阈值的商品，用 st.warning 或高亮显示。
7. 启动 `streamlit run app.py`，把启动命令存成桌面快捷方式，方便日常使用。

### 76. 批量转换电子书格式，EPUB、MOBI、TXT 互相转换。

**细分能力点（5 条）**

1. 批量处理文件夹内所有电子书，自动识别原格式。
2. EPUB、MOBI、TXT、PDF 之间的互相转换（TXT 生成带目录的 EPUB）。
3. 保留封面、目录、章节结构，转 EPUB 时自动生成 TOC。
4. 转换前自动清理乱码、修复换行（TXT 常见问题）。
5. 转换后按格式分类归档到新目录，生成转换日志。

**可执行提示词（5 条）**

1. "把 D:\books\txt 文件夹里所有 TXT 转成 EPUB，自动切分章节并生成目录，输出到 D:\books\epub。"
2. "把 D:\books\epub 里的书批量转成 MOBI，保留封面和目录，方便放进 Kindle。"
3. "这个 TXT 文件里有乱码和多余空行，帮我清理后再转成 EPUB。"
4. "批量转换 D:\ebooks 下所有电子书，转成 EPUB，转换失败的单独列个清单。"
5. "转完的电子书按作者建文件夹归档，并生成一份转换日志。"

**操作步骤（7 步）**

1. 安装 Calibre，或用 Python 库 `pip install ebooklib beautifulsoup4`，Calibre 自带 ebook-convert 命令行最稳。
2. 整理源文件夹，确认格式与文件编码（TXT 检查 GBK/UTF-8）。
3. 写批量脚本：遍历文件，按扩展名调用 ebook-convert 或对应库函数。
4. TXT 转 EPUB 前做预处理：按正则切章节、去空行、转换编码。
5. EPUB 转 MOBI/PDF 直接用 ebook-convert，加 `--preserve-cover-aspect-ratio` 等参数。
6. 转完后用脚本校验产物：能否打开、是否含封面/TOC，失败的重试。
7. 把输出按作者/格式归档到新目录，写一份转换日志（原路径、新路径、状态）。

4. 到期提醒：桌面通知/弹窗，区分浇水、施肥、换盆类型。
5. 异常记录：黄叶、虫害、烂根等，附带照片便于跟踪恢复。

**可执行提示词（5 条）**

1. "帮我建一个绿植养护台账，记录每盆植物的名称、位置、上次浇水时间、浇水周期天数。"
2. "给绿萝设置每 4 天浇水一次、每月施肥一次，自动算出下次时间并在到期当天提醒我。"
3. "今天给阳台的琴叶榕浇了水，帮我更新记录，并列出明天需要浇水的所有植物。"
4. "生成本周绿植养护计划表：周几给哪几盆浇水、哪几盆施肥，输出成清单。"
5. "我这棵龟背竹叶子发黄了，帮我记录异常并给一个处理建议，设置 3 天后复查提醒。"

**操作步骤（7 步）**

1. 用 SQLite 建 plants 表：名称、品种、位置、光照、浇水周期、施肥周期、上次浇水/施肥时间。
2. 建 care_log 表记录每次养护事件（类型、时间、备注、照片路径）。
3. 用 Streamlit 或命令行写录入功能，逐盆录入现有绿植信息。
4. 写计算函数：下次浇水日 = 上次浇水日 + 周期天数，同理施肥、换盆。
5. 用 plyer/win10toast 做到期提醒，schedule 每天 8 点检查当天到期任务。
6. 增加拍照记录功能（Pillow/cv2 调摄像头或读图），把照片存到 plant_photos 目录。
7. 生成本周/下周养护计划表，导出 Excel，设置 Windows 计划任务自启。
