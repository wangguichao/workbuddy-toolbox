# Markdown 多格式转换

把整个文件夹里的 Markdown 文档批量转换为 Word、PDF、HTML 三种格式，自动处理标题、表格、代码块、图片和链接，并保证三种格式版式一致、图片正常显示。

## 适用场景

- 一批 Markdown 笔记/文档需要导出为 Word 交付或存档，格式要与公司标准一致
- 需要同时产出 PDF（打印/分享）和 HTML（网页/发布）版本的同一批文档
- 文档内容更新后要重新生成全套三种格式，保持各版本同步

## 向 Workbuddy 发送的指令

"把 D:\docs\ 里所有 Markdown 文件批量转成 Word、PDF、HTML 三种格式，输出到 D:\docs\output\，转换完成后生成清单列出成功和失败的文件及原因。"

## 处理要点

- 一次性读取输入文件夹内全部 .md 文件批量转换，无需逐个操作；子文件夹按原结构处理。
- 自动解析 Markdown 常见语法：标题层级、表格、代码块、图片、链接、列表，转换后版式保持完整。
- 各格式适配：Word 套用公司文档模板（reference 模板）统一标题字体字号；PDF 设置中文字体避免乱码，可加页眉页脚，保证打印效果一致；HTML 保留代码块高亮与链接跳转。
- 图片等资源为相对路径时自动重映射，确保 Word、PDF、HTML 三种格式里图片都能正常显示。
- 按与源文件同名的规则命名输出文件（如 报告.md → 报告.docx / 报告.pdf / 报告.html），避免混淆。

## 输出要求

- 每个 Markdown 源文件同时产出三种格式：Word（.docx）、PDF、HTML，内容一致。
- 输出到指定目录（如 D:\docs\output\），保留输入文件夹的子目录结构。
- 输出文件与源文件同名，仅扩展名不同，方便对应查找。
- 转换完成后生成一份转换清单/报告：统计成功与失败文件数量，失败文件记录错误原因，供集中复查处理。

## 注意事项

- 转换前确认源 Markdown 里的图片、附件等资源路径完整，避免转换后图片缺失或显示为占位图。
- 代码块在 Word 中默认可能丢失等宽字体或高亮，转 Word 时如需保留样式要明确告知；PDF 与 HTML 默认按原样保留。
- 表格列数过多时 Word 中可能溢出页面，可要求自动调整列宽或横向排布。
- 个别含复杂语法或损坏的源文件转换失败属正常，无需整体重跑，让 Workbuddy 按清单单独修复失败文件即可。
- 需要定期更新时可让 Workbuddy 定时重新转换新增文档并刷新 output 目录，避免手工重复操作。
