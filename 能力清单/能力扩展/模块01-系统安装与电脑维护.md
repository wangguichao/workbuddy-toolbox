# 系统安装与电脑维护（模块 01）

该模块把以下能力扩展为可直接参考的子项、提示词和操作步骤。原始条数 8，共 120~160 个扩展条目。

### 1. 下载 Steam，它可以自动帮你找到官网、下载、安装

**细分能力点（5 条）**

1. 识别并校验 Steam 官方网址（store.steampowered.com），避免误入假冒下载站。
2. 自动选择与系统匹配的 Windows 64 位官方安装包 SteamSetup.exe 下载。
3. 下载完成后校验安装包数字签名，确认为 Valve Corp. 官方签名。
4. 可带参数静默安装，自定义安装路径（如 D:\Steam），控制是否创建桌面快捷方式。
5. 安装完成后自动验证版本、调整下载区（中国上海）、关闭开机自启。

**可执行提示词（5 条）**

1. "帮我找到 Steam 官方下载页面，下载 Windows 版安装包，存到 D:\Downloads\Steam，完成后告诉我文件位置和大小。"
2. "Steam 官网到底是 store.steampowered.com 还是 steamcommunity.com？帮我确认官方网址后下载安装程序。"
3. "下载好 Steam 安装包后，帮我用静默安装参数安装到 D:\Steam，不创建桌面快捷方式，不勾选开机自启。"
4. "Steam 安装完成后，帮我在设置里把下载区改成中国（上海），关闭『启动时自动登录』和开机自启，并验证能否打开商店。"
5. "帮我检查刚下载的 SteamSetup.exe 的数字签名是不是 Valve 官方的，防止下载到捆绑病毒的假安装包。"

**操作步骤（7 步）**

1. 打开浏览器，地址栏手动输入 https://store.steampowered.com/about ，按 Enter 进入 Steam 官方首页。
2. 点击页面右上角或首页的"安装 Steam"绿色按钮，下载 SteamSetup.exe。
3. 下载完成后右键安装包 -> 属性 -> 数字签名，确认签名者名称为 "Valve Corp." 且状态为"正常"。
4. 双击运行安装包，按向导选择安装目录（建议改为 D:\Steam），取消勾选"开机自动启动 Steam"。
5. 等待安装完成，首次启动会弹出更新窗口，点击"下一步"完成客户端更新。
6. 登录账号后打开 设置 -> 下载，将下载地区改为"中国 - 上海"，按需设置下载限速。
7. 打开 设置 -> 界面，关闭"启动时自动运行"并调整语言，重启 Steam 确认配置生效。

### 2. 下载 idea，vscode，pycharm等等IDE，配置 sql server，jdk，python，maven等各种环境

**细分能力点（5 条）**

1. 从官方源（JetBrains 官网、code.visualstudio.com、python.org、Oracle/Temurin 官网）下载并安装各 IDE 与运行时。
2. 配置 JDK：设置 JAVA_HOME 环境变量并加入 Path，用 java -version 验证。
3. 配置 Python：安装时勾选 Add to PATH，设置 pip 国内镜像源。
4. 配置 Maven：解压、设置 MAVEN_HOME，修改 settings.xml 的本地仓库路径和阿里云镜像。
5. 安装 SQL Server Express 并配置 sa 密码、开启 TCP/IP 端口 1433，用 SSMS 连接测试。

**可执行提示词（5 条）**

1. "帮我下载 IntelliJ IDEA Community 版安装包并安装，路径放 D:\JetBrains\IDEA，装好后告诉我怎么新建第一个 Java 项目。"
2. "下载并安装 VS Code，帮我装好中文语言包、Python 扩展、Java 扩展和 Remote-SSH 扩展，配好 settings.json 里的中文字体和自动保存。"
3. "帮我配置 JDK 17：下载 Temurin 17 装到 D:\Java\jdk-17，新建 JAVA_HOME 环境变量并把 bin 加入 Path，装完运行 java -version 验证。"
4. "帮我配置 Python 开发环境：装 Python 3.11 到 D:\Python311，勾选 Add to PATH，用 pip config set global.index-url 把镜像换成清华源，然后装好 openpyxl 和 requests。"
5. "帮我安装 SQL Server Express 2022 到 D:\MSSQL，设置 sa 密码为强密码，开启 1433 端口 TCP/IP，装好 SSMS 并连接 localhost 测试。"

**操作步骤（9 步）**

1. 打开"设置 -> 系统 -> 关于"确认系统为 Windows 10/11 64 位，并确认磁盘剩余空间充足（建议留 10GB 以上）。
2. 浏览器访问 https://www.jetbrains.com/idea/download 下载 Community 版；访问 code.visualstudio.com 下载 VS Code 并安装。
3. 访问 https://adoptium.net 下载 Temurin JDK 17（或 Oracle JDK 17），按默认路径或自定义路径（如 D:\Java\jdk-17）安装。
4. 打开 系统属性 -> 高级系统设置 -> 环境变量，在"系统变量"新建 JAVA_HOME = D:\Java\jdk-17；编辑 Path 新增 %JAVA_HOME%\bin。
5. 打开新的 CMD 窗口输入 java -version 和 javac -version；若提示不是内部命令，说明环境变量未生效，注销后重试。
6. 从 python.org 下载 Python 3.11 安装包，安装时务必勾选 "Add python.exe to PATH"，再点 Install Now。
7. 打开 CMD 运行 `python -m pip install --upgrade pip`，再运行 `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple` 换镜像源。
8. 从 maven.apache.org 下载 apache-maven-3.9.x 二进制包解压到 D:\Maven；新建 MAVEN_HOME=D:\Maven\apache-maven-3.9.x，Path 加入 %MAVEN_HOME%\bin；编辑 settings.xml 将 <localRepository> 指向 D:\Maven\repository，并把中央仓库镜像换成阿里云（https://maven.aliyun.com/repository/public）。
9. 下载 SQL Server Express 安装包，按向导选择"基本"安装类型，设置 sa 密码；打开"SQL Server 配置管理器"启用 TCP/IP 并设置为 1433 端口；安装 SSMS 连接 localhost 验证。

### 6. 扫描系统文件，管理开机自启软件，协助清理电脑

**细分能力点（5 条）**

1. 扫描并统计磁盘占用，定位大文件、临时文件、缓存与更新残留。
2. 管理开机启动项：查看任务管理器"启动应用"、注册表 Run 键和启动文件夹中的自启软件。
3. 一键清理系统临时目录（temp、%temp%、prefetch）和 Windows 更新缓存（SoftwareDistribution）。
4. 使用系统磁盘清理（cleanmgr）与存储感知释放空间，识别可压缩、可移动的文件。
5. 生成清理报告：列出被清理的项目、释放的空间，以及建议手动确认的疑似可删项。

**可执行提示词（5 条）**

1. "扫描 C 盘占用空间最大的前 20 个文件/文件夹，按大小排序，列出完整路径和占用多少 GB，标出哪些是临时文件。"
2. "帮我列出所有开机自启项目：任务管理器启动项、注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 和启动文件夹，标出可疑项并给出禁用建议。"
3. "帮我清理系统临时文件、Windows 更新缓存和缩略图缓存，先估算能释放多少空间，再执行清理。"
4. "清理 C:\Users\我的用户名\AppData\Local\Temp 下 7 天前创建的临时文件，删除前把要删的文件清单保存到 D:\清理记录.txt。"
5. "帮我用 Windows 磁盘清理工具跑一遍，勾选『Windows 更新清理』和『以前的 Windows 安装』，然后告诉我释放了多少空间。"

**操作步骤（8 步）**

1. 打开"设置 -> 系统 -> 存储"，查看 C 盘和各盘的空间占用总览。
2. 按 Win+R 输入 temp、%temp%、prefetch 打开临时目录，Ctrl+A 全选后删除（跳过占用中的文件即可）。
3. 按 Win+R 输入 cleanmgr，选择 C 盘，勾选"Windows 更新清理""临时文件""缩略图""传递优化文件"等项后执行清理。
4. 打开"设置 -> 系统 -> 存储 -> 临时文件"再次清理，并开启"存储感知"自动清理。
5. 按 Ctrl+Shift+Esc 打开任务管理器 -> "启动应用"选项卡，对不需要的自启项点击右键 -> 禁用。
6. 按 Win+R 输入 regedit，进入 HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run 和 HKEY_LOCAL_MACHINE\...\Run，查看并删除多余启动项（先导出备份）。
7. 用 Everything 或 TreeSize Free 按大小扫描全盘，筛选出无用的安装包、视频缓存等大文件。
8. 打开"设置 -> 应用"卸载不再使用的软件，重启电脑验证启动速度和磁盘空间变化。

### 20. 协助排查网络问题，优化家庭网络速率

**细分能力点（5 条）**

1. 用 ipconfig / ping / nslookup 定位是局域网、外网还是 DNS 解析故障。
2. 重置网络栈：刷新 DNS、Winsock、TCP/IP 协议栈，修复常见连接问题。
3. 优化 DNS 配置：切换到阿里 223.5.5.5 / 腾讯 119.29.29.29 / 谷歌 8.8.8.8。
4. 检查网卡驱动版本，更新到官网最新版；区分 2.4G / 5G 频段并选择干扰小的信道。
5. 用在线测速工具对比有线与无线速率，定位家庭网络瓶颈并给出优化建议。

**可执行提示词（5 条）**

1. "帮我排查网络连不上：依次运行 ipconfig /all、ping 网关、ping 223.5.5.5、ping www.baidu.com，把结果贴出来并告诉我故障出在哪一段。"
2. "我的网总是隔一会断一次，帮我检查网卡驱动版本，给出当前硬件 ID 对应的官方驱动下载链接。"
3. "帮我把 DNS 改成 223.5.5.5 和 119.29.29.29，然后运行 ipconfig /flushdns 刷新缓存，写出每一步操作。"
4. "帮我写一个一键修复网络脚本：ipconfig /flushdns、netsh winsock reset、netsh int ip reset，然后提示重启电脑。"
5. "我家宽带是 500M，但下载只有 30MB/s，帮我分析可能的原因，并教我登录路由器改 5G 信道和启用 QoS。"

**操作步骤（8 步）**

1. 按 Win+R 输入 cmd 打开命令提示符，运行 `ipconfig /all` 查看本机 IP、默认网关和当前 DNS。
2. 运行 `ping 192.168.1.1 -t`（网关按实际地址），能通说明局域网正常；不通则检查网线、路由器指示灯和网卡。
3. 运行 `ping 223.5.5.5` 判断外网连通性；再运行 `ping www.baidu.com`，后者不通前者通说明 DNS 解析有问题。
4. 网络异常时依次运行 `ipconfig /flushdns`、`netsh winsock reset`、`netsh int ip reset`，然后重启电脑。
5. 打开"控制面板 -> 网络和 Internet -> 网络连接"，右键当前网卡 -> 属性 -> IPv4 -> 属性，填入首选 DNS 223.5.5.5、备用 DNS 119.29.29.29。
6. 按 Win+X 打开设备管理器，展开"网络适配器"，右键网卡 -> 属性 -> 详细信息 -> 硬件 ID，记下 VEN_ 和 DEV_ 编号，到厂商官网搜索下载最新驱动。
7. 浏览器访问路由器管理地址（通常是 192.168.1.1 或 192.168.0.1），登录后把无线频段切到 5G，信道设为"自动"或 36/149 等干扰较小的信道，开启 QoS/带宽控制。
8. 打开 speedtest.cn 或 fast.com 分别测有线和无线速率，对比结果确认瓶颈在网卡、路由器还是宽带线路，据此调整。

### 46. 清理微信缓存、重复文件，筛选大体积无用文件一键删除

**细分能力点（5 条）**

1. 使用微信"设置 -> 存储空间"管理缓存、聊天文件和表情包占用。
2. 定位微信数据目录（Documents\WeChat Files）并统计各账号、各类型文件占用。
3. 按 MD5/SHA1 哈希扫描全盘重复文件，先预览后删除，避免误删照片和文档。
4. 按大小和最后访问时间筛选大体积无用文件（视频缓存、下载残留、旧压缩包）。
5. 生成清理报告并支持"一键删除"清单：先移入回收站，确认无影响后再彻底删除。

**可执行提示词（5 条）**

1. "帮我打开微信存储空间管理，看看『缓存』和『聊天文件』各占多少，把能安全清理的缓存清掉，不删聊天记录。"
2. "扫描 D:\ 和 E:\ 找出所有大于 1GB 的文件，列出路径、大小和修改时间，标出像是视频缓存或安装包的。"
3. "帮我找出 F:\ 下面文件名相同但大小不同的重复文件，按组列出来，先给我确认再删。"
4. "分析 C:\Users\我的用户名\Documents\WeChat Files 的占用情况，把 1 年没打开过的群聊图片和视频缓存文件清理掉。"
5. "帮我写一个 Python 脚本，用 hashlib 算 MD5 找出全盘重复文件，输出 Excel 报告，重复的自动移动到 D:\重复文件待删 文件夹。"

**操作步骤（7 步）**

1. 打开微信 -> 左下角设置 -> 存储空间，点击"管理"，查看缓存与聊天文件占用明细。
2. 点击"清理"清理微信缓存（不影响聊天记录）；聊天文件按会话逐一勾选删除。
3. 打开资源管理器进入 C:\Users\你的用户名\Documents\WeChat Files，右键各账号文件夹 -> 属性，确认最大占用来源（图片/视频/语音）。
4. 重要聊天记录先通过"设置 -> 通用 -> 聊天记录迁移与备份"备份到本地或另一台设备，再清理旧文件。
5. 下载安装免费去重工具 AllDup 或 Duplicate Cleaner，勾选"照片/视频/文档"类型，按 MD5 对比扫描，预览后勾选冗余副本删除。
6. 用 TreeSize Free 或 WizTree 按文件大小排序，筛选出大于 1GB 的安装包、镜像（.iso）、视频缓存，人工确认后删除。
7. 如需脚本化，用 Python 的 os.walk 遍历指定盘符，hashlib 计算文件 MD5 存入 dict 找出重复项，把待删文件先移到"待删"文件夹而非直接删除。

### 73. 清理浏览器缓存、Cookie，批量导出备份账号书签

**细分能力点（5 条）**

1. 分浏览器（Chrome/Edge/Firefox）清理缓存、Cookie 与站点数据，可只清缓存保留登录态。
2. 批量导出书签：Chrome/Edge 导出 HTML，Firefox 导出 JSON，统一备份。
3. 导出密码/登录信息：Edge 密码导出 CSV，Chrome 用扩展或"从 Google 导入"方式备份。
4. 定期备份到本地目录并压缩，可同步到网盘，支持重装系统后导入恢复。
5. 支持设置定期清理与备份提醒，减少 Cookie 泄露与缓存膨胀风险。

**可执行提示词（5 条）**

1. "帮我在 Chrome 里清除浏览缓存和 Cookie，保留已保存的密码和书签，只清理最近 1 个月的数据。"
2. "把 Chrome 的书签导出成 HTML 文件，存到 D:\浏览器备份\Chrome书签_20260819.html。"
3. "把 Edge 的书签和密码一起备份：书签导出 HTML，密码导出 CSV，压缩后放到 D:\浏览器备份。"
4. "帮我清理电脑上所有浏览器的缓存和临时文件（Chrome、Edge、Firefox），先估算释放空间再执行。"
5. "帮我设置一个每周自动任务：周一提醒清理浏览器缓存，并把最新书签备份到 D:\浏览器备份 和网盘。"

**操作步骤（7 步）**

1. Chrome：点击右上角三个点 -> 设置 -> 隐私和安全 -> 清除浏览数据，选择"时间范围"为"时间不限"，勾选"缓存的图片和文件"和"Cookie 及其他站点数据"，点击清除数据。
2. Chrome 备份书签：按 Ctrl+Shift+O 打开书签管理器 -> 右上角三个点 -> 导出书签，选择保存位置 D:\浏览器备份，保存为 HTML。
3. Edge：设置 -> 隐私、搜索和服务 -> 选择要清除的内容，同样勾选缓存与 Cookie；书签导出在"收藏夹"页面点三个点 -> 导出收藏夹。
4. Edge 导出密码：设置 -> 个人资料 -> 密码，点右上角三个点 -> 导出密码，输入系统 PIN 后保存 CSV（仅本地使用，注意保管）。
5. Firefox：历史记录 -> 清除最近历史记录 -> 清除缓存和 Cookie；书签 -> 管理书签 -> 导入和备份 -> 导出书签为 HTML/JSON。
6. 将导出的 HTML、CSV 统一复制到 D:\浏览器备份，右键 -> 添加到压缩文件生成 zip。
7. 如需定期执行，用"任务计划程序"创建每周任务，调用浏览器自带的清理功能或 CCleaner 的命令行参数（如 `ccleaner /AUTO`）自动清理。

### 82. 自动检测电脑驱动缺失，一键下载安装适配驱动程序

**细分能力点（5 条）**

1. 通过设备管理器识别带黄色感叹号的异常设备，定位缺失/损坏驱动。
2. 通过硬件 ID（VEN_xxx&DEV_xxx）精确匹配对应驱动的官方下载源。
3. 使用 Windows 更新、厂商官网或驱动工具（驱动精灵/360 驱动大师）一键安装适配驱动。
4. 安装前备份现有驱动，支持重装系统后一键恢复驱动。
5. 检测 GPU、声卡、网卡驱动版本是否过旧，给出更新建议并验证安装后设备状态。

**可执行提示词（5 条）**

1. "帮我检查设备管理器里所有带黄色感叹号的设备，逐个列出名称和硬件 ID，告诉我缺哪个驱动。"
2. "我的显卡是 NVIDIA RTX 3060，帮我找到官网最新驱动下载页，说明是装 Game Ready 还是 Studio 版。"
3. "帮我用命令备份全部已安装驱动到 D:\驱动备份，写清楚重装系统后怎么恢复。"
4. "检测我网卡和声卡驱动是否过时，给出官方下载链接和安装步骤。"
5. "帮我在设备管理器里自动搜索并更新所有有问题的驱动，完成后验证是否还有黄色感叹号。"

**操作步骤（7 步）**

1. 按 Win+X 打开设备管理器，展开各分类，找出名称前带黄色感叹号（！）的设备。
2. 右键异常设备 -> 属性 -> 详细信息，下拉选择"硬件 ID"，复制如 VEN_10DE&DEV_2503 的编号。
3. 方式一（系统更新）：右键设备 -> 更新驱动程序 -> 自动搜索驱动程序；也可选择"手动查找"，指向官网下载的解压目录。
4. 方式二（官网下载）：根据硬件 ID 中的 VEN_/DEV_ 或设备型号，前往对应厂商官网（NVIDIA、AMD、Intel、Realtek、主板厂商）搜索下载最新 WHQL 驱动。
5. 方式三（工具一键）：下载驱动精灵或 360 驱动大师，一键扫描缺失驱动后安装；注意安装时取消勾选捆绑的推广软件。
6. 备份驱动：以管理员运行 CMD，执行 `dism /online /export-driver /destination:D:\驱动备份`，导出全部驱动；恢复时在设备管理器手动指向该文件夹即可。
7. 安装完成后重启电脑，回到设备管理器确认感叹号消失、设备状态"正常工作"，可用 dxdiag 验证显卡/声卡识别正常。

### 88. 扫描磁盘冗余安装包、压缩包，筛选长期未使用文件清理

**细分能力点（5 条）**

1. 全盘扫描冗余安装包（.exe/.msi/.iso）和压缩包（.zip/.rar/.7z），按大小排序。
2. 结合"最后访问时间"筛选长期未使用的文件（如 180 天未打开）。
3. 识别已卸载软件的残留安装包，与已安装程序清单比对后标记清理。
4. 生成磁盘占用与可清理清单报告（可导出 Excel），供人工确认。
5. 清理前将文件移入回收站/待删目录，确认软件无影响后再彻底删除。

**可执行提示词（5 条）**

1. "扫描 C 盘和 D 盘上所有 .exe、.msi、.iso、.zip、.rar、.7z 文件，按文件大小从大到小列出前 50 个，标出完整路径。"
2. "找出 C 盘和 D 盘上超过 1 年没打开过、且大于 500MB 的文件，列出路径、大小和最后访问时间，供我确认是否删除。"
3. "帮我清理下载文件夹 C:\Users\我的用户名\Downloads 里超过 3 个月的安装包和压缩包，先出清单再删。"
4. "扫描全盘找出已卸载软件留下的安装包残留（比如已经卸载了 Steam 但还留着 SteamSetup.exe），列出待删清单。"
5. "帮我写个 Python 脚本：遍历指定盘符，统计大文件分布（按扩展名和文件夹归类），把结果导出成 Excel 报告。"

**操作步骤（7 步）**

1. 下载并打开 Everything，在搜索框输入 `*.exe | *.msi | *.iso | *.zip | *.rar | *.7z`，点击"大小"列倒序排列，即可看到全盘最大的安装包/压缩包。
2. 下载 WizTree 或 TreeSize Free 扫描 C/D 盘，查看各文件夹占用，定位下载目录、临时目录和旧备份目录的冗余。
3. 打开 C:\Users\你的用户名\Downloads，按"修改日期"排序，将 3 个月前的安装包、旧压缩包列入待删清单。
4. 对照"设置 -> 应用 -> 已安装的应用"，确认已卸载软件对应的安装包（如卸载 7-Zip 后残留的 7zsetup.exe）可以删除。
5. 用磁盘清理工具清理 C:\Windows\SoftwareDistribution\Download（Windows 更新缓存）和 C:\Windows\Temp。
6. 如需脚本化，用 Python 写脚本：os.walk 遍历盘符，os.path.getsize 获取大小，os.path.getatime 获取最后访问时间，筛选 `size > 500MB and 今天-最后访问 > 180天` 的文件写入 Excel（用 openpyxl）。
7. 将待删除文件先剪切到 D:\待删除文件夹（相当于回收站缓冲），正常运行电脑一周，确认无任何软件报错后再彻底删除该文件夹。
