# SkillHub 技能清单（腾讯）

> **SkillHub** 是腾讯推出的「面向中国用户的 AI 技能社区」：[skillhub.cn](https://skillhub.cn/skills)，精选 **Top 50** 高质量 AI 技能，覆盖办公、开发、运维、营销、学习等场景。
>
> **WorkBuddy 已集成 SkillHub CLI**，可直接安装技能，无需手动搜索。

## 如何安装技能

- **方式一（推荐，零操作）**：直接对 WorkBuddy 说 ——「帮我安装 SkillHub 上的『技能名』技能」，WorkBuddy 会通过 SkillHub CLI 自动安装。
- **方式二（命令行）**：登录后执行 `skillhub login` → `skillhub install <技能名>`。
- **方式三（网页）**：打开 [skillhub.cn/skills](https://skillhub.cn/skills) 搜索技能名，按提示安装到 WorkBuddy。

> 提示：技能名以 SkillHub 站内名称为准；不确定时让 WorkBuddy 在 SkillHub 搜索对应关键词即可。
