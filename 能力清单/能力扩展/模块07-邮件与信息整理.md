### 8. 将浏览器200个收藏夹的网页去重、按主题分类

**细分能力点（5 条）**

1. 支持 Chrome/Edge 书签管理器一键导出 HTML 文件，兼容旧版 Netscape 书签格式。
2. 用 BeautifulSoup 解析 HTML，提取每条书签的标题、URL 和所在文件夹层级。
3. 按 URL 规范化去重：去掉 ?utm_source 等追踪参数、统一协议与域名大小写、折叠 http/https 与 www。
4. 基于标题分词和域名关键词自动打主题标签（编程、新闻、购物、工作、娱乐等）。
5. 生成分类后的目录结构并导出新 HTML，可重新导入浏览器，同时输出 CSV 清单便于核对。

**可执行提示词（5 条）**

1. "读入 D:\浏览器备份\bookmarks.html，把 200 条收藏去重，按标题和域名打主题标签，输出去重后的清单。"
2. "按我的常用主题（编程、新闻、购物、工作、娱乐、学习）把这批书签自动分类，给出每个主题的条数。"
3. "URL 里带 ?utm_source、?from 这类追踪参数的先去掉参数再判重，保留打开最早的 1 条。"
4. "把分类结果生成新的 bookmarks.html，保留原文件夹层级，同时导出一份 CSV 汇总表给我核对。"
5. "找出主题分不出来的书签单独列一个『待定』文件夹，标注原因（标题过短或域名陌生）。"

**操作步骤（6 步）**

1. 在 Chrome/Edge 打开书签管理器（Ctrl+Shift+O），点击"导出书签"另存为 HTML 文件。
2. 安装 Python，pip 安装 beautifulsoup4、lxml、pandas。
3. 写脚本用 BeautifulSoup 解析 HTML，遍历 <A> 标签读取 href 和 add_date 属性，同时记录 <H3> 文件夹层级。
4. 用 urllib.parse 去掉查询参数，把 URL 转为小写域名并折叠 www/http/https，建立 URL→记录 的映射去重。
5. 构建关键词词典（如 "python|java|github"→编程）对标题和域名打标签，规则之外落到"待定"。
6. 用 html 模板或第三方库导出新书签 HTML 并在浏览器导入验证，必要时调整关键词后再重跑。

### 10. 管理qq邮箱邮件，按发件人、主题关键词分类归档，垃圾邮件批量标记

**细分能力点（5 条）**

1. 在 QQ 邮箱设置中开启 IMAP/SMTP 服务，用 16 位授权码登录（非邮箱登录密码）。
2. 用 imaplib 批量拉取收件箱邮件头（发件人、主题、日期），支持按日期范围增量读取。
3. 按发件人域名/地址和主题关键词建立规则表，自动打标签并归档到不同文件夹。
4. 识别标题/正文含"中奖、发票代开、兼职刷单"等特征的垃圾邮件，批量标记或删除。
5. 用 pandas 生成邮件分类统计报告（发件人 Top20、各分类数量），核对后再执行移动。

**可执行提示词（5 条）**

1. "用我的 QQ 邮箱授权码通过 IMAP 登录，把收件箱最近 3 个月的邮件头（发件人、主题、日期）拉下来存成 CSV。"
2. "把来自 @qq.com 群发、订阅号、同事、客户等不同发件人的邮件，按发件人域名自动归类。"
3. "标题或正文含『中奖、发票代开、兼职刷单、退订』的邮件批量标记为垃圾邮件，先给我清单再删。"
4. "按主题关键词（报价、合同、发票、周报）创建 IMAP 文件夹，把匹配的邮件移动过去。"
5. "生成邮件分类统计表：发件人 Top20、每天收发量、各分类文件夹邮件数量，导出 Excel 发我。"

**操作步骤（7 步）**

1. 登录 mail.qq.com → 设置 → 账户，开启 IMAP/SMTP 服务，按提示用手机号验证获取 16 位授权码。
2. 安装 Python，确认 imaplib、email、pandas 可用（imaplib 为标准库，无需额外安装）。
3. 用 imaplib IMAP4_SSL 连接 imap.qq.com 端口 993 登录，SELECT 收件箱后用 SEARCH 按日期范围取 UID。
4. 循环遍历 UID，用 imaplib FETCH (BODY.PEEK[HEADER]) 只取邮件头，避免下载附件占用流量。
5. 用 email.header.decode_header 解码发件人/主题，处理 =?UTF-8?B? 等 Base64/Quoted-Printable 编码。
6. 维护一个 JSON 规则表（发件人关键词、主题关键词→目标文件夹），先以"只统计不移动"模式跑一遍看结果。
7. 确认无误后，用 IMAP COPY + STORE \Deleted 批量移动归档，垃圾邮件单独标为 \Junk 或移动到垃圾箱，再 EXPUNGE 清除。

### 11. 管理百度网盘文件，按文件名分类整理

**细分能力点（5 条）**

1. 通过百度网盘开放平台 API（或第三方 CLI 工具）获取指定目录下的完整文件列表。
2. 按扩展名建立类型映射（pdf/doc→文档、jpg/png→图片、mp4→视频、zip/rar→压缩包、py/js→代码）。
3. 结合文件名关键词（合同、报表、照片、课程）二次补充分类规则，提高归类准确率。
4. 支持批量重命名统一规范（日期_项目_类型），并自动创建分类文件夹移动文件。
5. 计算文件 md5 识别重复文件，生成"重复清单"待人工确认，并输出整理前后路径对比报告。

**可执行提示词（5 条）**

1. "用百度网盘 API 扫描我网盘根目录下所有文件，按扩展名统计文档、图片、视频、压缩包各多少。"
2. "按文件名关键词（合同、报表、照片、课程、简历）把文件分到对应分类文件夹，先给方案再执行。"
3. "把文件名统一改成『YYYYMMDD_项目名_类型』格式，批量重命名，冲突的加 _1、_2 后缀。"
4. "找出网盘里 md5 相同的重复文件，输出重复清单列出大小和时间，等我确认后再删。"
5. "整理完成后生成一份分类汇总报告（每个文件夹文件数与总大小），导出 Excel 发给我。"

**操作步骤（7 步）**

1. 在百度网盘开放平台（pan.baidu.com）注册应用，获取 AppID/AppKey，并通过 OAuth 授权拿到 access_token。
2. 安装 Python，用 requests 调 /rest/2.0/xpan/multimedia 或 v1/file 系列接口，递归拉取全部文件信息（fs_id、path、md5、size）。
3. 用 pandelete/pandas 建两张表：一张扩展名→类别映射，一张文件名关键词→类别映射。
4. 先对文件列表做分类预测，输出"预测结果 + 置信度"，把置信度低的条目人工过一遍。
5. 调用 create 接口批量建分类文件夹，调用 move 接口把文件移动到对应文件夹。
6. 重复文件：按 md5 分组，只保留最早上传的 1 份，其余移到"重复待删"文件夹而不是直接删除。
7. 记录每个文件整理前后的完整路径，导出 Excel 对照表；遇到接口限流时加 time.sleep 控制请求频率。

### 31. 自动同步多平台待办清单（飞书、钉钉、备忘录），汇总统一视图

**细分能力点（5 条）**

1. 通过飞书开放平台自建应用 API 拉取"我的待办"任务（标题、截止时间、状态、优先级）。
2. 通过钉钉开放平台 API 拉取任务/待办接口，处理 access_token 的获取与刷新。
3. 解析 Windows 备忘录/日历（或 Wunderlist、微软 To Do 的导出数据）作为第三数据源。
4. 按"标题相似度 + 截止日期"做跨平台去重合并，同一条只保留一条并标注来源平台。
5. 生成统一视图（Excel 或 HTML），用任务计划程序定时同步并推送汇总结果。

**可执行提示词（5 条）**

1. "用飞书 app_id/app_secret 拿 token 拉取『我的待办』，再拉钉钉的任务，合并成一张总清单。"
2. "合并时按标题相似度（编辑距离<3）且截止日期相同判定为同一条，只保留一条。"
3. "把合并后的清单按截止时间排序，今天到期和已逾期的排最前面，标红显示。"
4. "生成 Excel 汇总表，列包含：来源平台、标题、截止时间、状态、优先级、是否重复。"
5. "设置每天早 8 点自动跑一次同步，把汇总清单通过 SMTP 发到我邮箱，同时保存 HTML 报告。"

**操作步骤（7 步）**

1. 在飞书开放平台创建企业自建应用，开通"待办"相关权限，拿到 app_id、app_secret，发布上线。
2. 用 requests POST 换取 tenant_access_token，调用 /open-apis/task 系列接口拉取任务列表并转成 DataFrame。
3. 在钉钉开放平台创建应用，获取 appKey/appSecret 换 user access_token，调用待办接口（如 /topapi 系列）拉取任务。
4. 微软 To Do/备忘录：用微软 Graph API 或导出为 JSON/CSV 后读取，与上面数据统一字段。
5. 用 difflib.SequenceMatcher 计算标题相似度，再叠加截止日期相同条件做跨平台去重。
6. 用 openpyxl 生成统一 Excel（列：来源、标题、截止时间、状态、优先级、备注），HTML 同理。
7. 用 Windows 任务计划程序注册每天 8:00 运行的批处理（python 脚本 + 日志输出），再用 smtplib 定时推送结果。

### 38. 自动整理聊天记录，提取客户需求、订单信息归档存档

**细分能力点（5 条）**

1. 用 WeChatMsg 等工具把微信电脑版聊天记录导出为文本或 SQLite 数据库。
2. 按会话/联系人分组，识别客户身份并建立客户档案字段（昵称、备注、联系方式）。
3. 用正则和关键词词典提取订单号、金额、商品名、交货日期等结构化信息。
4. 识别客户"需求句"（含"需要、希望、麻烦、尽快"等意图词），按客户汇总成需求清单。
5. 生成订单台账与客户跟进报告，按月份归档并建立可检索的索引表。

**可执行提示词（5 条）**

1. "把微信电脑版导出的聊天记录文件读进来，按联系人分组统计每个人发了多少条、最近聊天时间。"
2. "从聊天记录里提取订单信息：订单号、金额、商品、交货日期、下单人，整理成订单台账。"
3. "找出客户明确表达的需求句子，按客户汇总成『客户需求清单』，注明原文和日期。"
4. "把聊天里出现的手机号、微信号、邮箱、地址等联系方式单独提取出来去重，建立客户通讯录。"
5. "每周日晚自动整理本周新增聊天，更新订单台账和客户跟进报告，发我邮箱。"

**操作步骤（6 步）**

1. 用 WeChatMsg（开源工具）选择微信电脑版数据，导出为 txt 或 SQLite 数据库文件到 D:\聊天记录\。
2. 安装 Python，用 sqlite3 或 openpyxl 读取导出数据，把消息按 sender、createTime、content 建表。
3. 用正则提取订单号（如 #12345、订单编号[:：]?\d+）和金额（¥\d+.\d{2}），写入订单台账表。
4. 建意图关键词词典（需要、希望、麻烦、尽快、什么时候发货等），对消息做需求句判定。
5. 按联系人分组，把该客户的订单、需求、联系方式汇总成一张 Sheet，形成客户档案。
6. 归档策略：增量处理只读上次 UID 之后的新消息，按月份建文件夹（2026-08\客户A.xlsx）并生成总索引 Excel。

### 43. 监控邮箱新消息，关键词匹配自动回复预设模板邮件

**细分能力点（5 条）**

1. 用 imaplib 轮询（或 IDLE 扩展）监控收件箱新邮件，记录已处理 UID 避免重复回复。
2. 对主题和正文做关键词匹配，命中预设规则（报价、发票、物流、招聘等）。
3. 从模板库中选择对应回复内容，按发件人、邮件主题做变量替换（如称呼、询价单号）。
4. 用 smtplib 通过 SMTP 自动发送 UTF-8 编码的模板回复，并记录发送日志。
5. 设置白名单（重要客户必回）与黑名单（广告免回）、一键暂停开关，避免误发。

**可执行提示词（5 条）**

1. "写个 Python 脚本每 5 分钟检查一次收件箱，有新邮件就打印出来并微信通知我。"
2. "邮件主题含『报价』的，自动回复模板『报价单已收到，我们将在 1 个工作日内回复』，带上对方姓名。"
3. "发件人在白名单且正文含『发票』的，自动回复发票模板并抄送财务邮箱。"
4. "命中垃圾关键词（中奖、兼职、推广）的邮件不自动回复，只记录到日志里。"
5. "把每次自动回复的触发时间、发件人、匹配关键词、回复模板记录下来，生成日志表。"

**操作步骤（7 步）**

1. 在 QQ 邮箱设置中开启 IMAP/SMTP 并获取 16 位授权码，记录 SMTP 服务器 smtp.qq.com 端口 465。
2. 用 imaplib IMAP4_SSL 登录并 SELECT 收件箱，用 SEARCH UNSEEN 或记录已处理 UID 集合检测新邮件。
3. 拉取新邮件的主题与正文（用 email 库解析，处理 multipart 与 base64/UTF-8 编码）。
4. 建立 rules.json：每条规则包含匹配字段（subject/body）、关键词列表、模板文件路径、是否启用。
5. 匹配成功后用 smtplib + SSL 发送模板邮件，MIMEText 显式设置 utf-8 避免中文乱码，设置 From/Reply-To。
6. 用 pandas 追加写日志表（时间、UID、发件人、规则、模板名），支持 --dry-run 参数先模拟不真发。
7. 先用一次性临时邮箱跑一轮 dry-run 验证规则与模板，确认无误回后再切真实邮箱，并留一键停止开关。
