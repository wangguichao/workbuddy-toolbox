# 会议纪要

把会议录音自动转成文字，提炼议题、关键结论、决策项与行动项，按统一模板批量生成会议纪要，实现会议跟进闭环。

## 适用场景

- 会议录音需要整理成结构化纪要，提炼结论和待办，不想逐句听写
- 一批录音文件（周会、项目评审、客户会）需要批量生成纪要并统一归档
- 需要从录音中提取全部行动项，列出负责人和截止时间以便跟进

## 向 Workbuddy 发送的指令

"把 D:\会议录音\20260819-项目评审.mp3 转成文字，提炼会议结论和行动项（负责人+截止时间）及风险点，按模板生成会议纪要，保存到 D:\会议纪要\。"

## 处理要点

- 直接读取指定路径的录音文件（mp3、wav、m4a、aac 等常见格式），支持一次处理整个文件夹内的多个录音并逐个生成纪要。
- 自动完成录音转文字，无需手动转写或核对原文。
- 转写后自动提炼会议内容：会议主题与参与角色、各议题及结论、决策项，不必输出逐句全文。
- 自动提取行动项并结构化：每条任务带负责人、截止时间、任务描述，按名字和时间对号入座。
- 按统一模板排版（会议信息/议题与结论/行动项/风险与待确认），导出为 Markdown 或 Word。

## 输出要求

- 每个录音生成一份独立会议纪要文档，文件名与录音名一致，批量时一一对应。
- 纪要结构：一、会议信息（时间/参会人/主题）；二、议题与结论；三、行动项；四、风险与待确认。
- 行动项以表格呈现，明确任务、负责人、截止日期、优先级，便于后续跟进闭环。
- 输出到指定目录（如 D:\会议纪要\），可按日期归档，导出格式支持 Markdown 或 Word。

## 注意事项

- 多人会议如需要区分发言人或会议角色，提前告知 Workbuddy（如"按参会人区分发言"）；区分不准时直接指出修正。
- 涉及机密内容的录音，确认存储与转写方式符合隐私要求，不把敏感录音传给不相关的渠道。
- 转写结果可能有个别同音字或专业术语错误，生成后检查结论和行动项是否准确，出错处直接让 Workbuddy 修正。
- 录音命名建议用"日期-主题"格式（如 20260819-项目评审.mp3），便于归档和对应；行动项中提到的名字尽量提供全名，避免指代不清。
- 需要长期自动处理时，可让 Workbuddy 监听固定文件夹，拖入新录音即自动转写生成纪要草稿并提醒你复核。
