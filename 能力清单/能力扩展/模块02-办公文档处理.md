# 办公文档处理（模块 02）

该模块把以下能力扩展为可直接参考的子项、提示词和操作步骤。原始条数 11，共 165~220 个扩展条目。

### 3. 将500份PDF文件批量转成Word文件

**细分能力点（5 条）**

1. 支持批量指定输入文件夹，一次性读取全部 PDF 并逐个转换，无需手动逐文件操作。
2. 自动区分文字版 PDF 与扫描版 PDF，扫描件先做 OCR 文字识别再转 Word，保证可编辑。
3. 尽量保留原始 PDF 的段落结构、标题层级、表格和图片等基本版式。
4. 支持按文件名规则或子文件夹分类输出，转换后的 Word 归入对应目录。
5. 生成转换日志与失败清单，跳过损坏文件并记录原因，方便集中复查。

**可执行提示词（5 条）**

1. "把 D:\资料\PDF源文件\ 文件夹里所有 PDF 批量转成 Word，输出到 D:\资料\Word输出\，用 pdf2docx 处理。"
2. "这批 PDF 里有扫描件，帮我先做 OCR 识别再转 Word，输出格式要保留段落和表格。"
3. "转换完成后生成一份报告，列出成功和失败的文件名及失败原因，失败的单独放一个文件夹。"
4. "按子文件夹转换：PDF 在哪个子目录，转出的 Word 也放在对应子目录，保持目录结构。"
5. "只转换文件名包含『合同』的 PDF，转完后按文件名排序输出到指定目录。"

**操作步骤（6 步）**

1. 安装 Python，执行 pip install pdf2docx（依赖 pdfminer.six），需要时再装 python-docx。
2. 把 500 份 PDF 集中放入一个源文件夹，先抽取 3~5 个样本测试转换效果。
3. 编写脚本遍历文件夹，用 pdf2docx 的 Converter 逐文件转换并指定输出路径，异常用 try/except 捕获。
4. 对扫描版 PDF 先调用 PaddleOCR 或 Tesseract 识别文字，再用 python-docx 重建可编辑文档。
5. 转换后抽查 5 个文件，核对标题层级、表格与图片是否保留，按结果调整参数后全量运行。
6. 运行完成后检查日志，把失败文件另存到"待处理"目录，人工修复或用备用引擎（如 ABBYY）重跑。

### 13. 修改论文格式，修改页眉页脚、统一参考文献、图表编号

1. 一键修改整篇论文的页边距、行距、正文字号字体，匹配学校论文模板要求。

3. 自动统一参考文献格式（GB/T 7714、APA 等），并按正文引用顺序重新编号。
4. 批量调整图表编号为"图 1-1""表 2-3"式统一编号，并同步更新正文中的交叉引用。
5. 自动生成目录并更新域代码，保证目录页码、标题与正文内容完全一致。

**可执行提示词（5 条）**

1. "把 D:\论文\毕业论文.docx 的正文改成宋体小四、行距 1.5 倍，标题用黑体，页边距按学校模板设置。"
2. "设置页眉为论文标题、页脚为页码，前 5 页用罗马数字，正文从第 6 页起用阿拉伯数字重新从 1 开始。"
3. "统一参考文献格式为 GB/T 7714，按正文引用顺序重新编号，并同步更新文中 [1][2] 标注。"
4. "把全文图表编号改成『图 2-1』『表 3-2』格式，所有正文里的交叉引用一起更新。"
5. "更新整个文档的目录和所有域，让目录页码与正文一致，然后导出 PDF 检查。"

**操作步骤（6 步）**

3. 用"插入→页眉页脚"分节设置：封面无页码、目录用罗马数字、正文重新从 1 编号。
4. 用 EndNote 或 Zotero 管理文献，选择 GB/T 7714 输出样式后点"更新引文和参考文献"。
5. 把图表题注统一用"引用→插入题注"，编号选择"章号-序号"格式，全文按 F9 更新域。
6. 全选按 F9 更新所有域，再"文件→导出→PDF"检查页眉页脚、编号和目录是否一致。

### 27. 批量提取 Word、PDF 内全部表格，汇总到总 Excel 台账

**细分能力点（5 条）**

1. 支持同时扫描 Word(.docx) 和 PDF 文件，自动识别文件内所有表格区域。
2. 提取表格的行列数据、表头信息，并记录来源文件名与页码便于追溯。
3. 将每个表格按文件归类，保留来源信息（文件名、路径、页号）作为附加列。
4. 自动合并表头相同的表格到同一张 Sheet，异构表格单独分 Sheet 存放。
5. 输出 Excel 台账时自动设置列宽、冻结首行，支持去重、删除空行与数字格式化。

**可执行提示词（5 条）**

1. "把 D:\报表\ 下所有 Word 和 PDF 里的表格提取出来，汇总到一个 Excel，每个源文件一个 Sheet。"
2. "只提取 PDF 里跨页的表格，并把页号、文件名一起记录到总台账里。"
3. "表头一样的表格自动合并到同一个 Sheet，表头不同的单独放，方便统计。"
4. "提取时保留数字格式，金额列保留两位小数，空行自动删除。"
5. "汇总后生成一个 Excel 台账，冻结首行、列宽自适应，另加一列『来源文件』。"

**操作步骤（6 步）**

1. 安装 Python，执行 pip install python-docx pdfplumber openpyxl。
2. 遍历文件夹：Word 用 docx 的 document.tables 读取表格，PDF 用 pdfplumber 的 extract_tables 读取。
3. 为每个表格记录来源文件名、页码、表头，整理成统一的数据结构。
4. 用 openpyxl 创建总台账，按"表头相同合并"或"每文件一 Sheet"两种策略写入。
5. 数据写入后统一数字格式、删除空行、设置冻结窗格与自适应列宽。
6. 抽取 2~3 个文件核对提取结果与原表格，修正解析参数（如表格线检测阈值）后全量运行。

### 57. 批量转换 Markdown 文档为 Word、PDF、HTML 三种格式

**细分能力点（5 条）**

1. 一条命令把整个文件夹的 .md 文件批量转为 Word、PDF、HTML 三种格式。
2. 自动处理 Markdown 中的标题、表格、代码块、图片、链接等常见语法。
3. 支持自定义样式：Word 用 reference.docx 模板、PDF 可加页眉页脚和字体。
4. 图片和资源文件路径自动重映射，保证三种格式里图片都能正常显示。
5. 批量处理后生成转换报告，统计成功/失败文件并记录错误原因。

**可执行提示词（5 条）**

1. "把 D:\docs\ 里所有 Markdown 文件批量转成 Word、PDF、HTML 三种格式，输出到 D:\docs\output\。"
2. "用 pandoc 转换时套用 reference.docx 模板，让 Word 样式和公司文档保持一致。"
3. "转 PDF 时用 xelatex 或 weasyprint 引擎，中文不乱码，并加页眉页脚。"
4. "Markdown 里的图片是相对路径，转换后要保持图片能正常显示。"
5. "转换完成后生成一个清单，列出哪些文件成功、哪些失败及原因。"

**操作步骤（6 步）**

1. 安装 pandoc（winget install pandoc），转 PDF 时另装 MiKTeX 或 TinyTeX（xelatex）。
2. 在 PowerShell 中进入 Markdown 目录，先用单个文件测试转换命令。
3. 转 Word：pandoc input.md -o output.docx --reference-doc=template.docx。
4. 转 PDF：pandoc input.md -o output.pdf --pdf-engine=xelatex -V mainfont="Microsoft YaHei"。
5. 转 HTML：pandoc input.md -o output.html --standalone --css=style.css --embed-resources。
6. 编写 for 循环遍历文件夹批量执行，检查图片路径与表格渲染，修正参数后重跑全量。

### 66. 批量压缩大量 PDF 文件，减小体积不降低文字清晰度

**细分能力点（5 条）**

1. 批量压缩文件夹内所有 PDF，可设定目标压缩比例或质量档位。
2. 对文字型 PDF 用重新编码压缩（不损文字清晰度），对含图 PDF 压缩图片质量。
3. 支持设置压缩后体积上限（如单文件不超过 5MB），超限自动调低参数重压。
4. 压缩前后对比文件大小，输出压缩率报告，便于核对收益。
5. 保留可编辑文字与书签，压缩过程不影响文字选中、复制与搜索。

**可执行提示词（5 条）**

1. "把 D:\扫描件\ 里所有 PDF 压缩到原来一半大小，文字必须保持清晰可选中。"
2. "批量压缩 D:\合同\ 的 PDF，目标单文件不超过 3MB，超出的继续降低图片质量。"
3. "用 Ghostscript 压缩，文字用 /ebook 档，图片适当降采样，保留书签。"
4. "压缩完对比每个文件前后大小，生成压缩率报告给我看。"
5. "把 D:\资料\ 里 200 个 PDF 批量压缩，输出到新文件夹，不要覆盖原文件。"

**操作步骤（6 步）**

1. 安装 Ghostscript（winget install ghostscript），并确认 gswin64c 已加入系统 PATH。
2. 打开 CMD，用 gswin64c -sDEVICE=pdfwrite -dPDFSETTINGS=/ebook 压缩单个文件测试。
3. 分别测试 /screen、/ebook、/printer 三档，对比清晰度与体积，选出合适的档位。
4. 编写批处理循环遍历文件夹：gswin64c -sDEVICE=pdfwrite -dCompatibilityLevel=1.5 -dPDFSETTINGS=/ebook 逐个压缩。
5. 用 pypdf 或 pdfinfo 读取压缩前后页数、大小，验证页数不变、文字可复制。
6. 汇总压缩率清单，对体积仍超标的文件单独调低图片 DPI 或使用 /screen 档再压。

### 74. 批量拆分 PDF 文档，按每页、每章节生成独立小文件

**细分能力点（5 条）**

1. 支持按页拆分：每页一个文件，或每 N 页合并一个文件。
2. 支持按章节/关键字（如"第一章""结论"）定位拆分点。
3. 拆分后自动命名文件（如"原文件名_第1页.pdf"或按章节名命名）。
4. 提取拆出文件的书签目录，保证每个小文件保留对应书签。
5. 生成拆分索引表，记录每份小文件对应的页码范围，方便还原。

**可执行提示词（5 条）**

1. "把 D:\报告\年度报告.pdf 按每页一个文件拆开，文件名用『年度报告_页码』命名。"
2. "把这份 PDF 按『第一章』『第二章』……的关键字拆成独立文件，用章节名命名。"
3. "每 10 页拆成一个 PDF，输出到 D:\拆分结果\，并生成页码范围索引表。"
4. "拆分后每个小文件保留书签，方便按章跳转。"
5. "先识别 PDF 里的目录页，从目录页之后才开始拆分正文，封面和目录单独存。"

**操作步骤（6 步）**

1. 安装 Python 的 pypdf（pip install pypdf），或用 Adobe Acrobat 的"组织页面→拆分文档"功能。
2. 先读取 PDF 总页数，确认拆分方式：按页 / 按章节 / 按页码范围。
3. 按页拆分：用 pypdf 的 PdfWriter 依次把每页写入独立文件，命名中加页码。
4. 按章节拆分：用 pdfplumber 读取每页文本，检测到章节关键字即作为新文件起点。
5. 用 outline 属性读取书签，把对应书签写入拆出的文件，并生成"文件名-页码范围"索引表。
6. 抽查拆分结果的页数与内容完整性，确认无误后对全部文件执行。

### 99. 批量替换文档内旧公司名称、联系方式，统一更新信息

**细分能力点（5 条）**

1. 批量在 Word、TXT、PDF、Excel 中查找并替换旧公司名称、电话、邮箱。
2. 支持"旧值→新值"映射表，一次处理多组信息。
3. 支持区分大小写、全半角转换，支持通配符或正则匹配。
4. 替换后生成差异报告，列出每处替换的位置、原值、新值。
5. 自动备份原文件，替换过程不影响文档格式与版式。

**可执行提示词（5 条）**

1. "把 D:\合同\ 下所有 Word 文档里『旧公司名』全部替换成『新公司名』，旧电话也换成新电话。"
2. "批量替换 D:\资料\ 里全部文档：公司名、联系电话、邮箱、地址四项统一更新。"
3. "替换时忽略大小写，并把全角数字转半角后再匹配。"
4. "替换前把原文件备份到 D:\备份\，替换后给我一份改动清单，包含位置和原值新值。"
5. "只替换正文，不要动页眉页脚里的公司名，页眉页脚单独处理。"

**操作步骤（6 步）**

1. 用 python-docx 编写替换脚本，遍历 docx 的段落与表格单元格执行 text.replace。
2. 用 openpyxl 处理 Excel，遍历单元格按映射表替换并保持格式。
3. 处理 PDF：文字版用 pdfplumber 抽取后重建，或用 Acrobat 的"编辑→查找和替换"。
4. 建立"旧值-新值"映射表（公司名、电话、邮箱、地址），用字典统一管理。
5. 替换时对每处改动记录所在文件、段落、原值新值，生成差异报告。
6. 用正则处理全半角与大小写变体，全量替换后抽查 5 个文件确认无遗漏。
