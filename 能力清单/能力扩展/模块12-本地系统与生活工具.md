### 16. 搭建一个本地的管理系统：如库存管理系统，家庭图书管理系统。

**细分能力点（5 条）**

1. 用 SQLite 数据库存储条目，本地零配置、数据不出本机。
2. 支持增删改查：录入、修改、删除、按关键词/分类检索。
3. 库存管理：记录商品名称、数量、单价、入库/出库时间、供应商、预警阈值。
4. 家庭图书管理：记录书名、作者、ISBN、分类、书架位置、借出状态。
5. 用 Streamlit 或 Flask 做可视化界面，配 Excel 导入导出和 CSV 备份。

**可执行提示词（5 条）**

1. "帮我搭建一个家庭图书管理系统：能录入书名、作者、ISBN、分类、书架位置、借出状态，装好直接能用，放在 D:\family-library 目录。"
2. "给库存管理系统加个功能：当某商品数量低于设定的预警阈值时，在首页用红色高亮提醒我补货。"
3. "把 D:\books.csv 里的图书数据批量导入管理系统，遇到重复 ISBN 就更新不新增。"
4. "为库存系统增加『出库』操作，选择商品后输入数量，自动扣减库存并记录出库时间和用途。"
5. "给系统加一个按分类统计的图表，统计各分类图书数量和各商品库存金额占比。"

**操作步骤（7 步）**

1. 向 Workbuddy 发送指令：「帮我搭建一个本地家庭图书管理系统，能录入书名、作者、ISBN、分类、书架位置、借出状态，放到 D:\family-library。」
2. Workbuddy 会确认界面形式（网页/桌面）、是否需要搜索和 Excel 导入导出，你按需补充（如"要有搜索框和导入导出功能"）。
3. 确认后，Workbuddy 自动把系统搭建好并启动，你无需安装任何软件或写脚本，打开就能用。
4. 开始录入：把现有图书信息整理成表格发给 Workbuddy（或指给它 D:\books.csv），由它批量导入。
5. 检查列表和首页：字段、搜索、编辑、删除是否正常，有问题直接告诉 Workbuddy 调整。
6. 需要更多功能时直接说：加低库存红色提醒、按分类统计图表、导出备份等，Workbuddy 会自动改好。
7. 想让数据更安全，让 Workbuddy 配置每日自动备份到指定目录，长期放心使用。

### 32. 解析快递单号，批量查询物流状态，生成物流汇总表。

**细分能力点（5 条）**

1. 自动识别快递公司（顺丰、中通、圆通、韵达、申通、京东等），用单号前缀/正则规则判断。
2. 批量导入单号：支持 Excel/CSV/文本粘贴，自动去重和校验格式。
3. 调用快递查询 API（快递100、快递鸟等）获取物流轨迹和最新状态。
4. 自动归类状态：已签收、运输中、待揽收、异常，异常件单独标记。
5. 生成物流汇总表 Excel，包含单号、公司、状态、最近更新时间、备注。

**可执行提示词（5 条）**

1. "帮我识别这串快递单号属于哪家快递公司，并查询最新物流状态：SF1234567890123。"
2. "批量查询 D:\物流单号.xlsx 里所有快递单号的状态，生成汇总表 D:\物流汇总.xlsx，按状态分类排序。"
3. "把 Excel 里单号为空、格式不对的重复行先清理掉，再去批量查询。"
4. "给查询加个功能：把超过 48 小时没有新物流信息的单号标黄，签收的标绿，异常的标红。"
5. "设置每天早晚各查一次所有在途单号，有状态变化就汇总发我一份邮件。"

**操作步骤（6 步）**

1. 准备单号：把要查询的快递单号整理到 D:\物流单号.xlsx，或直接粘贴给 Workbuddy。
2. 发送指令：「帮我把这批快递单号批量查询物流状态，自动识别快递公司，生成物流汇总表 Excel。」
3. Workbuddy 会确认输出格式：列名、保存路径、是否按状态分类，你按需补充（如"保存到 D:\物流汇总.xlsx，异常件单独列出"）。
4. 确认后，Workbuddy 自动完成识别、去重校验、逐单查询并生成汇总表，无需注册接口或写脚本。
5. 打开汇总表检查：单号、公司、状态是否准确，异常件是否已标红并单独列清单。
6. 后续管理：告诉 Workbuddy「每天早上 9 点查一次在途单号，有变化发我邮件」，即可长期自动跟进。

### 44. 搭建本地小型影音库，自动整理电影、剧集，生成封面目录。

**细分能力点（5 条）**

1. 扫描本地文件夹，按文件名识别电影/剧集名称与季集信息。
2. 调用 TMDB 或豆瓣 API 自动匹配影片信息（片名、年份、简介、评分）。
3. 自动下载并缓存封面海报图，按影片规范重命名。
4. 用 Jellyfin/Plex 或自建 Web 界面生成可视化封面目录（海报墙）。
5. 支持按类型/评分/年份筛选，自动归档未识别和重复文件。

**可执行提示词（5 条）**

1. "扫描 D:\movies 和 D:\tvshows 文件夹，自动识别文件名中的电影/剧集标题，匹配影片信息并下载封面。"
2. "把识别失败、文件名杂乱的视频挑出来，整理成清单让我手动重命名。"
3. "为影音库生成一个网页封面墙，按年份和评分排序，点击封面能打开对应视频。"
4. "帮我把同名的多版本视频（1080p、720p）去重，只保留画质最好的一个。"
5. "帮我搭建一个本地影音库：把整理好的电影剧集自动整理成封面海报墙，支持按类型/评分筛选，并配好字幕下载。"

**操作步骤（7 步）**

1. 把电影、剧集分别放进 D:\movies 和 D:\tvshows 文件夹。
2. 发送指令：「帮我搭建一个本地影音库，扫描这两个文件夹，自动识别片名、匹配影片信息、下载封面，生成海报墙。」
3. Workbuddy 会确认媒体库规则：电影/剧集是否分开、命名规范、是否需要字幕下载，你按需补充。
4. 确认后，Workbuddy 自动完成扫描、识别、匹配、下载封面并生成网页封面墙，无需安装服务器或写脚本。
5. 打开封面墙检查：片名、年份、评分是否正确，识别失败的视频已单独列出清单。
6. 对识别失败的文件，按清单手动改名后让 Workbuddy 重扫，或直接让它批量修正。
7. 后续管理：让 Workbuddy 定期扫描新增视频、自动去重、更新封面墙，影音库长期自动维护。

### 60. 搭建本地食谱管理工具，录入食材自动匹配可做菜品。

**细分能力点（5 条）**

1. 录入菜品数据：菜名、所需食材、用量、步骤、分类（家常/烘焙/汤羹）。
2. 记录冰箱/厨房现有食材及数量、保质期。
3. 根据现有食材自动匹配可做菜品，支持缺料提示（还差什么）。
4. 支持多食材组合查询（给定 2-3 种食材找能做的菜）。
5. 生成每日菜单建议和采购清单（缺哪些食材一键列出）。

**可执行提示词（5 条）**

1. "帮我搭建一个食谱管理工具：录入菜名、食材、用量、做法步骤、所需时间，装好直接能用。"
2. "我冰箱里有鸡蛋、番茄、土豆、猪肉、豆腐，帮我匹配出所有能做的菜，缺的食材标出来。"
3. "新增一道菜『可乐鸡翅』：食材为鸡翅 500g、可乐一罐、生抽、姜、料酒，做法两步煎后焖。"
4. "根据本周菜单自动生成采购清单，把重复食材合并，按超市分区排序。"
5. "按今天食材推荐 3 道菜搭配成一餐，优先用临期的食材。"

**操作步骤（7 步）**

1. 发送指令：「帮我搭建一个本地食谱管理工具，能录入菜谱、记录冰箱现有食材，根据现有食材自动匹配能做的菜。」
2. Workbuddy 会确认录入字段和界面形式，你按需补充（如"要能按分类筛选、支持上传菜品图片"）。
3. 确认后，Workbuddy 自动搭建好并启动，你直接录入，或把现有菜谱表格发给它批量导入。
4. 把常用菜谱逐条（或整理成表格）交给 Workbuddy 录入，它会自动填好。
5. 把冰箱现有食材告诉 Workbuddy（如"鸡蛋 6 个、番茄 3 个、土豆 5 个"），它更新食材清单并给出可做菜品和缺料清单。
6. 检查匹配结果：可做与缺料标注是否准确，让 Workbuddy 调整匹配规则。
7. 后续管理：让 Workbuddy 每日按现有食材推荐菜单、生成采购清单 Excel，按着买菜即可。

5. "把游戏时长和周报数据导出到 Excel，存到 D:\娱乐时长报表。"

**操作步骤（6 步）**

4. 查看生成的月报：总时长、日均、玩得最多的游戏、时段分布是否准确，有问题让它修正。
5. 让 Workbuddy 加规则：「设置每日游戏上限 2 小时，超时弹窗提醒我」。
6. 设置定时：每周日生成周报、每月 1 号生成月报并存到 D:\娱乐时长报表，长期自动统计。

### 76. 批量转换电子书格式，EPUB、MOBI、TXT 互相转换。

**细分能力点（5 条）**

1. 批量处理文件夹内所有电子书，自动识别原格式。
2. EPUB、MOBI、TXT、PDF 之间的互相转换（TXT 生成带目录的 EPUB）。
3. 保留封面、目录、章节结构，转 EPUB 时自动生成 TOC。
4. 转换前自动清理乱码、修复换行（TXT 常见问题）。
5. 转换后按格式分类归档到新目录，生成转换日志。

**可执行提示词（5 条）**

1. "把 D:\books\txt 文件夹里所有 TXT 转成 EPUB，自动切分章节并生成目录，输出到 D:\books\epub。"
2. "把 D:\books\epub 里的书批量转成 MOBI，保留封面和目录，方便放进 Kindle。"
3. "这个 TXT 文件里有乱码和多余空行，帮我清理后再转成 EPUB。"
4. "批量转换 D:\ebooks 下所有电子书，转成 EPUB，转换失败的单独列个清单。"
5. "转完的电子书按作者建文件夹归档，并生成一份转换日志。"

**操作步骤（7 步）**

1. 把待转换的电子书按格式整理到 D:\books\ 对应文件夹（如 txt、epub）。
2. 发送指令：「把 D:\books\txt 里所有 TXT 转成 EPUB，自动切分章节、生成目录，输出到 D:\books\epub。」
3. Workbuddy 会确认转换参数：输出格式、是否保留封面目录、乱码如何处理，你按需补充。
4. 确认后，Workbuddy 自动完成转换、清理乱码、校验成品，无需安装转换软件或写脚本。
5. 检查转换结果：封面、目录、章节是否完整，失败的已单独列出清单。
6. 对失败的文件，让 Workbuddy 调整规则重试，或按清单人工处理。
7. 让 Workbuddy 按作者建文件夹归档并生成转换日志，方便日后查找。

### 98. 搭建本地绿植养护台账，记录浇水施肥周期定时提醒。
