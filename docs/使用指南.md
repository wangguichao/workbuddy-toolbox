# 使用指南

本文档说明如何高效地使用本项目，把「清单」变成你手上真正能跑起来的自动化。

## 一、如何找到你需要的能力

1. 打开 [分类总览](分类总览.md)，浏览 14 大主题，找到关心的一类事务。
2. 如果不确定主题，直接看 [能力清单/分类整理.md](../能力清单/分类整理.md)，100 条能力都有编号和一句话描述。
3. 记下编号，到 [能力清单/能力扩展](../能力清单/能力扩展/) 打开对应模块文件，找到该编号的章节。

## 二、三种落地方式

### 方式 A：让 AI 直接执行（最快）

每个能力章节里都有 5 条**可执行提示词**，直接复制粘贴给 Workbuddy / Claude 桌面应用等 AI 助手即可。

例如，想要基金简报，直接对 AI 说：

> "设置每天 14:30 定时任务，抓取我持仓基金的当日净值，整合前 1/5/10 天价格生成简报，通过邮件发送给我。"

提示词里已含具体参数，AI 会接手后续步骤。落地后，把成功的提示词反馈回本项目（见[贡献](../CONTRIBUTING.md)），帮助更多人。

### 方式 B：按步骤自行搭建（可控）

每个能力章节都有 5~10 步**操作步骤**，落到了具体工具与库：

- 用到的 Python 库（如 pandas、openpyxl、requests、Pillow、ffmpeg 等）
- 软件（Excel、WPS、剪映、7-Zip 等）
- Windows 系统操作（环境变量、任务计划程序、注册表等）

按步骤执行即可在本地搭建出可复用的脚本或流程。

### 方式 C：组合成流水线

很多能力可以串联成完整流程，例如：

- 发票识别（14）→ 报销汇总（71）
- 图片统一尺寸（9）→ 添加品牌水印（70）
- 爬取行情数据（22）→ 表格清洗（59）→ 生成日报（24）
- 录音转文字（65）→ 会议纪要提炼（65）

## 三、落地优先级建议

- **高频、见效快**：表格处理（03）、图片处理（04）、财务记账（06）类，通常一次搭建、长期复用。
- **需外部授权**：简历投递（08）、邮件自动回复（07）、网盘同步（13）等，需要你提供对应平台的账号权限或接入方式。
- **涉及数据合规**：爬虫、价格监控（10）等，务必遵守目标网站条款与频率限制，建议控制请求频率并人工复核结果。
- **破坏性操作**：文件删除、加密、批量替换（13）类，务必先备份再执行。

## 四、如何扩展与维护

- 想新增能力或完善现有条目？阅读 [扩展模板](扩展模板.md) 与 [贡献指南](../CONTRIBUTING.md)。
- 项目完全离线可用，纯 Markdown，可直接放在本地、同步到云盘，或托管到 GitHub。

## 五、常见问题

**Q：我不会写代码，能用吗？**
可以。优先用「方式 A」让 AI 执行；AI 会根据提示词帮你完成代码与配置。

**Q：提示词执行失败了怎么办？**
把 AI 的报错信息、你的文件/数据情况一起发给它，让它调整方案；也可以在项目里提 Issue 反馈。

**Q：操作步骤里的工具没装怎么办？**
按步骤安装即可（多为 `pip install xxx`），或直接让 AI 帮你装。
