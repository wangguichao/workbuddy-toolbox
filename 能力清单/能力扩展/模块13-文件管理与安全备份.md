### 21. 批量重命名本地上千份文档，统一规范命名格式

**细分能力点（5 条）**

1. 支持按规则批量重命名：前缀/后缀、日期、序号、原文件名保留等任意组合。
2. 支持 Excel 清单驱动重命名：读取"原名—新名"两列批量生效，适合人工整理的映射表。
3. 重命名前自动预览全部改动，重名冲突自动检测、跳过或追加序号。
4. 支持正则表达式匹配旧文件名并替换，适合清理版本号、乱码等杂乱命名。
5. 每次重命名记录写入日志文件，可一键撤销/回滚到原文件名。

**可执行提示词（5 条）**

1. "把 D:\文档\ 下所有 Word 文档统一改成『项目A_2026_序号_原文件名』格式，先给我预览列表，确认无误再执行。"
2. "读取 E:\重命名清单.xlsx 的 A 列（旧文件名）和 B 列（新文件名），批量重命名 D:\文档\ 里的文件，出错的列出来。"
3. "把 D:\文档\ 下所有文件名中的中文括号『（）』改成英文括号，空格改成下划线，先预览命中项再执行。"
4. "给 D:\文档\ 下所有 PDF 文件加上当天日期前缀 20260819_，重名的自动加 (1)(2) 序号。"
5. "写个脚本：每周一扫描 D:\合同\ 下新增文件，按『客户名_签订日期_金额』规则自动命名，并把命名结果发给我确认。"

**操作步骤（7 步）**

1. 备份：先把 D:\文档\ 用 `robocopy D:\文档 E:\重命名前备份 /E` 复制一份，确保改坏可恢复。
2. 安装 Python，`os.listdir()` 或 `os.scandir()` 列出目录下所有文件名，导出到 Excel 或直接打印预览。
3. 定义命名规则，用字符串拼接或 `re.sub()` 正则构造新文件名，保留文件扩展名。
4. 处理重名冲突：执行前用 `os.path.exists()` 判断目标是否存在，存在则自动追加 `_1`、`_2` 序号。
5. 先跑 dry-run：只打印"旧名 → 新名"对照表，人工核对命名规则是否符合预期。
6. 用 `os.rename()` 正式执行，套 try/except 捕获权限不足或文件占用等异常，失败项记录到日志。
7. 把每次改动的"原路径→新路径"写入 log，另存一份 undo 脚本，需要时按日志反向 `os.rename()` 回滚。

### 49. 批量修改文件名内敏感字符，统一替换违规关键词

**细分能力点（5 条）**

1. 批量扫描文件与文件夹名称中的敏感关键词，支持按目录递归遍历。
2. 支持敏感词清单（txt/Excel，每行一个词）批量自动匹配与替换。
3. 匹配时忽略英文大小写差异，防止漏改（如 password/PASSWORD）。
4. 用正则识别身份证号、手机号、银行卡号等模式，做脱敏处理。
5. 替换前高亮预览所有命中项，替换后输出"原名—新名—替换词"对照报告。

**可执行提示词（5 条）**

1. "扫描 D:\共享\ 下所有文件名和文件夹名，把『工资表』『绩效』『身份证』替换成『薪资表』『考核』等合规词，先列出全部命中文件让我确认。"
2. "读取 E:\敏感词表.txt 里的关键词，在 D:\资料\ 整个目录（含子文件夹）的文件名中脱敏替换，替换前先备份目录。"
3. "把文件名里出现的 11 位手机号（1 开头）用正则替换成 138****0000 这种脱敏格式，批量执行前先预览结果。"
4. "查找 D:\共享盘\ 文件名中出现的连续 18 位数字（身份证号），统一替换为 XXXX，并输出一份替换对照表。"
5. "设置监控脚本：检测到公司共享盘新增文件名含敏感词时自动改名并给我发通知，同时记录到日志。"

**操作步骤（7 步）**

1. 准备敏感词清单文件 `E:\敏感词表.txt`，每行一个词，英文统一用小写存入便于忽略大小写匹配。
2. 备份待处理目录：`robocopy D:\资料 E:\脱敏前备份 /E /R:2 /W:3`。
3. 用 Python `os.walk()` 遍历目录，收集所有文件和文件夹的相对路径与名称。
4. 匹配时统一 `name.lower()` 转小写后匹配清单中的词，命中即替换；身份证号用正则 `\d{17}[\dXx]`、手机号用 `1[3-9]\d{9}` 匹配。
5. 先 dry-run 打印全部命中项与新文件名，核对命中数量和替换规则，避免误伤。
6. 正式执行 `os.rename()`，每项记录到替换日志（原名、新名、命中的敏感词），重名冲突自动加序号。
7. 生成替换报告 Excel（openpyxl 写入：原名、新名、命中词、操作时间），抽查 10 个样本人工确认无误。

### 51. 自动同步云盘与本地文件夹，双向备份新增、修改文件

**细分能力点（5 条）**

1. 本地文件夹与云盘（百度网盘/OneDrive 等同步盘）双向自动同步。
2. 增量同步：只传输新增和修改过的文件，不重复整传，节省流量与时间。
3. 删除操作单独确认或移入回收站，防止同步机制误删文件。
4. 双向冲突（两边都改过同一文件）自动保留两个版本并标注来源。
5. 同步日志可追溯，同步失败自动重试并发出告警。

**可执行提示词（5 条）**

1. "把 D:\工作\ 和百度网盘同步盘里的『工作』文件夹设为双向同步，每 5 分钟检查一次，只同步新增和修改的文件。"
2. "用 FreeFileSync 配置双向同步：源目录 D:\工作，目标目录 D:\云盘同步\工作，冲突文件保留两个版本，先做一次试运行给我看结果。"
3. "写个脚本：把 C:\Users\me\Documents 用 robocopy /MIR 单向备份到 E:\备份，先 dry-run 展示将复制/删除哪些文件。"
4. "监测 D:\项目\ 文件夹变化，发现新增或修改文件立即用 rclone 上传到 OneDrive 云端『项目备份』目录。"
5. "设置每日 18:00 自动把 D:\资料\ 双向同步到 D:\云盘同步\资料，同步完生成一份报告发我。"

**操作步骤（7 步）**

1. 选择工具：Windows 自带 `robocopy`（适合单向镜像），或安装免费的 FreeFileSync/rclone（支持双向）。
2. 安装百度网盘/OneDrive 桌面客户端并登录，开启"同步盘"模式，确定本地同步盘目录。
3. 用 FreeFileSync 新建双向同步方案：选好源与目标目录，比较方式选"文件大小+时间戳"，速度快且够准。
4. 设置冲突策略为"保留两个版本（副本_源/副本_目标）"，删除策略设为"移入回收站"，避免误删。
5. 用 Windows 任务计划程序（`schtasks` 或图形界面）绑定同步方案，设置触发时间（开机/定时/文件变更）。
6. 命令行方案：`robocopy 源 目标 /MIR /R:3 /W:5 /LOG:同步日志.txt` 配合任务计划每日运行，或用 `rclone sync` 同步到云盘。
7. 先跑一次完整同步并人工核对两边文件数一致，再观察一周日志，确认无异常删除、无重复冲突后才长期运行。

### 55. 扫描本地重复文件，一键删除重复照片、安装包、文档

**细分能力点（5 条）**

1. 按文件内容哈希（MD5/SHA1/SHA256）精确识别内容完全相同的重复文件。
2. 先按文件大小分组快速预筛，只对同大小的文件算哈希，大幅加快扫描速度。
3. 每组可指定保留策略：最早创建/最新修改/指定路径，其余标记为待删。
4. 删除前展示重复分组清单（文件路径、大小、哈希），支持逐项勾选确认。
5. 删除文件先移入回收站而非直接永久删除，可随时恢复。

**可执行提示词（5 条）**

1. "扫描 D:\照片\ 找出内容完全相同的重复照片（按 MD5 哈希比对），列出分组清单和每组占用的空间，让我确认后再删。"
2. "扫描 D:\下载\ 里重复的安装包和文档，每组只保留最早的一个，其余移到 D:\重复文件待删\ 文件夹，先给我统计。"
3. "用 Python 写去重脚本：遍历 D:\资料\ 所有文件按大小分组，同大小的计算 SHA256，输出重复分组报告 Excel。"
4. "找出 D:\桌面 和 E:\备份 之间内容重复的文件，删除前先告诉我共有几组重复、一共能释放多少空间。"
5. "设置每月 1 日自动扫描 D:\下载\ 的重复文件，移到回收站并生成清理报告发我。"

**操作步骤（7 步）**

1. 备份关键目录：去重删除前对 D:\照片、D:\文档 用 `robocopy /E` 复制一份，重要文件宁可多备份。
2. 安装 Python，`pip install pandas`，先用 `os.path.getsize()` 按文件大小分组，过滤掉大小唯一的文件。
3. 对同大小的文件用 `hashlib.md5()` 或 `hashlib.sha256()` 分块计算（每块 1MB，`read(1024*1024)`），避免大文件占满内存。
4. 建立"哈希 → 文件路径列表"的字典，长度大于 1 的即为重复组；照片等大文件可再用 SHA256 复核 MD5 结果。
5. 确定每组保留哪一个：按"优先保留最早创建、其次最新修改"规则，把其余文件路径写入待处理清单。
6. 先输出重复报告 Excel（分组、保留文件、待删文件、可释放空间），人工核对确认保留策略无误。
7. 用 `shutil.move()` 把待删文件移到 D:\回收待处理\（或调用回收站 API），确认功能正常后清空，生成清理报告。

### 62. 自动整理电脑桌面文件，按文档、图片、安装包分类收纳

**细分能力点（5 条）**

1. 按扩展名自动分类：文档、图片、视频、安装包、压缩包、音频等。
2. 支持自定义规则：按项目名、日期（年月）、文件名关键词二次归类。
3. 目标文件夹自动创建，同名文件自动追加序号，避免覆盖。
4. 桌面快捷方式（.lnk）、正在运行程序的文件可加入排除列表保留原地。
5. 支持一键归档大文件/旧文件到冷归档目录，释放桌面空间。

**可执行提示词（5 条）**

1. "帮我整理桌面：把文件按 文档(.docx/.pdf/.txt)、图片(.jpg/.png/.gif)、安装包(.exe/.msi)、压缩包(.zip/.rar)、视频(.mp4) 分类放进桌面对应文件夹，快捷方式保留不动。"
2. "写一个 Python 脚本：每天 22:00 自动整理 C:\Users\me\Desktop，按扩展名归档到桌面对应分类文件夹，并把空文件移到回收站。"
3. "把桌面文件按最近修改日期归档到 桌面\归档\2026年8月\ 这种按月文件夹，先预览分类结果再执行。"
4. "整理桌面时把文件名含『合同』『发票』的文件单独放到 桌面\合同票据\ 文件夹，其余按类型归档。"
5. "一键整理桌面：找出超过 30 天没修改、大于 100MB 的文件，提示我是否移入 D:\冷归档\ 释放空间。"

**操作步骤（7 步）**

1. 确定分类映射：用字典维护"扩展名 → 目标文件夹"，如 `.docx/.pdf → 文档`、`.jpg/.png → 图片`、`.exe/.msi → 安装包`。
2. 用 Python `os.scandir()` 或 `glob.glob(r"C:\Users\me\Desktop\*")` 遍历桌面，跳过文件夹本身。
3. 排除 .lnk 快捷方式、桌面系统图标及白名单文件（用 `file.lower().endswith(".lnk")` 判断）。
4. 创建目标文件夹：`os.makedirs(目标路径, exist_ok=True)`，每个分类一个目录。
5. 检查重名：`os.path.exists(目标)` 为真时自动加 `_1`、`_2` 序号再移动，防止覆盖。
6. 用 `shutil.move(源, 目标)` 移动文件并记录日志；先用 dry-run 打印分类结果，人工确认映射无误。
7. 用 Windows 任务计划程序把脚本设为每天定时运行，运行一周核对分类是否正确，再调整规则。

### 80. 每日定时备份重要文档至移动硬盘与云端双备份

**细分能力点（5 条）**

1. 支持"本地 → 移动硬盘"与"本地 → 云端"双目标同时备份。

3. 每日定时自动执行，任务计划程序驱动，失败自动重试并告警。
4. 备份后自动校验：对比源与目标的文件数量、总大小，重要文件比对哈希。

2. "写一个备份脚本：把 C:\Users\me\Documents 用 robocopy /MIR /R:3 /W:5 /LOG 备份到 F:\备份\Documents，结束后对比源与目标的文件数。"
3. "帮我配置 Windows 的文件历史记录或备份功能，每日定时备份到移动硬盘 E:\ 盘。"
4. "把 D:\工作\ 每日增量同步到百度网盘同步盘和移动硬盘，移动硬盘没插上就跳过该目标并提示我。"
5. "每次备份完成后生成报告：备份文件总数、新增数、失败列表、占用空间，保存到 D:\备份报告\。"

**操作步骤（8 步）**

1. 规划备份方案：明确源目录（如 D:\重要文档）、两个目标（移动硬盘盘符 E:\、云端同步盘目录）、备份时间（每日 22:00）。
2. 用 `robocopy 源 E:\重要文档备份 /E /R:3 /W:5 /LOG:D:\备份日志\daily.log` 做增量镜像备份，`/E` 复制所有子目录、`/R` 重试次数、`/LOG` 输出日志。
3. 处理移动硬盘未连接的异常：脚本先用 `os.path.exists("E:\\")` 判断盘符是否存在，不存在则跳过该目标并提示插入。
4. 云端备份用 OneDrive/百度网盘同步盘：直接把 D:\重要文档 放进同步盘目录让其自动上传，或用 `rclone copy 源 remote:备份` 定时上传。
5. 用 Windows 任务计划程序创建每日 22:00 的定时任务，指向备份脚本或 robocopy 命令，勾选"如果任务失败则重新启动"。
6. 校验备份完整性：备份后用脚本统计源与目标的文件数、总字节数对比，重要文件（如合同 PDF）比对 MD5 哈希。
7. 保留历史版本：配合 Windows"文件历史记录"功能对 D:\重要文档 做多版本备份，或 robocopy 加 `/B` 备份模式保留权限与版本。
8. 每周人工抽查一次：从备份里随机解压/打开几个文件验证可用，每月做一次完整恢复演练（把备份复制回一个临时目录验证）。

### 95. 批量加密重要文档文件夹，设置独立访问密码

**细分能力点（5 条）**

1. 支持对文件夹整体加密（7-Zip AES-256 加密压缩，含加密文件名选项）。
2. 支持对文件夹内每个文件单独加密并设置各自独立的访问密码。
3. 自动生成高强度随机密码（大小写字母+数字+符号，16 位以上）并批量套用。
4. 生成密码清单并安全保存（Excel + 密码管理器双重存放）。
5. 加密/解密后自动校验：解压对比文件数与内容哈希，确保文件完整无损。

**可执行提示词（5 条）**

1. "用 7-Zip 把 D:\机密\ 文件夹加密成带密码的压缩包，密码用 16 位大小写字母+数字+符号随机生成，先告诉我怎么设置 7-Zip 命令行。"
2. "写个 Python 脚本：用 cryptography 库给 D:\合同\ 下每个文件单独加密，每个文件一个随机密码，密码表导出到 Excel。"
3. "把 D:\财务\ 里所有文件压缩成 财务备份_2026.zip 并加密（AES-256、加密文件名），设置密码 Abc@123456，完成后给我校验解压一遍。"
4. "批量解密：读取 E:\密码表.xlsx，把 D:\加密文件\ 下的加密压缩包用对应密码批量解压到 D:\已解密\，解压后对比文件数。"
5. "设置脚本：每月 1 日提醒我把上月新增的机密文件加入加密目录并重新加密，旧加密包移到冷备份目录。"

**操作步骤（8 步）**

1. 先备份原始文件夹：加密前用 `shutil.copytree("D:\\机密", "D:\\机密_原始备份")` 或 `robocopy /E` 复制一份，误操作可恢复。
2. 安装 7-Zip 并将其安装目录加入系统 PATH，便于命令行直接调用 `7z.exe`。
3. 用 Python `secrets` 模块批量生成高强度随机密码（如 `secrets.token_urlsafe(16)`），确保每文件/每包密码独立不重复。
4. 整体加密命令：`7z a -p密码 -mhe=on -tzip D:\加密文件\机密.zip D:\机密\*`（`-mhe=on` 加密文件名，AES-256 默认启用），多文件可写循环。
5. 逐文件加密方案：用 `cryptography` 库的 Fernet 对称加密读取每个文件字节后写入 `.enc` 文件，原文件可加 `.bak` 后缀保留。
6. 生成密码表：openpyxl 写入"文件名、密码、加密时间、备注"四列，保存为 `E:\密码表.xlsx`，并同步导入 Bitwarden/Keepass 等密码管理器，密码表单独加密保存。
7. 删除原始文件前先校验：用 `7z t -p密码` 测试压缩包完整性，或用密码表逐文件解密比对 MD5 哈希，确认无误再清空原文件。
8. 安全保管密码表：本地加密一份、云端（密码管理器）一份、打印纸本一份放安全处，定期测试解密流程，防止忘密码导致数据永久不可读。
