### 24. 生成视频文案并制作 srt 文件，添加到剪映对应的草稿。

**细分能力点（5 条）**

1. 根据主题、目标时长和口播风格生成短视频文案，输出适合口语化的分句文本。
2. 将文案按语义停顿、每行不超过 14 字的安全规则自动切分成字幕句。
3. 生成标准 SRT 格式文件（序号、时间轴、字幕文本），支持中英双语与 UTF-8 编码。
4. 按字数与语速自动估算每句起止时间，使时间轴与视频时长匹配。
5. 支持批量：对文件夹内多个视频逐一生成同名 SRT，并挂载进剪映草稿目录。

**可执行提示词（5 条）**

1. "帮我写一条 30 秒短视频口播文案，主题是『家用咖啡机推荐』，语气轻松带货风，总字数控制在 90 字内，分成 6 句。"
2. "把这段文案按每行不超过 14 个字切分成字幕句，生成标准 SRT 字幕文件，保存到 D:\视频\文案\coffee.srt。"
3. "按每秒 3.5 字估算语速，核算这段 92 字文案的字幕总时长是否与 32 秒匹配，不对就自动调整每句时间轴。"
4. "把 D:\视频\素材\ 下所有 mp4 视频逐一生成同名 SRT 字幕文件，输出到各视频同目录。"
5. "每周一 09:00 自动扫描 D:\视频\新文案\ 里的新视频，生成配套 SRT 字幕并同步到剪映草稿，完成后通知我。"

**操作步骤（7 步）**

1. 把要配字幕的视频和文案分别放到 D:\视频\素材\、D:\视频\文案\ 文件夹。
2. 向 Workbuddy 发送指令：「帮我把 D:\视频\素材\ 下的视频配上字幕，文案在 D:\视频\文案\，生成 SRT 并导入剪映草稿。」
3. Workbuddy 会确认切分与时间轴参数：每行字数上限、语速、视频总时长、剪映草稿项目名，按需补充（如"每行不超 14 字，语速每秒 3.5 字，草稿『咖啡评测』"）。
4. 确认后，Workbuddy 自动完成文案切分、时间轴估算、SRT 生成，并挂载进剪映对应草稿，你无需手动搭建环境。
5. 打开剪映检查字幕与画面是否同步，错位或切分不当的地方直接指出来。
6. Workbuddy 根据你的反馈微调首句偏移或重切个别字幕句。
7. 后续管理：告诉 Workbuddy「每周一自动把新视频按同样规则配字幕并导入剪映，完成后通知我」，即可定时运行。

### 25. 裁剪视频批量去除黑边，统一分辨率 1080P，压缩文件体积。

**细分能力点（5 条）**

1. 用 cropdetect 自动检测视频四周黑边位置，计算出有效画面区域。
2. 用 crop 滤镜批量裁剪顶、底、左、右黑边，保持画面内容不失真。
3. 统一缩放到 1920×1080（1080P），支持等比缩放居中裁剪或模糊底填充两种方式。
4. 用 H.264/H.265 编码 + CRF 参数压缩体积，兼顾画质与文件大小。
5. 输出到独立目录并保留原文件名，生成每个文件处理前后分辨率与体积的对照表。

**可执行提示词（5 条）**

1. "把 D:\视频\原片\ 下所有视频批量去掉四周黑边，只保留有效画面，输出到 D:\视频\处理结果\。"
2. "去黑边后统一缩放为 1920×1080 分辨率，用等比缩放居中裁切的方式，保证画面不变形。"
3. "处理这批视频时压缩文件体积，目标单个不超过 200MB，画质优先，实在超标再适当降低画质。"
4. "对黑边位置不均匀的视频，先逐段分析有效画面范围，再按各自参数裁剪，避免误裁主体。"
5. "全部处理完，生成一份每个视频处理前后分辨率与体积的对照表，和结果一起放到 D:\视频\处理结果\。"

**操作步骤（7 步）**

1. 把需要处理的视频统一放到 D:\视频\原片\ 文件夹。
2. 向 Workbuddy 发送指令：「把 D:\视频\原片\ 里的视频去掉黑边、统一成 1080P，再压缩体积。」
3. Workbuddy 会确认输出要求：分辨率方案（等比裁剪还是模糊底填充）、体积上限、输出目录，按需补充（如"等比居中裁切，单文件不超 200MB，结果放处理结果目录"）。
4. 确认后，Workbuddy 自动逐段检测黑边、裁剪、缩放、压缩，你无需手动安装或写脚本。
5. 打开处理结果抽查几个视频，检查是否误裁主体、分辨率是否达标。
6. 发现个别黑边检测不准的，把文件名告诉 Workbuddy，让它按该段画面单独重新裁剪。
7. 后续管理：告诉 Workbuddy「每周日 20:00 自动处理 D:\视频\新素材\ 里的新增视频」，即可按同一套规则运行。

### 26. 抓取本地音乐文件，自动补齐缺失歌手、专辑、封面信息。

**细分能力点（5 条）**

1. 扫描本地音乐目录，识别 MP3/FLAC/M4A 等格式并解析现有 ID3/元数据标签。
2. 通过音频指纹（Chromaprint/AcoustID）或文件名匹配在线数据库补全歌手、专辑、标题。
3. 从 MusicBrainz / Cover Art Archive 下载并嵌入专辑封面图。
4. 自动修正乱码标签（常见 GBK/UTF-8 编码错乱），统一为 ID3v2.3 UTF-8 规范。
5. 批量生成元数据修复报告，列出已补齐与未命中的文件，方便人工兜底。

**可执行提示词（5 条）**

1. "扫描 D:\音乐\ 下所有音乐文件，列出缺失歌手、专辑、封面信息的文件清单。"
2. "识别 D:\音乐\ 里标记为『未知歌手』的歌曲，联网补齐歌手、专辑、曲名并写回文件标签。"
3. "给 D:\音乐\ 下所有音乐自动匹配专辑封面，找不到封面的单独标记出来。"
4. "修复这批音乐文件的乱码标签，把歌手、专辑、歌名显示成正常中文，避免出现问号。"
5. "处理完把每首歌的歌手、专辑、封面补齐情况整理成 Excel 表格发我。"

**操作步骤（7 步）**

1. 把音乐文件统一放到 D:\音乐\ 目录。
2. 向 Workbuddy 发送指令：「扫描 D:\音乐\，把缺歌手、专辑、封面的歌列出来。」
3. Workbuddy 扫描后给出缺失清单，并询问处理方式，比如是否联网匹配、是否下载封面。
4. 用户确认：「联网补齐，封面自动下载嵌入，乱码标签一起修好，完成后发我 Excel 汇总。」
5. Workbuddy 自动完成识别、补全、写入标签、下载封面，你无需安装任何软件。
6. 打开汇总表检查未命中的文件，对重名歌、Live 版、Remix 等告诉 Workbuddy 手动指定信息。
7. 后续管理：新增音乐时直接让 Workbuddy「把新加的歌也按同样规则补齐」。

### 27. 批量转换音频格式，MP3/WAV/M4A 互转，统一音量大小。

**细分能力点（5 条）**

1. 支持 MP3、WAV、M4A、FLAC、OGG 等常见格式互相转换，按需指定采样率、位深、码率。
2. 转换时保留声道布局（单/双声道），音质损失可控。
3. 用 EBU R128 标准（loudnorm）统一音量，让不同来源文件的听感一致。
4. 支持整个文件夹递归批量转换，输出时保留相对目录结构。
5. 输出处理日志与每个文件转换前后格式、体积、响度对照。

**可执行提示词（5 条）**

1. "把 D:\音频\原文件\ 下所有 WAV 批量转成 320kbps MP3，输出到 D:\音频\MP3\。"
2. "把文件夹里所有 M4A 转成无损 WAV（44.1kHz / 16bit），供剪映编辑使用。"
3. "统一这批音频的音量，让不同来源的歌曲听起来响度一致，批量处理。"
4. "转换时把文件名改成『歌手-歌名』格式，重名自动追加序号避免覆盖。"
5. "转完后把每个文件转换前后的格式、体积、响度整理成表格发我。"

**操作步骤（6 步）**

1. 把需要转换的音频放到 D:\音频\原文件\ 文件夹。
2. 向 Workbuddy 发送指令：「把 D:\音频\原文件\ 下的 WAV 全部转成 320kbps MP3，音量统一，输出到 MP3 文件夹。」
3. Workbuddy 会确认参数：目标格式与码率、音量统一标准、文件名规则、输出目录，按需补充。
4. 确认后，Workbuddy 自动完成格式转换、音量统一、重命名与归档，你无需手动配置环境。
5. 抽查转换结果，试听确认音量和音质正常，有问题的让 Workbuddy 重新处理。
6. 后续管理：告诉 Workbuddy「每周三自动把新增音频按同样规则转换并统一音量」。

### 28. 自动拆分长音频，按停顿分割成独立片段并批量命名。

**细分能力点（5 条）**

1. 用 silencedetect 检测长音频中的静音段，按停顿位置自动切分。
2. 支持设置静音阈值（如 -30dB）、最小时长（如 1 秒）等参数控制切分粒度。
3. 切分后按时间戳自动命名（如 片段_0001_00h05m12s.mp3），方便回查。
4. 可配合 ASR 识别每段首句文字，生成内容索引清单。
5. 过滤过短片段与纯静音段，去除片头片尾无效内容。

**可执行提示词（5 条）**

1. "把 D:\录音\讲座.wav 按停顿自动拆分，停顿超过 1 秒的地方断开，每段单独保存。"
2. "把这段 2 小时讲座音频按停顿拆成小段，每段导出为 128kbps MP3。"
3. "拆分后按『片段序号_起始时间』批量重命名，如 片段_0001_00h05m12s.mp3。"
4. "拆分前先识别每句语音内容，再按话题停顿切分，把切分点列表发我确认。"
5. "拆完后把每段的时长和首句文字生成索引清单，保存到 D:\录音\拆分\。"

**操作步骤（7 步）**

1. 把长音频放到 D:\录音\ 目录。
2. 向 Workbuddy 发送指令：「把 D:\录音\讲座.wav 按停顿超过 1 秒的地方拆分成小段，每段导出为 MP3。」
3. Workbuddy 会确认切分粒度：停顿判定时长、最短保留时长、是否跳过片头片尾无效内容，按需补充（如"太短的片段去掉"）。
4. 确认后，Workbuddy 自动检测停顿、切分、过滤短片段、按时间戳命名，你无需手动搭建。
5. 抽查几段开头结尾是否裁切自然，不合适的让 Workbuddy 重新切。
6. 需要内容索引时，让 Workbuddy「识别每段首句文字，生成索引清单」。
7. 后续管理：告诉 Workbuddy「每周自动拆分新增录音并更新索引」。

### 29. 批量截取视频关键帧，导出高清产品展示图片素材。

**细分能力点（5 条）**

1. 从视频中按固定间隔或场景变化自动抽取关键帧。

3. 导出 JPG/PNG 高清图，可指定宽度与画质（如 JPG q:v 2）。
4. 按"视频名-时间戳-帧序号"批量命名，便于对照回查。
5. 抽取后自动剔除模糊帧与重复帧，只保留清晰且构图不同的画面。

**可执行提示词（5 条）**

1. "从 D:\视频\产品\ 下每个视频每 5 秒抽一帧，导出宽 1920 的高清 JPG。"
2. "用场景变化检测方式抽取画面变化明显的关键帧，阈值 0.4，保存成 PNG。"
3. "批量抽取 D:\产品视频\ 全部视频的关键帧，作为电商主图素材，命名带时间戳。"
4. "抽取后自动剔除模糊帧和几乎相同的重复帧，每个视频最多保留 20 张。"
5. "把抽出的关键帧按商品名建子文件夹归档，并生成图片清单表格。"

**操作步骤（7 步）**

1. 把产品视频放到 D:\产品视频\ 文件夹。
2. 向 Workbuddy 发送指令：「抽取 D:\产品视频\ 里每个视频的关键帧，每 5 秒一张，1920 宽高清 JPG，按商品名归档。」
3. Workbuddy 会确认抽帧方式：按固定间隔还是场景变化，输出画质与命名规则，按需补充。
4. 确认后，Workbuddy 自动抽帧、剔除模糊帧与重复帧、按商品归档，你无需手动安装软件。
5. 打开归档目录浏览图片，把不满意的挑出来让 Workbuddy 重新抽。
6. 需要补图时，直接让 Workbuddy「额外抽取某个时间点附近的关键帧」。
7. 后续管理：告诉 Workbuddy「每次新增产品视频按同样规则自动抽帧并归档」。

### 30. 批量提取视频音频，分离音轨保存为独立音频文件。

3. 可选无损提取（-c copy 不重新编码）或转码为 MP3/WAV/M4A。
4. 批量处理整个文件夹，输出到独立目录并保留原文件名。
5. 支持单独导出某一声道（如左声道、右声道分离）。

**可执行提示词（5 条）**

1. "把 D:\视频\ 下所有 MP4 的音轨提取出来，保存为 320kbps MP3 到 D:\音频\提取\。"

3. "把这段视频的音频直接用不转码的方式抽出来，保存为 m4a，保持原音质。"
4. "把这段视频的左声道和右声道分别导出成两个独立音频文件。"
5. "提取完把每个视频的音频时长、码率、声道数汇总成表格发我。"

**操作步骤（6 步）**

1. 把视频放到 D:\视频\ 文件夹。
2. 向 Workbuddy 发送指令：「把 D:\视频\ 下所有 MP4 的音轨提取出来，转成 320kbps MP3，存到 D:\音频\提取\。」
3. Workbuddy 会确认提取方式：是否转码、多音轨怎么命名、是否保留原文件，按需补充。
4. 确认后，Workbuddy 自动提取、转码、按语言命名、归档，你无需手动操作。
5. 抽查几个音频确认音质、时长、声道数正常，有问题的让 Workbuddy 重新处理。
6. 后续管理：告诉 Workbuddy「新增视频后按同样规则自动提取音轨」。

### 31. 读取监控摄像头录像，自动标记移动画面截取片段。

**细分能力点（5 条）**

1. 用背景减除（MOG2）或帧差法检测画面中的运动区域。
2. 标记运动事件起止时间，自动截取包含移动画面的视频片段。
3. 按运动面积、持续时间过滤误报（光线变化、树叶晃动、飞虫）。
4. 在截取片段上叠加时间戳水印，便于取证回查。
5. 批量处理多路/多日录像，生成事件日志与缩略图预览。

**可执行提示词（5 条）**

1. "分析 D:\监控\ 下今天的录像，检测画面里有人/车移动的时间段，输出事件时间表。"
