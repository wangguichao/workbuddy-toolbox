# 文件管理与安全备份（模块 13）
该模块把以下能力扩展为可直接发送给 Workbuddy 的提示词与对话式操作步骤。原始条数 7，共 105~140 个扩展条目。

### 21. 批量重命名本地上千份文档，统一规范命名格式

**细分能力点（5 条）**

1. 支持按规则批量重命名：前缀/后缀、日期、序号、原文件名保留等任意组合。
2. 支持 Excel 清单驱动重命名：读取"原名—新名"两列批量生效，适合人工整理的映射表。
3. 重命名前自动预览全部改动，重名冲突自动检测、跳过或追加序号。
4. 支持正则表达式匹配旧文件名并替换，适合清理版本号、乱码等杂乱命名。
5. 每次重命名记录写入日志文件，可一键撤销/回滚到原文件名。

**可执行提示词（5 条）**

1. "把 D:\文档\ 下所有 Word 文档统一重命名为『项目A_2026_序号_原文件名』，先预览全部改动，确认后再执行。"
2. "读取 E:\重命名清单.xlsx 里旧名/新名两列，批量重命名 D:\文档\ 里的文件，完成后列出失败项。"
3. "把 D:\文档\ 文件名里的中文括号『（）』改成英文括号、空格改成下划线，先列出命中项确认再改。"
4. "给 D:\文档\ 下所有 PDF 加上当天日期前缀 20260819_，重名的自动追加 (1)(2) 序号，改完给我一份对照表。"
5. "每周一自动扫描 D:\合同\ 下新增文件，按『客户名_签订日期_金额』规则命名，改完发我确认清单。"

**操作步骤（6 步）**

1. 备份：先向 Workbuddy 说「把 D:\文档\ 备份一份到 E:\重命名前备份，防止改坏」，Workbuddy 自动完成备份并告知结果。
2. 发送指令：「帮我把 D:\文档\ 下所有 Word 文档按『项目A_2026_序号_原文件名』统一重命名。」
3. Workbuddy 会确认命名规则和范围，如「序号从几开始、是否保留原文件名」，你按需补充（如"序号从 001 开始"）。
4. Workbuddy 自动生成"旧名 → 新名"对照表预览，你核对规则无误后回复"确认执行"。
5. Workbuddy 自动完成全部重命名，重名自动加序号，并把失败项和完整对照表发给你。
6. 你检查结果；想回滚就说「把刚才的重命名全部撤销」，Workbuddy 按日志恢复；想定时就说「每周一自动扫描 D:\合同\ 新增文件按『客户名_签订日期_金额』命名，改完发我确认」。

### 49. 批量修改文件名内敏感字符，统一替换违规关键词

**细分能力点（5 条）**

1. 批量扫描文件与文件夹名称中的敏感关键词，支持按目录递归遍历。
2. 支持敏感词清单（txt/Excel，每行一个词）批量自动匹配与替换。
3. 匹配时忽略英文大小写差异，防止漏改（如 password/PASSWORD）。
4. 用正则识别身份证号、手机号、银行卡号等模式，做脱敏处理。
5. 替换前高亮预览所有命中项，替换后输出"原名—新名—替换词"对照报告。

**可执行提示词（5 条）**

1. "扫描 D:\共享\ 下所有文件名和文件夹名，把『工资表』『绩效』『身份证』替换成合规词，先列出全部命中文件让我确认。"
2. "读取 E:\敏感词表.txt 里的关键词，在 D:\资料\ 整个目录（含子文件夹）的文件名中脱敏替换，替换前先备份目录。"
3. "把文件名里出现的 11 位手机号批量替换成 138****0000 这种脱敏格式，执行前先预览命中项。"
4. "查找 D:\共享盘\ 文件名中 18 位连续数字（身份证号），统一替换为 XXXX，并输出一份替换对照表。"
5. "设置监控：检测到共享盘新增文件名含敏感词时自动改名并通知我，同时记录到日志。"

**操作步骤（6 步）**

1. 发送指令：「把 D:\资料\ 目录（含子文件夹）里文件名中的敏感词，按 E:\敏感词表.txt 批量替换。」
2. Workbuddy 确认处理范围和规则，如是否区分大小写、是否连同文件夹名一起处理，你按需补充。
3. 替换是敏感操作，Workbuddy 会先提示备份，你确认后它自动把 D:\资料\ 完整备份到安全位置。
4. Workbuddy 自动扫描并高亮列出全部命中项（原名 → 新名 → 命中词），你核对有无误伤。
5. 确认无误后 Workbuddy 自动执行替换，重名自动加序号，并输出"原名—新名—替换词"对照报告。
6. 你抽查改名结果；想长期监控就说「以后共享盘新增文件名含敏感词就自动改名并通知我」。

### 51. 自动同步云盘与本地文件夹，双向备份新增、修改文件

**细分能力点（5 条）**

1. 本地文件夹与云盘（百度网盘/OneDrive 等同步盘）双向自动同步。
2. 增量同步：只传输新增和修改过的文件，不重复整传，节省流量与时间。
3. 删除操作单独确认或移入回收站，防止同步机制误删文件。
4. 双向冲突（两边都改过同一文件）自动保留两个版本并标注来源。
5. 同步日志可追溯，同步失败自动重试并发出告警。

**可执行提示词（5 条）**

1. "把 D:\工作\ 和百度网盘同步盘里的『工作』文件夹设为双向同步，每 5 分钟检查一次，只同步新增和修改的文件。"
2. "设置双向同步：源目录 D:\工作，目标目录 D:\云盘同步\工作，冲突文件保留两个版本，先做一次试运行给我看结果。"
3. "把 C:\Users\me\Documents 单向备份到 E:\备份，先展示将要复制和删除哪些文件，确认后执行。"
4. "监测 D:\项目\ 文件夹变化，发现新增或修改的文件立即上传到 OneDrive 云端『项目备份』目录。"
5. "设置每日 18:00 自动把 D:\资料\ 双向同步到 D:\云盘同步\资料，同步完生成一份报告发我。"

**操作步骤（6 步）**

1. 确认云端：登录百度网盘/OneDrive 桌面端并开启同步盘，告诉 Workbuddy 云盘对应的本地目录。
2. 发送指令：「把 D:\工作\ 和云盘里的『工作』文件夹设为双向同步，每 5 分钟检查一次。」
3. Workbuddy 确认同步策略：是否只同步新增/修改文件、两边都改过的文件如何处理、删除是否进回收站，你确认。
4. 确认后 Workbuddy 自动完成技术配置并先跑一次试运行，展示将新增/修改/删除哪些文件，你核对无误后再启用。
5. 启用后 Workbuddy 自动持续同步，同步失败会自动重试并发告警，你无需手动干预。
6. 想调整就说「改成每天 18:00 同步一次」或「暂停同步」；想看记录就说「发我最近的同步日志」。

### 55. 扫描本地重复文件，一键删除重复照片、安装包、文档

**细分能力点（5 条）**

1. 按文件内容哈希（MD5/SHA1/SHA256）精确识别内容完全相同的重复文件。
2. 先按文件大小分组快速预筛，只对同大小的文件算哈希，大幅加快扫描速度。
3. 每组可指定保留策略：最早创建/最新修改/指定路径，其余标记为待删。
4. 删除前展示重复分组清单（文件路径、大小、哈希），支持逐项勾选确认。
5. 删除文件先移入回收站而非直接永久删除，可随时恢复。

**可执行提示词（5 条）**

1. "扫描 D:\照片\ 找出内容完全相同的重复照片，列出分组清单和每组占用的空间，让我确认后再删。"
2. "扫描 D:\下载\ 里重复的安装包和文档，每组只保留最早的一个，其余移到 D:\重复文件待删\ 文件夹，先给我统计。"
3. "扫描 D:\资料\ 里的全部重复文件，按组输出报告，标注每组保留哪个、删哪些、一共能释放多少空间。"
4. "找出 D:\桌面 和 E:\备份 之间内容重复的文件，先告诉我共有几组重复、能释放多少空间。"
5. "设置每月 1 日自动扫描 D:\下载\ 的重复文件，移到回收站并生成清理报告发我。"

**操作步骤（7 步）**

1. 发送指令：「扫描 D:\照片\ 找出内容完全相同的重复照片，列出分组清单。」
2. Workbuddy 确认扫描范围和比对方式（按文件内容精确比对），你确认后它自动开始扫描。
3. Workbuddy 展示重复分组报告：每组文件路径、大小、占用空间、建议保留哪个。
4. 你核对保留策略（如"每组保留最早创建的"），告诉 Workbuddy 按此执行。
5. 删除是敏感操作，Workbuddy 会先提示备份或确认移入回收站，你确认后再继续。
6. Workbuddy 把待删文件移入回收站（不直接永久删除），生成清理报告并发给你。
7. 想定期清理就说「每月 1 日自动扫描 D:\下载\ 重复文件，移到回收站并给我报告」。

### 62. 自动整理电脑桌面文件，按文档、图片、安装包分类收纳

**细分能力点（5 条）**

1. 按扩展名自动分类：文档、图片、视频、安装包、压缩包、音频等。
2. 支持自定义规则：按项目名、日期（年月）、文件名关键词二次归类。
3. 目标文件夹自动创建，同名文件自动追加序号，避免覆盖。
4. 桌面快捷方式（.lnk）、正在运行程序的文件可加入排除列表保留原地。
5. 支持一键归档大文件/旧文件到冷归档目录，释放桌面空间。

**可执行提示词（5 条）**

1. "帮我整理桌面：把文件按 文档(.docx/.pdf/.txt)、图片(.jpg/.png/.gif)、安装包(.exe/.msi)、压缩包(.zip/.rar)、视频(.mp4) 分类放进桌面对应文件夹，快捷方式保留不动。"
2. "设置每天 22:00 自动整理桌面，按类型归档到对应分类文件夹，并把空文件移到回收站。"
3. "把桌面文件按最近修改日期归档到『桌面\归档\2026年8月\』这种按月文件夹，先预览分类结果再执行。"
4. "整理桌面时把文件名含『合同』『发票』的文件单独放到 桌面\合同票据\ 文件夹，其余按类型归档。"
5. "整理桌面：找出超过 30 天没修改、大于 100MB 的文件，提示我是否移入 D:\冷归档\ 释放空间。"

**操作步骤（6 步）**

1. 发送指令：「帮我把桌面文件按类型自动归类到对应文件夹，快捷方式保留不动。」
2. Workbuddy 确认分类规则：哪些扩展名算文档/图片/安装包，快捷方式是否保留、空文件怎么处理，你按需补充。
3. 你确认分类方案后，Workbuddy 先预览分类结果，展示每个文件将移动到哪个文件夹。
4. 核对无误后 Workbuddy 自动创建分类文件夹并移动文件，同名文件自动加序号不覆盖。
5. 你检查桌面整理结果，想让某类文件归到别处，直接告诉 Workbuddy 调整即可。
6. 想每天自动整理就说「以后每天 22:00 自动整理桌面，并汇报归档情况」。

### 80. 每日定时备份重要文档至移动硬盘与云端双备份

**细分能力点（5 条）**

1. 支持"本地 → 移动硬盘"与"本地 → 云端"双目标同时备份。
2. 增量备份只备份新增与修改文件，大幅缩短每日耗时。
3. 每日定时自动执行，任务计划程序驱动，失败自动重试并告警。
4. 备份后自动校验：对比源与目标的文件数量、总大小，重要文件比对哈希。
5. 移动硬盘未插入时自动跳过并提示，不报错、不影响云端备份。

**可执行提示词（5 条）**

1. "设置每日 22:00 把 D:\重要文档\ 增量备份到移动硬盘 E:\ 和 OneDrive 云端，两个目标都执行，并输出备份日志。"
2. "把 C:\Users\me\Documents 每日备份到 F:\备份\Documents，结束后对比源与目标的文件数量，报告差异。"
3. "设置每日定时备份重要文档到移动硬盘 E:\ 盘，备份完成后自动校验完整性。"
4. "把 D:\工作\ 每日增量同步到百度网盘同步盘和移动硬盘，移动硬盘没插上就跳过该目标并提示我。"
5. "每次备份完成后生成报告：备份文件总数、新增数、失败列表、占用空间，保存到 D:\备份报告\。"

**操作步骤（7 步）**

1. 规划备份方案：告诉 Workbuddy 源目录 D:\重要文档、两个目标（移动硬盘 E:\、OneDrive 云端）、备份时间。
2. 发送指令：「设置每日 22:00 把 D:\重要文档\ 增量备份到移动硬盘和 OneDrive 云端两个目标。」
3. Workbuddy 确认备份策略：只备份新增/修改文件、失败自动重试、移动硬盘未插入时跳过，你确认。
4. 确认后 Workbuddy 自动完成技术配置，并立即跑一次备份做验证，你无需手动搭建。
5. 备份完成后 Workbuddy 自动校验：对比源与目标文件数、核对重要文件内容一致，把结果发给你。
6. 你抽查备份文件能否正常打开，确认无误后让它长期运行；想调整就说「备份时间改成 02:00」或「今晚暂停备份」。
7. 每周围绕备份做一次抽查（从备份里打开几个文件验证可用），每月让 Workbuddy 做一次完整恢复演练。

### 95. 批量加密重要文档文件夹，设置独立访问密码

**细分能力点（5 条）**

1. 支持对文件夹整体加密（7-Zip AES-256 加密压缩，含加密文件名选项）。
2. 支持对文件夹内每个文件单独加密并设置各自独立的访问密码。
3. 自动生成高强度随机密码（大小写字母+数字+符号，16 位以上）并批量套用。
4. 生成密码清单并安全保存（Excel + 密码管理器双重存放）。
5. 加密/解密后自动校验：解压对比文件数与内容哈希，确保文件完整无损。

**可执行提示词（5 条）**

1. "把 D:\机密\ 文件夹加密成带密码的压缩包，密码用 16 位大小写字母+数字+符号随机生成，加密后给我校验一遍。"
2. "把 D:\合同\ 下每个文件单独加密，每个文件一个随机密码，密码表导出到 Excel 并安全保存。"
3. "把 D:\财务\ 里所有文件加密成 财务备份_2026.zip（含加密文件名），设置密码 Abc@123456，完成后校验解压一遍。"
4. "读取 E:\密码表.xlsx，把 D:\加密文件\ 下的加密包用对应密码批量解密到 D:\已解密\，解压后对比文件数。"
5. "设置每月 1 日提醒我把上月新增的机密文件加入加密目录并重新加密，旧加密包移到冷备份目录。"

**操作步骤（8 步）**

1. 加密是敏感操作：先让 Workbuddy 把 D:\机密\ 完整备份一份到安全位置，确保误操作可恢复。
2. 发送指令：「把 D:\机密\ 文件夹加密成带密码的压缩包，密码自动随机生成。」
3. Workbuddy 确认加密方式：整包加密还是逐文件加密、密码强度、密码表保存位置，你按需补充。
4. 确认后 Workbuddy 自动完成加密，生成高强度随机密码，并把密码表保存为 Excel + 同步进密码管理器双份存放。
5. Workbuddy 自动校验加密包完整性（能否正常解开、文件数与内容一致），把结果发给你。
6. 确认无误后，Workbuddy 才按你确认的规则处理原文件（如清空原文件夹），不会擅自删除。
7. 你妥善保管密码表（本地、云端、纸本各一份），忘记密码后数据将永久不可读，务必定期测试解密流程。
8. 想定期加密就说「每月 1 日提醒我把上月新增的机密文件加入加密目录并重新加密」。
