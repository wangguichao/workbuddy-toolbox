### 5. 每天下午 2 点 30 分发送邮件告知基金价格，并整合前 1/5/10 天价格生成简报。

**细分能力点（5 条）**

1. 支持自定义监控基金列表，指数基金/ETF/主动基金均可，基金代码写入配置文件方便随时增删。
2. 自动抓取当日最新净值/收盘价，与前一交易日对比计算单日涨跌幅。
3. 按 1 个、5 个、10 个交易日三个区间统计区间涨跌幅，辅助判断短期趋势。
4. 每天 14:30 自动发送 HTML 邮件，正文含价格表格与近 10 日净值走势图。
5. 内置异常预警：单日跌幅超过阈值或连续多天下跌时，在邮件中高亮提醒。

**可执行提示词（5 条）**

1. "用 akshare 抓取基金 510300、159915、588000 今天的净值，和昨天对比算出涨跌幅，再计算近 5 日、10 日的区间涨跌，整理成表格。"
2. "帮我写一个 Python 脚本：每天 14:30 用 yagmail 把基金日报（当日价格、1/5/10 日涨跌、10 日走势图）发到邮箱 zhangsan@qq.com。"
3. "监控 510300、159915、512880 三只基金，如果某只单日跌幅超过 3%，在邮件标题和正文里标红提醒。"
4. "给基金简报加一张 matplotlib 折线图，画出这几只基金最近 10 个交易日的净值走势，每只基金用不同颜色区分。"
5. "把监控的基金列表写进配置文件 fund_list.json，脚本每天读取这个文件确定监控对象，方便我以后自己修改。"

**操作步骤（7 步）**

1. 确定要监控的基金清单并记录基金代码（如 510300 沪深300ETF、159915 创业板ETF、588000 科创50ETF），确认在天天基金网能查到。
2. 安装 Python 3 及依赖库：pip install akshare pandas matplotlib yagmail。
3. 用 akshare 的 fund_etf_hist_em（ETF 历史行情）或 fund_open_fund_info_em（开放式基金）抓取当日净值与历史净值数据。
4. 用 pandas 清洗并对齐交易日，计算区间涨跌幅 = (当前净值 / 区间起始净值 - 1) × 100%，分别取 1、5、10 个交易日。
5. 用 matplotlib 生成近 10 日净值走势 PNG 图，再用 HTML 表格组织当日价格与各区间涨跌数据。
6. 配置 yagmail：开启发件邮箱 SMTP 并获取授权码（QQ 邮箱在设置→账户里生成），填写收件人地址，把图片嵌入邮件正文发送。
7. 在"任务计划程序"里新建任务，触发器设为每天 14:30、操作指向 pythonw.exe 运行脚本（不弹黑窗）；先手动跑一次确认邮件与数据无误再启用。

### 14. 扫描发票截图，自动提取信息填好报销表。

**细分能力点（5 条）**

1. 支持 JPG/PNG/PDF 多种格式，兼容手机拍照、屏幕截图、扫描仪输出三类来源。
2. 用 OCR 提取发票号码、开票日期、购买方/销售方名称、价税合计金额、税额、税号等关键字段。
3. 自动识别发票类型（增值税普票/专票/电子发票）并按费用类别初步归类。
4. 识别结果自动写入标准报销台账 Excel，列名与公司报销模板对齐，可直接导入 OA。
5. 识别后做校验：金额合法性、日期格式与范围检查，异常条目单独标记待人工核对。

**可执行提示词（5 条）**

1. "识别这张发票图片 D:\报销\发票.jpg，提取发票号、开票日期、价税合计金额、销售方名称，填入报销表模板。"
2. "批量识别 D:\报销发票\ 目录下所有 JPG/PNG/PDF，输出到 Excel，列为：发票号、日期、金额、税额、销售方、类别。"
3. "把识别出的发票按『交通、餐饮、办公、其他』四类归类，金额保留两位小数，生成月度报销汇总。"
4. "检查这批发票里金额为负数或日期超出本月范围的记录，单独列一个 Sheet 标黄，方便我人工核对。"
5. "用百度 OCR 通用文字识别 API 识别发票，把返回的 JSON 结果解析后写入报销台账，置信度低于 80% 的字段标红。"

**操作步骤（6 步）**

1. 安装 Python 与 OCR 引擎：PaddleOCR（pip install paddleocr，中文识别效果好）；或用百度/腾讯 OCR 的 API Key。
2. 建立目录 D:\报销发票\ 存放扫描件，规范命名为"日期-金额-名称"，并按月份分子文件夹。
3. 编写脚本用 PaddleOCR 识别图片文字块，配合正则按"发票号码、开票日期、价税合计、销售方"等关键字抽取字段。
4. 对抽取结果做双重校验：金额对照大写与数字、日期用 datetime 判断合法性，无法匹配的记录写入"待核对"表。
5. 用 openpyxl 将结果写入报销台账模板（列：日期、发票号、金额、税额、销售方、类别、状态）。
6. 先跑 10~20 张样张评估准确率，调整正则规则与 OCR 参数后再全量处理，并每月复核一次。

### 18. 自动记账，将支付宝和微信账单的导出文件自动分类统计、生成月度消费报告。

**细分能力点（5 条）**

1. 支持解析支付宝、微信导出的账单文件（CSV/Excel 常见格式），自动识别列名与编码。
2. 统一字段结构：交易时间、交易类型、金额（正负号）、收付款方、商品说明、支付渠道。
3. 自动打消费分类标签（餐饮、交通、购物、居住、娱乐、转账、退款等），分类规则可自定义。
4. 合并去重：同一笔交易在微信、支付宝重复出现时按金额+时间去重，退款自动冲抵支出。
5. 按月/类别/渠道三维统计，生成月度消费报告与饼图、柱状图、周趋势图。

**可执行提示词（5 条）**

1. "解析 D:\账单\支付宝-2026年08月.csv 和 微信支付账单(2026-08).xlsx，合并后按类别统计 8 月消费总额。"
2. "把支付宝账单里『餐饮美食、出行交通、日用百货』等商家名自动映射到我的分类规则，输出分类结果表。"
3. "生成 2026 年 8 月消费报告：总支出、各分类金额和占比、环比上月变化，用饼图和柱状图展示。"
4. "找出同一笔在支付宝和微信里重复记账的交易（金额相同且时间相差 5 分钟以内），自动去重只保留一条。"
5. "把上个月支出按周汇总，标出单笔超过 1000 元的大额支出，生成一份提醒清单发给我。"

**操作步骤（8 步）**

1. 导出账单：支付宝「我的→账单→右上角…→开具交易流水证明→选时间范围导出 CSV」；微信「我→服务→钱包→账单→常见问题→下载账单→发送到邮箱」。
2. 安装依赖：pip install pandas matplotlib openpyxl xlrd。
3. 分别读取两种账单，将列名映射为统一字段（时间、类型、金额、对方、备注、渠道），处理编码（微信 CSV 常为 GBK，用 encoding='gbk' 读取）。
4. 合并数据，删除表头重复行与空行，按"金额绝对值 + 时间 ±5 分钟 + 对方"规则去重。
5. 建立分类规则字典（如包含"滴滴/地铁/公交"→交通，包含"美团/餐饮"→餐饮），遍历备注/对方字段打标签；未命中的进入"待分类"。
6. 把退款、红包、转入转出、理财收益等非消费项单独归类，从消费统计中剔除。
7. 用 pandas groupby 按月、类别统计，生成月度台账 CSV 与消费报告（总支出、分类占比、环比）。
8. 用 matplotlib 画饼图 + 柱状图输出报告，可设为每月 1 号自动生成上月报告。

### 53. 解析银行流水表格，自动区分工资、消费、转账分类统计。

**细分能力点（5 条）**

1. 支持招商银行、工商银行、建设银行等主流银行导出的流水（Excel/CSV/PDF 均可解析）。
2. 自动识别流水字段：交易日期、收入、支出、余额、对方户名、摘要/附言。
3. 智能分类：工资（固定日期入账、摘要含"代发"）、消费（商户刷卡/扫码）、转账（本人他卡或转他人）。
4. 工资按月汇总核对，拆分应发工资与社保、公积金、个税等代扣项目。
5. 输出月度/年度收支分类统计表与图表，支持与记账 App 数据交叉比对。

**可执行提示词（5 条）**

1. "解析招商银行 2026 年 1-8 月流水表 D:\流水\交易流水.xlsx，把每一笔分为工资、消费、转账、利息、其他五类。"
2. "从流水里识别工资记录（每月固定日期入账、附言含『代发工资』），统计每月实发工资，并列出社保公积金个税代扣金额。"
3. "把转给本人另一张卡的转账和转给他人的转账区分开，转给他人的按月份统计总额。"
4. "生成 2026 年消费分类统计图，把刷卡消费按商户类型（超市、餐饮、加油站、网购）细分。"
5. "把流水里的收入、支出、结余做成月度收支表，和我记账 App 的数据做差异比对，不一致的列出来。"

**操作步骤（7 步）**

1. 在手机银行/网银导出流水，Excel/CSV 优先，PDF 次之，导出时注意勾选"含摘要/附言"并选对时间范围。
2. 安装依赖：pip install pandas pdfplumber openpyxl。
3. 读入表格并统一列名与金额符号（收入为正、支出为负），用正则清理千分位逗号与货币符号。
4. 定义分类规则：工资（摘要含"代发/工资"且金额稳定）、转账（含"转账/他行/本人"）、消费（商户名称）、利息（含"利息/结息"）。
5. 用 pandas 分组统计：月度工资总额、消费总额、转账总额、利息收入，并按商户关键字细分消费。
6. 计算结余 = 收入 - 支出，与表格期末余额比对，不一致则排查遗漏或借贷方向标错的行。
7. 生成汇总 Excel（分类汇总 Sheet + 明细 Sheet）和图表，无法归类的"其他"项单独列出人工处理。

### 71. 自动汇总各部门报销单据，核算总金额生成报销汇总单。

**细分能力点（5 条）**

1. 按部门文件夹批量读取统一模板的报销单据（Excel/CSV），支持递归遍历子目录。
2. 按部门、费用类别（差旅、餐饮、办公、通讯）分组核算单据数与金额。
3. 自动校验：发票号是否重复、单笔金额是否超标准、报销日期是否在当月，违规项标出。
4. 生成报销汇总单：总金额、各部门小计、单据数、报销人次，交叉统计部门×类别。
5. 输出 Excel 汇总单并支持转成 Word/PDF 打印版，供财务负责人签字。

**可执行提示词（5 条）**

1. "汇总 F:\报销单\各部门\ 文件夹下各部门提交的 Excel 报销单，核算每部门总金额和单据数。"
2. "把所有报销单据按部门分组，列：部门、报销人、单据数、金额小计、占比，生成一张汇总单。"
3. "检查各部门报销单里发票号是否重复、单笔金额是否超过 5000 元标准，超标的标红并列出问题清单。"
4. "生成 2026 年 8 月报销汇总单 Excel，包含总表、按部门 Sheet、按类别 Sheet，金额用 SUM 公式自动求和。"
5. "把各部门报销汇总单转成 Word 版（含表格和合计行），方便财务负责人签字打印。"

**操作步骤（8 步）**

1. 规范各部门使用统一 Excel 模板（列：部门、报销人、日期、类别、金额、发票号、备注），存放到 F:\报销单\各部门\ 下按部门命名子文件夹。
2. 安装依赖：pip install openpyxl pandas python-docx。
3. 编写脚本用 os.walk 遍历所有部门子文件夹，读取每个 Excel 模板 Sheet。
4. 用 pandas 拼接所有单据，做数据清洗：金额转数字、日期格式统一为 YYYY-MM-DD、空值填 0 或剔除。
5. 用 groupby('部门') 汇总单据数与金额小计，用 pivot_table 生成部门×类别交叉统计表。
6. 校验逻辑：发票号去重（重复标记）、单笔金额与 5000 元上限比对、报销日期在当月，违规项写入"问题清单"。
7. 用 openpyxl 生成汇总单 Excel：总表（合计）、部门明细 Sheet、类别 Sheet、问题清单 Sheet。
8. 用 python-docx 把汇总单转成 Word 打印版；先跑一个月历史数据与财务手工账核对一致后，再固化月末自动执行的流程。

### 75. 自动统计外卖、打车消费，生成月度生活开销分布图。

**细分能力点（5 条）**

1. 自动收集美团、饿了么、滴滴等平台的外卖与打车订单记录（导出或批量整理）。
2. 按平台、月份统计外卖与打车消费金额和订单数，计算平均单均价格。
3. 识别高频商家、高频路线（起点-终点组合），生成 Top 消费对象榜单。
4. 按周/日对比消费趋势，标记消费异常偏高的日期便于自查。
5. 生成月度生活开销分布图（外卖 vs 打车占比饼图 + 每日支出趋势图）并输出报告。

**可执行提示词（5 条）**

1. "统计 2026 年 8 月美团外卖支出，按周汇总，算出平均每单价格，列出消费最多的前 3 家店。"
2. "解析滴滴出行订单明细 D:\账单\滴滴-2026-08.xlsx，按打车类型（快车、专车、拼车）统计费用和订单数。"
3. "把外卖和打车账单合并，生成 8 月生活开销分布图：外卖 vs 打车占比饼图 + 每日支出趋势图。"
4. "对比 7 月和 8 月的外卖支出，找出涨幅超过 30% 的类别，分析是否集中在周末或加班日。"
5. "设置提醒：当本月外卖 + 打车累计超过 1000 元时，推送一条月度预警和分类消费明细。"

**操作步骤（7 步）**

1. 获取订单数据：美团「我的→钱包→账单」、饿了么「我的→订单→开具发票」、滴滴「钱包→账单」可导出 Excel/CSV；无法直接导出的平台用浏览器登录后手动导出或整理。
2. 安装依赖：pip install pandas matplotlib openpyxl。
3. 把外卖、打车账单分别读入，统一字段（时间、平台、金额、商家/路线、类型），处理 GBK 编码。
4. 打分类标签：外卖按商家名归类（正餐、奶茶、便利店、夜宵），打车按类型（快车、专车、拼车）。
5. 用 pandas groupby 统计月度总支出、订单数、平均单均，识别 Top 商家与高频路线（起点-终点组合）。
6. 用 matplotlib 绘制外卖/打车占比饼图与 30 日每日支出柱状图，标注单日峰值与异常日。
7. 生成月度报告 Excel/HTML（分类明细 + 图表），设置月累计阈值提醒；长期运行后沉淀个人消费画像。
