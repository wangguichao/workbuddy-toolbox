# Workbuddy 能力扩展清单

> 在「Workbuddy 能力清单 · 100 条整理分类」的基础上，将 **100 条能力** 逐条扩展为 **细分能力点 + 可执行提示词 + 操作步骤** 三类结合的内容，共 14 个模块、**1690 个扩展条目**，按主题拆分如下。

## 使用说明

每个模块文件内的每一条原始能力，都按统一结构展开：

- **细分能力点（5 条）**：把这条能力拆成更小的可执行子任务。
- **可执行提示词（5 条）**：可直接发送给 Workbuddy 的指令，已含具体参数/路径。
- **操作步骤（5~10 步）**：对话式执行流程，展示你从向 Workbuddy 发指令到任务完成的交互过程。

适合用于：挑选想落地的能力 → 复制提示词发给 Workbuddy，或按操作步骤的对话流程完成。
