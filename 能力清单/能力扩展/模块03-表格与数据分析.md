### 7. 将多张 excel 表合并，数据去重、清洗、排序，画饼图

**细分能力点（5 条）**

1. 支持合并同结构/不同结构的多张 Excel 表，兼容 xlsx、xls、csv 三种格式。
2. 自动检测并处理表头不一致：列名相同则纵向拼接，列名不同则按列名对齐补齐。
3. 数据去重：支持按指定关键列（如订单号、客户名）去重，可自定义保留哪条记录。
4. 数据清洗：删除全空行、去掉单元格前后空格、统一日期与金额格式、填充或删除缺失值。
5. 按指定列（如日期、金额）升序或降序排序，并对清洗后的数据自动绘制饼图、导出 PNG。

**可执行提示词（5 条）**

1. "把 D:\销售数据\ 文件夹下所有 xlsx 合并成一个总表，按'订单号'去重，重复行只保留一条。"
2. "合并后删除空白行，去掉列名和单元格里多余的空格，按'日期'列升序排序。"
3. "合并 C 盘三个月份的销售表，按'产品类别'列统计销量占比，画出饼图保存到 D:\报表\。"
4. "按'客户名称'列去重，同一客户有多条订单时保留金额最大的一条，其余删掉。"
5. "合并清洗完成后，输出一份日志：原始行数、去重条数、各品类占比，并把饼图和总表一起导出。"

**操作步骤（7 步）**

1. 安装 Python，在命令行执行 `pip install pandas openpyxl matplotlib`，安装好三个核心库。
2. 把需要合并的所有 Excel 文件放入同一个文件夹，先打开扫一眼确认各表的列名尽量一致。
3. 用 `pd.read_excel()` 循环读取文件夹下所有文件，存到一个列表，再用 `pd.concat(..., ignore_index=True)` 纵向合并成一个大 DataFrame。
4. 用 `df.drop_duplicates(subset=['订单号'])` 按关键列去重；如果两张表列名不同，先通过 `rename` 统一列名再合并。
5. 用 `df.dropna(how='all')` 删除全空行，用 `str.strip()` 清理空格，用 `pd.to_datetime()` 统一日期格式。
6. 用 `df.sort_values('日期')` 排序，用 `df.groupby('产品类别').size()` 统计各品类数量。
7. 用 matplotlib 的 `plt.pie()` 画饼图，`plt.savefig('饼图.png')` 导出，再用 `df.to_excel('合并总表.xlsx', index=False)` 保存结果。

### 15. 将 excel 中一千条 20260628 这样的数据改成 2026-06-28，两千条手机号码中间四位打 ****

**细分能力点（5 条）**

1. 批量把 YYYYMMDD 八位数字日期转换为 YYYY-MM-DD 标准格式。
2. 批量把 11 位手机号码中间四位替换为 \*\*\*\*，实现隐私脱敏。
3. 支持整列或指定区域批量处理，处理过程不影响表格其他列的数据。
4. 内置校验规则：自动识别非 8 位日期、非 11 位手机号，标记为异常不误改。
5. 处理前自动备份原文件，处理后生成一份处理日志（处理行数、异常行数）。

**可执行提示词（5 条）**

1. "把 D:\名单.xlsx 的 B 列所有 20260628 这样的 8 位日期统一改成 2026-06-28 格式。"
2. "把 C 列 2000 个手机号中间四位打成星号，变成 138****5678 这样。"
3. "批量处理 D:\名单.xlsx：A 列日期转格式，B 列手机号脱敏，处理结果另存为新文件，别覆盖原表。"
4. "转换之前先备份一份原文件，处理完统计一下日期转换了多少行、手机号处理了多少行。"
5. "处理时遇到不是 8 位数字的日期、不是 11 位的手机号，单独列出来标红，不要直接删。"

**操作步骤（6 步）**

1. 打开原文件，先"另存为"一份备份，命名为"名单_bak.xlsx"，防止操作失误。
2. 方法一（Excel 自带）：选中日期所在列，点击"数据 → 分列 → 下一步 → 选择 YMD → 完成"，再右键设置单元格格式为"自定义 yyyy-mm-dd"。
3. 方法二（Python 批量）：写脚本用 `pd.to_datetime(df['日期'], format='%Y%m%d')` 一步完成转换。
4. 手机号脱敏用正则：`df['手机号'] = df['手机号'].astype(str).str.replace(r'(\d{3})\d{4}(\d{4})', r'\1****\2', regex=True)`。
5. 用正则 `^\d{11}$` 筛出非 11 位手机号，把异常行单独导出，不打星号。
6. 处理完成后另存为新文件，抽查前 10 行确认日期格式和手机号脱敏效果无误。

### 36. Excel 批量拆分超大表格，按地区 / 品类自动分成独立文件

**细分能力点（5 条）**

1. 按指定列（如"地区"、"品类"）的值自动分组，把一个大表拆成多个独立 Excel 文件。
2. 每个拆出的文件自动保留原始表头，文件名自动用分组值命名（如"华东区.xlsx"）。
3. 支持超大表（几十万行）分块读取，避免一次读入内存卡死。
4. 支持组合拆分：先按地区分，再按日期/品类二次拆分子文件。
5. 拆分结束后自动生成一份文件清单，列出每个文件的名称、行数和状态。

**可执行提示词（5 条）**

1. "把 D:\大表.xlsx 按'地区'列拆分成多个独立 Excel 文件，每个文件都保留表头。"
2. "按'品类'列分组拆分，每个品类单独存一个文件，文件名直接用品类名。"
3. "这个表有 30 万行，用分块读取的方式处理，别卡死，拆完给我一份文件清单。"
4. "先按地区拆，每个地区内部再按日期拆成多个子文件，命名格式 地区_日期。"
5. "拆分后给每个文件末尾加一行汇总：该组总行数、合计金额，方便核对。"

**操作步骤（7 步）**

1. 确认拆分依据列（比如"地区"），先检查该列有没有空值，空值单独归到一个"未分类"文件。
2. 表较小（几千行）可用 Excel 自带方式：数据透视表或筛选后复制到新文件，逐个保存。
3. 超大表改用 Python：`pd.read_excel('大表.xlsx', chunksize=50000)` 分块读取，边读边丢弃无关列。
4. 用 `df.groupby('地区')` 分组，遍历每个分组用 `group.to_excel(f'{地区}.xlsx', index=False)` 写文件。
5. 文件名用 `groupby` 的 key 自动生成，写入引擎用 `engine='openpyxl'` 保证中文文件名正常。
6. 写完后遍历输出目录，用 `pd.read_excel` 读取每个文件的行数，生成 CSV 清单（文件名、行数）。
7. 随机抽查 2~3 个拆分文件，核对表头是否保留、行数与分组统计是否一致。

### 48. 汇总多份调查问卷数据，自动生成折线、柱状分析图表

**细分能力点（5 条）**

1. 读取多份问卷导出文件（xlsx/csv），按相同题目自动纵向合并成一份总数据。
2. 统一题目标题：不同批次问卷列名略有差异时，通过映射字典自动对齐。
3. 计算各题频数、百分比、均值、标准差等基础统计指标。
4. 自动生成图表：单选题画柱状图，随时间变化或数值型题画折线图。
5. 输出结构完整：统计表导出 Excel、图表导出 PNG，可插入 Word/PPT 生成报告。

**可执行提示词（5 条）**

1. "把 D:\问卷\ 文件夹下 5 份问卷结果合并成一份总表，先列出每道题的频数统计。"
2. "第 3 题是单选题，帮我画柱状图展示每个选项的占比，柱子上标注百分比。"
3. "按'填写日期'分组统计满意度均值，画折线图看变化趋势。"
4. "合并时注意不同批次题目标题可能不一致，先按我给的映射表对齐列名再合并。"
5. "统计完成后输出一份分析报告：统计表+柱状图+折线图，全部导出到 D:\问卷报告\。"

**操作步骤（7 步）**

1. 用 pandas 循环读取所有问卷文件，用 `pd.concat()` 合并，加一列"来源文件"方便追溯。
2. 检查各文件列名差异，写一个映射字典 `{'满意度v1':'满意度', '满意程度':'满意度'}` 统一题目标题。
3. 用 `df['题目'].value_counts()` 计算单选题各选项频数，用 `value_counts(normalize=True)` 算百分比。
4. 用 matplotlib 画柱状图：`plt.bar(选项, 频数)`，用 `plt.text()` 在柱顶标注百分比。
5. 数值型/趋势题用 `df.groupby('填写日期')['满意度'].mean().plot()` 画折线图。
6. 处理中文字体：在脚本开头加 `plt.rcParams['font.sans-serif'] = ['SimHei']` 和 `plt.rcParams['axes.unicode_minus'] = False`，避免图表乱码。
7. 用 `to_excel()` 导出统计表，用 `plt.savefig()` 保存图表，再插入 Word/PPT 生成完整报告。

### 59. 批量修正 Excel 乱码、空白行、无效数据，修复表格格式

**细分能力点（5 条）**

1. 自动识别并修复乱码文本：替换乱码字符（如 �）、统一编码重新读取保存。
2. 批量删除全空行、连续空行，对部分缺失单元格按规则填充默认值。
3. 修正无效数据：如年龄超出 0~120、日期出现 13 月、金额为负数等，标记或纠正。
4. 修复表格格式：调整列宽、设置表头加粗、冻结首行、修复合并单元格错乱。
5. 生成修正报告，分类型统计每个问题处理了多少条，方便审计回溯。

**可执行提示词（5 条）**

1. "清理 D:\数据表.xlsx：删除所有全空行，金额列有负数的单元格标红。"
2. "修复乱码：把文件里的 � 和问号乱码字符替换成空字符串，用 UTF-8 重新保存。"
3. "检查年龄列，大于 120 或小于 0 的值标记为异常，列到单独的 Sheet。"
4. "日期列里出现 13 月、32 号这种无效日期的，统一标记出来给我核对。"
5. "清理完后给我一份报告：每类问题处理了多少条、怎么处理的，修正后的文件另存一份。"

**操作步骤（7 步）**

1. 打开原文件，先"另存为"一份备份，后续所有操作都基于副本进行。
2. 用 pandas 读取，先跑 `df.isnull().sum()` 查看每列缺失值分布，`df.duplicated().sum()` 查重复行。
3. 删除全空行：`df.dropna(how='all')`；部分缺失用 `df.fillna({'金额':0, '备注':'无'})` 按列填充。
4. 乱码处理：先用 `pd.read_excel(..., encoding='utf-8')` 读，读不出乱码就换 `encoding='gbk'` 重试，再用 `str.replace('�','')` 清洗。
5. 数值校验：年龄列 `df[(df['年龄']<0)|(df['年龄']>120)]` 筛出异常；日期用 `pd.to_datetime(errors='coerce')` 把无效日期转成 NaT 再标记。
6. 用 openpyxl 修复格式：`ws.column_dimensions['A'].width = 20` 调列宽，`ws.freeze_panes = 'A2'` 冻结首行，给表头加粗。
7. 导出修正后的文件，同时生成一份"修正日志.csv"记录每类问题的处理数量和规则。

### 89. 批量拆分长 Excel 文本，按逗号、空格拆分多列数据

**细分能力点（5 条）**

1. 按指定分隔符（逗号、中文逗号、空格、分号、Tab）把一列长文本拆成多列。
2. 支持一次拆分多个列，每列可指定不同的分隔符。
3. 智能处理边界情况：连续分隔符、文本内容里本来就带逗号的情况。
4. 拆出的新列自动命名（如 原列_1、原列_2），可设置保留或删除原始列。
5. 支持上千行批量处理，性能稳定不卡顿。

**可执行提示词（5 条）**

1. "把 D:\名单.xlsx 的 A 列按逗号拆成多列，拆的时候文本里的逗号不要误拆。"
2. "把'姓名 手机号 城市'这种用空格分隔的文本拆成三列，多出的空格去掉。"
3. "把 B 列按分号拆分，拆完自动生成列名 B_1、B_2、B_3。"
4. "拆分完把原来的那一列删掉，新列放在原列的位置。"
5. "C 列有 5000 行地址，按逗号拆开，拆完每个单元格去掉首尾空格。"

**操作步骤（6 步）**

1. 先观察要拆的列，确认分隔符是英文逗号、中文逗号、空格还是分号，以及每行拆分后列数是否一致。
2. 方法一（Excel 自带）：选中该列 → "数据 → 分列 → 按分隔符号 → 勾选对应分隔符 → 完成"。
3. 方法二（Python）：`df[['姓名','手机号','城市']] = df['A'].str.split(' ', expand=True)`，用 expand=True 自动扩成多列。
4. 处理连续分隔符：`.str.split('，', regex=True, expand=True)`，拆完用 `.str.strip()` 去掉每个单元格的首尾空格。
5. 检查拆分结果：用 `df[列].isnull()` 找出拆完行数不足、有空值的行，单独标记。
6. 给新列重命名（如 名称_1、名称_2），按需 `drop('原列', axis=1)` 删除原列，最后 `to_excel()` 导出。

### 92. 自动汇总线上问卷反馈，提取高频问题生成优化建议

**细分能力点（5 条）**

1. 自动汇总多份线上问卷的开放式反馈文本，合并到一张总表。
2. 对反馈文本做中文分词、去停用词、关键词频率统计。
3. 按主题聚类：自动把反馈归入"价格、功能、服务、体验、其他"等类别。
4. 生成高频问题 TOP 榜单，每个问题附原文示例和一条优化建议。
5. 输出结构化汇总报告（Excel/Word），按影响程度排序方便决策。

**可执行提示词（5 条）**

1. "把 D:\反馈.xlsx 里开放题的答案全部汇总，找出出现频率最高的 20 个关键词。"
2. "把反馈按'价格/功能/服务/体验'四类自动聚类，统计每类有多少条。"
3. "生成高频问题 TOP10 清单，每个问题附 3 条原文引用和一条优化建议。"
4. "用 jieba 做中文分词提取关键词，去掉'的、了、吗'这类停用词。"
5. "输出一份改进建议报告，按问题影响人数从高到低排序，导出到 D:\反馈报告\。"

**操作步骤（6 步）**

1. 用 pandas 汇总所有问卷的开放题答案到一列，去掉空答案，统计总反馈条数。
2. 安装分词库：`pip install jieba`，用 `jieba.cut()` 对每条反馈分词。
3. 准备一个停用词表（的、了、是、和、在、吗等），过滤后用一个 `Counter` 统计词频取 TOP20。
4. 简单聚类：按"价格/贵/优惠"、"功能/卡顿/不能用"等关键词规则，把反馈分到四个主题。
5. 每个主题下抽出 3 条最典型的原句，合并生成"高频问题+优化建议"表格。
6. 用 `to_excel()` 导出汇总报告，包含主题分布、TOP 关键词、高频问题和建议，必要时插入 Word 排版。
