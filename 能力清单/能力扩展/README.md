# Workbuddy 能力扩展清单

> 在「Workbuddy 能力清单 · 100 条整理分类」的基础上，将 **100 条能力** 逐条扩展为 **细分能力点 + 可执行提示词 + 操作步骤** 三类结合的内容，共 14 个模块、**1712 个扩展条目**，按主题拆分如下。

## 使用说明

每个模块文件内的每一条原始能力，都按统一结构展开：

- **细分能力点（5 条）**：把这条能力拆成更小的可执行子任务。
- **可执行提示词（5 条）**：可直接复制粘贴给 Workbuddy 的指令，已含具体参数/路径。
- **操作步骤（5~10 步）**：落到具体工具/方法（Python 库、软件、系统操作）的实施指南。

适合用于：挑选想落地的能力 → 直接复制提示词让 Workbuddy 执行 → 按操作步骤自行搭建。
