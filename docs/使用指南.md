# 使用指南

本文档说明如何高效地使用本项目，把「清单」变成你手上真正能跑起来的自动化。

> **核心原则**：所有任务只需向 Workbuddy 发送指令即可完成，无需自行搭建环境、安装软件或编写代码。

## 一、如何找到你需要的能力

1. 打开 [分类总览](分类总览.md)，浏览 14 大主题，找到关心的一类事务。
2. 如果不确定主题，直接看 [能力清单/分类整理.md](../能力清单/分类整理.md)，100 条能力都有编号和一句话描述。
3. 记下编号，到 [能力清单/能力扩展](../能力清单/能力扩展/) 打开对应模块文件，找到该编号的章节。

## 二、使用方式

### 方式 A：直接复制提示词发给 Workbuddy（最快）

每个能力章节里都有 5 条**可执行提示词**，是目标导向、含具体参数的完整指令，直接复制粘贴给 Workbuddy 即可。

例如，想要基金简报，直接对 Workbuddy 说：

> "监控这几只基金：510300、159915、588000，每天 14:30 自动抓取净值并计算近 1/5/10 日涨跌，整理成表格邮件发到 zhangsan@qq.com。"

提示词里已含具体参数，Workbuddy 会接手后续全部工作。落地后，把成功的提示词反馈回本项目（见[贡献](../CONTRIBUTING.md)），帮助更多人。

### 方式 B：跟着「操作步骤」对话完成（推荐）

每个能力章节都有 5~10 步**操作步骤**，是一段与 Workbuddy 的对话式执行流程：

发指令 → Workbuddy 确认/询问 → 你补充信息 → Workbuddy 自动完成 → 你检查结果 → 后续管理（改配置/定时/暂停）

例如「基金简报」的操作步骤：

1. 向 Workbuddy 发送指令：「监控这几只基金：510300、159915、588000，每天 14:30 自动抓取净值并计算近 1/5/10 日涨跌，整理成表格邮件发到 zhangsan@qq.com。」
2. Workbuddy 会确认收件邮箱、发送时间、是否要走势图等细节，按需补充。
3. 确认后，Workbuddy 自动完成整套流程，你无需安装软件或写代码。
4. 首次执行后核对邮件，有问题直接反馈给 Workbuddy 调整。
5. 改清单、改时间、暂停/恢复，直接对 Workbuddy 说即可。

### 方式 C：组合成流水线

很多能力可以串联成完整流程，例如：

- 发票识别（14）→ 报销汇总（71）
- 图片统一尺寸（9）→ 添加品牌水印（70）
- 爬取行情数据（22）→ 表格清洗（59）→ 生成日报（24）
- 录音转文字（65）→ 会议纪要提炼（65）

组合时只需把整条流程描述给 Workbuddy，它会依次执行。

## 三、落地优先级建议

- **高频、见效快**：表格处理（03）、图片处理（04）、财务记账（06）类，通常一次对话配置、长期复用。
- **需外部授权**：简历投递（08）、邮件自动回复（07）、网盘同步（13）等，需要你提供对应平台的账号权限或授权方式（Workbuddy 会引导你完成授权）。
- **涉及数据合规**：爬虫、价格监控（10）等，Workbuddy 会遵守目标网站条款与控制频率，你确认合规后即可使用。
- **破坏性操作**：文件删除、加密、批量替换（13）类，Workbuddy 会先提示备份，由你确认后再执行。

## 四、如何扩展与维护

- 想新增能力或完善现有条目？阅读 [扩展模板](扩展模板.md) 与 [贡献指南](../CONTRIBUTING.md)。
- 项目完全离线可用，纯 Markdown，可直接放在本地、同步到云盘，或托管到 GitHub。

## 五、常见问题

**Q：我不会写代码，能用吗？**
可以。所有任务只需向 Workbuddy 发送指令，由它自动完成技术实现，无需你安装软件、写脚本或配置环境。

**Q：提示词执行失败了怎么办？**
把 Workbuddy 的报错信息、你的文件/数据情况一起反馈给它，让它调整方案；也可以在项目里提 Issue 反馈。

**Q：操作步骤需要我做什么？**
只需要把指令发给 Workbuddy，并准备必要的素材：把账单/发票/文件放到指定文件夹、提供账号授权、确认输出格式等，其余由 Workbuddy 自动完成。
