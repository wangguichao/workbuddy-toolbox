# 办公文档处理（模块 02）

该模块把以下能力扩展为可直接发送给 Workbuddy 的提示词与对话式操作步骤。原始条数 11，共 165~220 个扩展条目。

### 3. 将500份PDF文件批量转成Word文件

**细分能力点（5 条）**

1. 支持批量指定输入文件夹，一次性读取全部 PDF 并逐个转换，无需手动逐文件操作。
2. 自动区分文字版 PDF 与扫描版 PDF，扫描件先做 OCR 文字识别再转 Word，保证可编辑。
3. 尽量保留原始 PDF 的段落结构、标题层级、表格和图片等基本版式。
4. 支持按文件名规则或子文件夹分类输出，转换后的 Word 归入对应目录。
5. 生成转换日志与失败清单，跳过损坏文件并记录原因，方便集中复查。

**可执行提示词（5 条）**

1. "把 D:\资料\PDF源文件\ 文件夹里所有 PDF 批量转成 Word，输出到 D:\资料\Word输出\，保留原目录结构。"
2. "这批 PDF 里有扫描件，先做文字识别再转 Word，尽量保留段落和表格版式。"
3. "转换完成后生成报告，列出成功与失败的文件名及原因，失败文件单独放一个文件夹。"
4. "PDF 在哪个子目录，转出的 Word 就放对应子目录；只转文件名含『合同』的文件。"
5. "设置每周日 8 点自动扫描 D:\资料\PDF源文件\ 新增的 PDF 并转成 Word，完成后发我清单。"

**操作步骤（7 步）**

1. 把 500 份 PDF 集中放入 D:\资料\PDF源文件\，先抽取 3~5 个样本确认版式要求。
2. 向 Workbuddy 发送指令：「把 D:\资料\PDF源文件\ 里所有 PDF 批量转成 Word，保留段落表格，输出到 D:\资料\Word输出\。」
3. Workbuddy 会确认转换细节：输出目录、扫描件是否做文字识别、是否按子目录归档，按需补充（如"扫描件做识别，按子目录归档"）。
4. 确认后 Workbuddy 自动完成全部转换与技术实现，你无需手动操作。
5. 抽查 5 个转换结果，核对标题层级、表格与图片是否保留，有问题直接指出来让 Workbuddy 调整后重跑。
6. 查看转换报告，让 Workbuddy 把失败文件单独归到"待处理"文件夹并说明原因。
7. 想长期维护就告诉 Workbuddy：「每周日 8 点自动扫描新增 PDF 并转换，完成后发我清单。」

### 13. 修改论文格式，修改页眉页脚、统一参考文献、图表编号

**细分能力点（5 条）**

1. 一键修改整篇论文的页边距、行距、正文字号字体，匹配学校论文模板要求。
2. 批量统一页眉页脚，支持设置奇偶页不同、章节页码（如目录用罗马数字、正文用阿拉伯数字）。
3. 自动统一参考文献格式（GB/T 7714、APA 等），并按正文引用顺序重新编号。
4. 批量调整图表编号为"图 1-1""表 2-3"式统一编号，并同步更新正文中的交叉引用。
5. 自动生成目录并更新域代码，保证目录页码、标题与正文内容完全一致。

**可执行提示词（5 条）**

1. "把 D:\论文\毕业论文.docx 的正文改成宋体小四、行距 1.5 倍，标题用黑体，页边距按学校模板设置。"
2. "设置页眉为论文标题、页脚为页码，前 5 页用罗马数字，正文从第 6 页起用阿拉伯数字重新从 1 开始。"
3. "统一参考文献格式为 GB/T 7714，按正文引用顺序重新编号，并同步更新文中 [1][2] 标注。"
4. "把全文图表编号改成『图 2-1』『表 3-2』格式，所有正文里的交叉引用一起更新。"
5. "更新全文目录与交叉引用，让目录页码和正文一致，导出 PDF 检查无误后发我。"

**操作步骤（7 步）**

1. 打开 D:\论文\毕业论文.docx，确认学校模板的格式要求（字体、字号、页边距、页码规则）。
2. 向 Workbuddy 发送指令：「按学校模板把毕业论文正文改成宋体小四、行距 1.5 倍，标题用黑体，页边距按要求设置。」
3. Workbuddy 会确认细节：页码规则（前 5 页罗马数字、正文阿拉伯数字）、页眉内容、参考文献格式，按需补充。
4. 确认后 Workbuddy 自动完成格式修改、页眉页脚、参考文献统一与图表重新编号，你无需手动在 Word 里操作。
5. 让 Workbuddy 更新全文目录与交叉引用，并导出 PDF 供你检查。
6. 打开 PDF 核对页码、目录、编号是否一致，有问题直接让 Workbuddy 修正。
7. 定稿后告诉 Workbuddy 导出最终 PDF 交付版。

4. "提取时保留原始数字格式，金额列统一保留两位小数，空行自动删除。"
5. "汇总后生成 Excel 台账，冻结首行、列宽自适应，加『来源文件』列；以后每天自动处理新增报表。"

5. 让 Workbuddy 统一数字格式、删除空行、设置冻结首行和自适应列宽。
6. 打开台账抽查 2~3 个文件，核对提取内容与原表是否一致，不一致的让 Workbuddy 修正。
7. 需要长期更新就告诉 Workbuddy：「每天 17 点自动扫描新增报表，增量更新台账并发我。」
