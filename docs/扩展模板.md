# 扩展模板规范

本项目每条能力都按统一结构展开，本文档定义该结构，供贡献者新增或完善内容时参考。

## 一、章节结构

每个能力章节使用三级标题，格式如下：

```markdown
### {全局编号}. {能力标题}

**细分能力点（5 条）**

1. {具体可执行的能力点}
2. {具体可执行的能力点}
3. {具体可执行的能力点}
4. {具体可执行的能力点}
5. {具体可执行的能力点}

**可执行提示词（5 条）**

1. "{可直接复制给 AI 助手的指令，含具体参数}"
2. "{可直接复制给 AI 助手的指令，含具体参数}"
3. "{可直接复制给 AI 助手的指令，含具体参数}"
4. "{可直接复制给 AI 助手的指令，含具体参数}"
5. "{可直接复制给 AI 助手的指令，含具体参数}"

**操作步骤（5~10 步）**

1. {第一步：具体方法/工具}
2. {第二步：具体方法/工具}
...
```

## 二、写作要求

### 细分能力点

- 把这条能力拆成 **5 个**更小的可执行子任务。
- 每个子任务要具体，例如「支持 JPG/PNG/PDF 多种格式」「自动提取发票号、金额、开票日期」。
- 避免重复标题语义，5 点应覆盖能力的核心环节（输入、处理、校验、分类、输出）。

### 可执行提示词

- **5 条**，每条约 30~80 字。
- 用第一人称，像用户直接对 AI 说话，例如「帮我……」「设置……」「批量……」「校验……」「对比……」。提示词不要加引号前后缀之外的说明。
- 包含具体参数：路径（如 `D:\数据\`）、时间（如「每天 14:30」）、格式（如「2026-06-28」）、数量阈值（如「降价超 5%」）。
- 5 条提示词应覆盖不同使用场景：一次处理、批量处理、定时任务、校验/复核、流程化。

### 操作步骤

- **5~10 步**，从准备环境到最终验证的完整链路。
- 落到具体工具/方法：Python 库名（`pip install pandas openpyxl ...`）、软件名（Excel、剪映）、系统操作（环境变量、任务计划程序）。
- 贴合 Windows 10/11。
- 涉及网络爬取、第三方平台时，注明合规要求（遵守 robots 协议、控制频率）与人工复核。
- 涉及删除、加密、批量替换时，先提示备份。

## 三、硬性校验

提交内容前请自查：

- [ ] 章节标题编号全局唯一（`### 编号. 标题`）
- [ ] 三个小节标题齐全：细分能力点、可执行提示词、操作步骤
- [ ] 细分能力点恰好 5 条
- [ ] 可执行提示词恰好 5 条
- [ ] 操作步骤 5~10 步
- [ ] 合计条目数在 **15~20** 之间
- [ ] 全文简体中文，表述具体可操作
- [ ] 新增编号已同步登记到 `能力清单/分类整理.md` 与 `docs/分类总览.md`

## 四、示例

```markdown
### 14. 扫描发票截图，自动提取信息填好报销表

**细分能力点（5 条）**

1. 支持 JPG/PNG/PDF 多种格式发票截图识别。
2. 自动提取发票号、开票日期、金额、税号、销售方等关键字段。
3. 对识别结果做格式校验（金额、日期合法性）。
4. 按公司/月份自动归类到报销台账。
5. 生成报销汇总表并导出 Excel。

**可执行提示词（5 条）**

1. "帮我识别这张发票截图，提取发票号、金额、开票日期、销售方，填入报销表。"
2. "批量识别 D:\报销发票\ 文件夹里所有发票图片，把字段汇总到报销台账 Excel。"
3. "把识别出的发票按月份分类，生成月度报销汇总表。"
4. "校验识别结果，金额或日期有问题的标记出来给我核对。"
5. "设置流程：每周五自动扫描『报销发票』文件夹，生成当周报销清单发给我。"

**操作步骤（6 步）**

1. 安装 Python，并安装 OCR 库 PaddleOCR（中文识别效果好）或 Tesseract。
2. 将发票截图统一放入一个文件夹，重命名成"日期-金额-公司"便于识别。
3. 编写脚本循环读取图片，用 OCR 提取关键字段，再用正则校验格式。
4. 用 openpyxl 把识别结果写入报销台账模板（列：日期、发票号、金额、税号、销售方）。
5. 按月份/类别生成汇总 Sheet，统计报销总额。
6. 先跑一批样本核对准确率，调整 OCR 阈值和正则后再批量处理。
```

该示例共 5 + 5 + 6 = **16 条**，符合 15~20 的要求。
