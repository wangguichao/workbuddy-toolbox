### 17. 生成视频文案并制作 srt 文件，添加到剪映对应的草稿。

**细分能力点（5 条）**

1. 根据主题、目标时长和口播风格生成短视频文案，输出适合口语化的分句文本。
2. 将文案按语义停顿、每行不超过 14 字的安全规则自动切分成字幕句。
3. 生成标准 SRT 格式文件（序号、时间轴、字幕文本），支持中英双语与 UTF-8 编码。
4. 按字数与语速自动估算每句起止时间，使时间轴与视频时长匹配。
5. 支持批量：对文件夹内多个视频逐一生成同名 SRT，并挂载进剪映草稿目录。

**可执行提示词（5 条）**

1. "帮我写一条 30 秒短视频口播文案，主题是『家用咖啡机推荐』，语气轻松带货风，总字数控制在 90 字内，分成 6 句。"
2. "把这段文案按每行不超过 14 个字切分成字幕句，生成标准 SRT 文件，保存到 D:\视频\文案\coffee.srt。"
3. "按每秒 3.5 字估算语速，为这段 92 字文案生成总时长约 32 秒的 SRT 时间轴，第 1 句从 0.5 秒开始。"
4. "把 D:\视频\素材\ 下所有 mp4 视频逐一生成同名 SRT 字幕文件，输出到各视频同目录。"
5. "把刚生成的 coffee.srt 导入剪映草稿『咖啡评测』项目，匹配时间轴并替换当前字幕轨内容。"

**操作步骤（7 步）**

1. 先让 AI 生成文案，按句整理成纯文本（每句一行），检查语感与总字数，保存为 txt。
2. 用 Python 脚本（或剪映的智能字幕）把每句按 14 字上限二次切分，超长的句子自动拆成两句。
3. 用 ffprobe 读取视频时长，按"语速 = 字数 / 目标时长"换算每句停留秒数，逐句累计出起止时间。
4. 生成 SRT：格式为 序号、HH:MM:SS,mmm --> HH:MM:SS,mmm、字幕文本，用 UTF-8 编码保存，避免中文乱码。
5. 定位剪映草稿目录（C:\Users\你的用户名\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft\），把 SRT 复制进对应草稿文件夹。
6. 打开剪映，右键字幕轨选择"导入字幕"加载该 SRT，检查时间轴是否对齐，错位则微调首句偏移。
7. 如需全自动挂载，可解析草稿的 draft_content.json 写入字幕片段 ID，操作前先备份整个草稿文件夹。

### 25. 裁剪视频批量去除黑边，统一分辨率 1080P，压缩文件体积。

**细分能力点（5 条）**

1. 用 cropdetect 自动检测视频四周黑边位置，计算出有效画面区域。
2. 用 crop 滤镜批量裁剪顶、底、左、右黑边，保持画面内容不失真。
3. 统一缩放到 1920×1080（1080P），支持等比缩放居中裁剪或模糊底填充两种方式。
4. 用 H.264/H.265 编码 + CRF 参数压缩体积，兼顾画质与文件大小。
5. 输出到独立目录并保留原文件名，生成每个文件处理前后分辨率与体积的对照表。

**可执行提示词（5 条）**

1. "用 ffmpeg 批量裁剪 D:\视频\原片\ 下所有视频的黑边，先逐段检测黑边位置再 crop。"
2. "把裁剪后的视频统一缩放为 1920×1080，等比缩放后居中裁剪，画质优先。"
3. "用 libx264 CRF 23 压缩这批视频，目标单文件不超过 200MB，超标的再降到 CRF 26。"
4. "对黑边不均匀的视频，先用 cropdetect 分析每段有效区域，再按各自参数批量裁剪。"
5. "处理完成后把结果放到 D:\视频\处理结果\，生成一份裁剪前后分辨率、体积对照表。"

**操作步骤（7 步）**

1. 下载 ffmpeg 并加入系统 PATH，命令行验证 ffmpeg -version 可正常运行。
2. 抽取 1~2 个代表性视频运行探测命令：ffmpeg -i 输入.mp4 -vf cropdetect=limit=24:round=2:reset=0 -f null - 查看输出的 crop=宽:高:x:y。
3. 记录各视频的 crop 参数，写入批处理脚本（bat 或 Python subprocess 循环调用）。
4. 执行裁剪：ffmpeg -i 输入.mp4 -vf "crop=W:H:X:Y" -c:a copy 裁剪.mp4，保留原音轨。
5. 统一分辨率：加 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2" 或用 crop 居中裁切。
6. 压缩编码：-c:v libx264 -crf 23 -preset medium -c:a aac -b:a 192k，控制输出体积。
7. 用 ffprobe 校验输出分辨率与体积，对比原文件；对字幕嵌在黑边内的素材调低 limit 值重新探测，避免误裁。

### 34. 抓取本地音乐文件，自动补齐缺失歌手、专辑、封面信息。

**细分能力点（5 条）**

1. 扫描本地音乐目录，识别 MP3/FLAC/M4A 等格式并解析现有 ID3/元数据标签。
2. 通过音频指纹（Chromaprint/AcoustID）或文件名匹配在线数据库补全歌手、专辑、标题。
3. 从 MusicBrainz / Cover Art Archive 下载并嵌入专辑封面图。
4. 自动修正乱码标签（常见 GBK/UTF-8 编码错乱），统一为 ID3v2.3 UTF-8 规范。
5. 批量生成元数据修复报告，列出已补齐与未命中的文件，方便人工兜底。

**可执行提示词（5 条）**

1. "扫描 D:\音乐\ 下所有音乐文件，列出缺失歌手、专辑、封面信息的文件清单。"
2. "用音频指纹识别 D:\音乐\ 里标记为『未知歌手』的歌曲，从 MusicBrainz 补齐信息并写回标签。"
3. "给 D:\音乐\ 下所有 MP3 自动匹配专辑封面，找不到封面的单独标记出来。"
4. "修复这批音乐文件的乱码标签，把编码统一成 UTF-8 的 ID3v2.3，避免显示问号。"
5. "处理完后把每首歌的歌手、专辑、封面补齐情况整理成一张 Excel 表格发我。"

**操作步骤（7 步）**

1. 安装 Python，pip 安装 mutagen、pychromaprint、musicbrainzngs 等依赖库。
2. 用 mutagen 遍历目录读取每首歌的现有标签，标记缺失字段与疑似乱码（如出现 â–º 等替换符）。
3. 对缺失信息的文件，用 pychromaprint 计算音频指纹并提交到 AcoustID 识别曲目。
4. 用 musicbrainzngs 按识别结果查询歌手、专辑、曲目号、发行年份，拼装新标签。
5. 从 Cover Art Archive（或 iTunes Search API）下载封面图，用 mutagen 写入 APIC 帧。
6. 对无法识别文件，按文件名正则（如"歌手 - 专辑 - 曲名.mp3"）提取信息兜底写入。
7. 导出修复报告 CSV，人工核对高风险条目（重名曲、演唱会 Live 版、Remix 版本等）。

### 40. 批量转换音频格式，MP3/WAV/M4A 互转，统一音量大小。

**细分能力点（5 条）**

1. 支持 MP3、WAV、M4A、FLAC、OGG 等常见格式互相转换，按需指定采样率、位深、码率。
2. 转换时保留声道布局（单/双声道），音质损失可控。
3. 用 EBU R128 标准（loudnorm）统一音量，让不同来源文件的听感一致。
4. 支持整个文件夹递归批量转换，输出时保留相对目录结构。
5. 输出处理日志与每个文件转换前后格式、体积、响度对照。

**可执行提示词（5 条）**

1. "把 D:\音频\原文件\ 下所有 WAV 批量转成 320kbps MP3，输出到 D:\音频\MP3\。"
2. "把文件夹里所有 M4A 转成无损 WAV（44.1kHz / 16bit），供剪映编辑使用。"
3. "用 EBU R128 标准统一这批音频音量，目标响度 -14 LUFS、峰值不超过 -1.5 dBTP，批量处理。"
4. "转换的同时把文件名改成『歌手-歌名』格式，重名自动追加序号避免覆盖。"
5. "转完后把每个文件转换前后的格式、体积、响度整理成表格发我。"

**操作步骤（6 步）**

1. 安装 ffmpeg 并确认命令行可用（ffmpeg -version）。
2. 用 Python os.walk 遍历目标目录，收集所有音频文件并按扩展名分类。
3. 写批量转换脚本：转 MP3 用 -c:a libmp3lame -b:a 320k；转 WAV 用 -c:a pcm_s16le；转 M4A 用 -c:a aac -b:a 256k。
4. 统一音量：对每个文件执行 ffmpeg -i 输入 -af "loudnorm=I=-14:TP=-1.5:LRA=11" 输出；要求更稳定时可先测 loudnorm 单遍参数再二次应用。
5. 用 ffprobe 抽查转换后文件的格式、采样率、码率是否正确，响度是否达标（结合 ebur128 滤镜查看）。
6. 把原文件备份到独立目录，替换/归档转换结果，输出日志与对照表。

### 47. 自动拆分长音频，按停顿分割成独立片段并批量命名。

**细分能力点（5 条）**

1. 用 silencedetect 检测长音频中的静音段，按停顿位置自动切分。
2. 支持设置静音阈值（如 -30dB）、最小时长（如 1 秒）等参数控制切分粒度。
3. 切分后按时间戳自动命名（如 片段_0001_00h05m12s.mp3），方便回查。
4. 可配合 ASR 识别每段首句文字，生成内容索引清单。
5. 过滤过短片段与纯静音段，去除片头片尾无效内容。

**可执行提示词（5 条）**

1. "用 ffmpeg silencedetect 检测 D:\录音\讲座.wav 的静音段，把停顿超过 1 秒的地方切开。"
2. "把这段 2 小时讲座音频按停顿自动拆成小段，每段单独保存为 128kbps MP3。"
3. "拆分后按『片段序号_起始时间』批量重命名，如 片段_0001_00h05m12s.mp3。"
4. "先用 whisper 识别每句话的起止时间，再按话题停顿切分，输出切分点列表。"
5. "拆完后把每段的时长和首句文字生成一个索引清单给我。"

**操作步骤（7 步）**

1. 安装 ffmpeg，用 ffprobe 确认音频总时长、采样率与声道数。
2. 运行 ffmpeg -i 输入.wav -af silencedetect=noise=-30dB:d=1 -f null - 提取 silence_start / silence_end 时间点。
3. 用 Python 解析输出，把相邻静音段之间的有效区间整理成切分点数组。
4. 用 ffmpeg -ss 起点 -to 终点 -i 输入 -c copy 截取各段；WAV 可无损切分，MP3/M4A 建议重新编码避免时间轴偏移。
5. 过滤掉时长过短（如 <3 秒）的片段，合并间隔极近的相邻段，跳过首尾大段静音。
6. 按"序号_起始时间"规则批量重命名，可选调用 whisper 识别每段首句文字。
7. 抽查几段的开头、结尾是否裁切自然，音量为是否正常，最终输出索引清单。

### 52. 批量截取视频关键帧，导出高清产品展示图片素材。

**细分能力点（5 条）**

1. 从视频中按固定间隔或场景变化自动抽取关键帧。
2. 用场景检测滤镜（select='gt(scene,0.4)'）提取画面变化明显的帧。
3. 导出 JPG/PNG 高清图，可指定宽度与画质（如 JPG q:v 2）。
4. 按"视频名-时间戳-帧序号"批量命名，便于对照回查。
5. 抽取后自动剔除模糊帧与重复帧，只保留清晰且构图不同的画面。

**可执行提示词（5 条）**

1. "从 D:\视频\产品\ 下每个视频每 5 秒抽一帧，导出宽 1920 的高清 JPG。"
2. "用场景检测方式抽取画面变化明显的关键帧，阈值 0.4，存成 PNG。"
3. "批量抽取 D:\产品视频\ 全部视频的关键帧，作为电商主图素材，命名带时间戳。"
4. "抽取后自动剔除模糊帧和几乎相同的重复帧，每个视频最多保留 20 张。"
5. "把抽出的关键帧按商品名建子文件夹归档，并生成图片清单表格。"

**操作步骤（7 步）**

1. 安装 ffmpeg，确认输入视频编码可解码。
2. 按间隔抽帧：ffmpeg -i 输入.mp4 -vf fps=1/5 -q:v 2 -vsync vfr 输出目录\帧_%04d.jpg，即每 5 秒一张。
3. 按场景抽帧：ffmpeg -i 输入.mp4 -vf "select='gt(scene,0.4)',showinfo" -f null - 先打印符合条件帧的时间戳。
4. 对选中时间点执行 -ss 时间 -i 输入 -frames:v 1 精确导出单帧。
5. 用 PIL/OpenCV 计算每张图的拉普拉斯方差，数值低于阈值（如 <60）判定为模糊帧剔除。
6. 用感知哈希（dhash）计算图片相似度，去重构图几乎一致的帧。
7. 按"视频名_时间戳_序号"重命名，归档到子文件夹，生成图片清单表格。

### 61. 批量提取视频音频，分离音轨保存为独立音频文件。

**细分能力点（5 条）**

1. 从视频（MP4/MKV/AVI 等）中提取主音轨为独立音频文件。
2. 支持提取多音轨（多语言、解说轨、评论轨），按语言标签区分命名。
3. 可选无损提取（-c copy 不重新编码）或转码为 MP3/WAV/M4A。
4. 批量处理整个文件夹，输出到独立目录并保留原文件名。
5. 支持单独导出某一声道（如左声道、右声道分离）。

**可执行提示词（5 条）**

1. "把 D:\视频\ 下所有 MP4 的音轨提取出来，保存为 320kbps MP3 到 D:\音频\提取\。"
2. "批量提取 MKV 文件里所有音轨，按语言标签命名，如 电影_国语.m4a、电影_原声.m4a。"
3. "用不重新编码的方式把视频里的 AAC 音轨直接抽出来存成 m4a。"
4. "把这段视频的左声道和右声道分别导出成两个独立音频文件。"
5. "提取完把每个视频的音频时长、码率、声道数汇总成一张表格。"

**操作步骤（6 步）**

1. 安装 ffmpeg 并确认可用。
2. 用 ffprobe -select_streams a -show_streams 视频.mp4 查看音轨数量、编码与语言标签。
3. 无损提取主音轨：ffmpeg -i 视频.mp4 -map 0:a:0 -c copy 音频.m4a。
4. 需要转码时加编码参数：-c:a libmp3lame -b:a 320k（MP3）或 -c:a pcm_s16le（WAV）。
5. 多音轨用 -map 0:a:N 逐条导出，配合 -metadata:s:a language 写入语言标签，按语言命名文件。
6. 分离声道用 -af "pan=mono|c0=FL" 和 "pan=mono|c0=FR"，批量循环整个目录，输出日志与汇总表。

### 64. 读取监控摄像头录像，自动标记移动画面截取片段。

**细分能力点（5 条）**

1. 用背景减除（MOG2）或帧差法检测画面中的运动区域。
2. 标记运动事件起止时间，自动截取包含移动画面的视频片段。
3. 按运动面积、持续时间过滤误报（光线变化、树叶晃动、飞虫）。
4. 在截取片段上叠加时间戳水印，便于取证回查。
5. 批量处理多路/多日录像，生成事件日志与缩略图预览。

**可执行提示词（5 条）**

1. "分析 D:\监控\ 下今天的录像，检测画面里有人/车移动的时间段，输出事件时间表。"
2. "把检测到移动画面的片段自动截取保存，每个片段前后各保留 10 秒，并叠加时间水印。"
3. "用背景减除法过滤静止画面，只标记移动面积占比超过 0.5% 的事件，避免树叶晃动误报。"
4. "把多路摄像头同一时间段的移动事件合并成一个按时间排序的日志。"
5. "扫描最近 7 天监控录像，提取所有夜间 20:00-06:00 的移动事件并汇总。"

**操作步骤（7 步）**

1. 安装 Python 与 OpenCV（pip install opencv-python）。
2. 用 cv2.VideoCapture 逐帧读取，配合 createBackgroundSubtractorMOG2 生成前景掩码。
3. 对掩码做形态学开闭运算（腐蚀+膨胀）去除噪点，减少光线抖动与树叶晃动干扰。
4. 计算前景面积占画面比例，超过阈值（如 0.5%）且持续超过 2 秒时判定为一次事件。
5. 记录事件起止帧时间，扩展前后缓冲各 10 秒，用 ffmpeg 按时间戳截取片段。
6. 用 drawtext 滤镜在片段叠加时间戳水印，保存到"事件片段"文件夹。
7. 生成事件日志 CSV（时间、时长、运动强度、文件路径）与缩略图网格，供快速浏览。

2. "把这段口播文案转成分镜脚本，镜头总时长自动核算到 45 秒，台词按镜头拆分。"
3. "为这套护肤产品出 3 个版本的 30 秒分镜脚本：口播版、剧情版、特效版。"
4. "给每个镜头补充运镜说明（推、拉、摇、移、跟、升降）和拍摄机位建议。"
5. "把分镜脚本导出成 Excel 表格，列：镜头、时长、景别、画面、台词、运镜、备注。"

1. 明确主题、目标时长、发布平台（抖音/小红书/B站）与视频风格。
2. 让 AI 生成分镜初稿，划分镜头并标注景别（远景/全景/中景/近景/特写）。
3. 用表格模板整理：镜头号、时长、画面内容、台词、运镜、场景/道具、备注。
4. 核算各镜头时长总和，与目标时长比对，超时则压缩镜头或删减冗余镜头。
5. 逐镜头补充运镜说明（推、拉、摇、移、跟、升降、环绕）与转场建议。
6. 批量处理多个选题：一次性生成多份脚本，统一导出为 Excel/CSV。
7. 把脚本发给拍摄/剪辑人员核对可行性，按实际素材微调时长与运镜。

### 85. 批量去除音频杂音，降噪处理导出清晰录音文件。

**细分能力点（5 条）**

1. 分析音频频谱，识别并抑制稳态底噪（风扇、电流声、白噪音）。
2. 处理瞬态杂音（鼠标点击、键盘声、咳嗽、爆音）。
3. 支持批量处理整个录音文件夹，保持采样率、时长不变。
4. 提供降噪强度/参数调节，针对人声优化，保留语音清晰度。
5. 输出降噪前后对比与响度统一检查，导出干净 WAV/MP3。

**可执行提示词（5 条）**

1. "用 ffmpeg 的 afftdn 滤镜去除这段录音的背景电流声，强度中等，导出干净版本。"
2. "对 D:\录音\访谈\ 文件夹里所有 WAV 批量降噪，去掉空调底噪，保留人声清晰。"
3. "把这段视频的解说轨降噪处理，抑制键盘敲击声，输出 320kbps MP3。"
4. "用 Audacity 的降噪流程处理这个录音：先截取纯噪声样本，再对整段应用降噪。"
5. "降噪后统一响度到 -16 LUFS，并和原文件做对比，保证人声不发闷。"

**操作步骤（7 步）**

1. 安装 ffmpeg 和 Audacity（Audacity 适合手动精细降噪，ffmpeg 适合批量）。
2. 先用 ffmpeg 导出频谱图或 Audacity 频谱视图，判断噪声类型（稳态底噪还是瞬态杂音）。
3. ffmpeg 批量降噪：-af "afftdn=nf=-25:tn=1" 处理稳态噪声，或 -af "arnndn=m=模型.rnnn" 用 RNNoise 针对人声优化。
4. Audacity 方式：选中约 1 秒纯噪声段，效果 → 降噪 → 获取噪声样本，再全选整段应用降噪，预览后调整强度。
5. 对瞬态爆音用 -af "deesser"、限制器，或 Audacity 中手动选中削波段静音修复。
6. 用 loudnorm=I=-16:TP=-1.5 统一响度，导出干净版本，与原文件对比试听微调参数。
7. 写批量脚本循环整个目录，输出到"已降噪"子目录，保留原文件。

### 96. 自动识别短视频字幕，批量导出纯文本字幕文件备用。

**细分能力点（5 条）**

1. 用 Whisper（本地运行）或剪映/通义听悟对视频做语音转文字，生成带时间戳字幕。
2. 输出 SRT/VTT/TXT 等多种格式，中英文均可识别，支持自动语言检测。
3. 自动去除口语语气词（嗯、啊、那个）与重复，整理成干净文稿。
4. 对识别结果做标点、断句、分段优化，方便二次创作使用。
5. 批量处理文件夹内所有短视频，输出与视频同名的字幕文件。

**可执行提示词（5 条）**

1. "用 Whisper 识别 D:\视频\ 下所有短视频的语音，输出中文 SRT 字幕文件。"
2. "把这段视频转成纯文本字幕，去掉『嗯』『啊』等语气词，标好标点和分段。"
3. "批量识别这批英文视频并翻译成中文，输出中英对照的 SRT 字幕。"
4. "识别后按句分段，每句不超过 20 字，生成适合发布到抖音的紧凑字幕。"
5. "把识别结果整理成 Word 文稿，按段落分好，作为公众号文章素材。"

**操作步骤（7 步）**

1. 安装 Python，pip install openai-whisper（内存紧张可用 faster-whisper + int8 量化）。
2. 首次运行会自动下载模型，中文识别推荐 medium 及以上模型，长视频选 faster-whisper 加速。
3. 运行 whisper 视频.mp4 --language zh --task transcribe --output_format srt --output_dir D:\字幕\ 生成字幕。
4. 长视频可先按段落切片再并行识别，或用 faster-whisper 的 VAD 过滤静音段加速。
5. 用脚本清洗文本：去语气词、合并过短句、修正常见同音错别字（如"在"与"再"）。
6. 导出 TXT 纯文本与 SRT 两种格式，文件与视频同名，统一存到字幕目录。
7. 抽查 2~3 句核对准确率；对专业名词、人名，用 initial_prompt 或热词表提升识别效果。
