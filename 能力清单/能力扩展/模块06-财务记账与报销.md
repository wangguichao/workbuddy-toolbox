# 财务记账与报销（模块 06）

> 该模块把以下能力扩展为**可直接发送给 Workbuddy 的提示词**与**对话式操作步骤**。所有任务只需向 Workbuddy 发指令即可完成，无需手动搭建环境。原始条数 6，共 90~120 个扩展条目。

### 5. 每天下午 2 点 30 分发送邮件告知基金价格，并整合前 1/5/10 天价格生成简报。

**细分能力点（5 条）**

1. 支持自定义监控基金列表，指数基金/ETF/主动基金均可，基金代码随时增删。
2. 自动抓取当日最新净值/收盘价，与前一交易日对比计算单日涨跌幅。
3. 按 1 个、5 个、10 个交易日三个区间统计区间涨跌幅，辅助判断短期趋势。
4. 每天 14:30 自动发送 HTML 邮件，正文含价格表格与近 10 日净值走势图。
5. 内置异常预警：单日跌幅超过阈值或连续多天下跌时，在邮件中高亮提醒。

**可执行提示词（5 条）**

1. "监控这几只基金：510300、159915、588000，每天 14:30 把当日净值、单日涨跌、近 1/5/10 日涨跌幅整理成表格，用邮件发到 zhangsan@qq.com。"
2. "帮我把基金日报做成 HTML 邮件，正文含价格表格和一张近 10 个交易日的净值走势图，每天下午 2 点半自动发送。"
3. "如果 510300、159915、512880 里任意一只单日跌幅超过 3%，在邮件标题和正文中标红提醒我。"
4. "把我要监控的基金列表整理成一个清单放好，方便我以后自己增删基金，每次发送都按最新清单来。"
5. "先帮我跑一次基金简报：抓取 510300、159915、588000 的最新净值和近 5 日、10 日涨跌，发到我的邮箱，我看下效果。"

**操作步骤（6 步）**

1. 向 Workbuddy 发送指令：「监控这几只基金：510300、159915、588000，每天 14:30 自动抓取净值并计算近 1/5/10 日涨跌，整理成表格邮件发到 zhangsan@qq.com。」
2. Workbuddy 会先确认细节：收件邮箱、发送时间、是否要走势图、统计口径，按需补充说明。
3. 确认后，Workbuddy 自动完成数据抓取、计算、生成图表、发送邮件的整套流程，你无需安装任何软件或写代码。
4. 首次执行后打开邮件核对：数据是否准确、图表是否正常、是否准点；发现问题直接反馈给 Workbuddy 调整。
5. 以后要改监控清单或时间，直接说：「把 510300 换成 512880」「改到上午 9:30 发送」，Workbuddy 立即更新。
6. 想暂停就说「暂停基金日报」，想恢复说「恢复」，Workbuddy 会帮你管理好这个定时任务。

### 14. 扫描发票截图，自动提取信息填好报销表。

**细分能力点（5 条）**

1. 支持 JPG/PNG/PDF 多种格式，兼容手机拍照、屏幕截图、扫描仪输出三类来源。
2. 自动提取发票号码、开票日期、购买方/销售方名称、价税合计金额、税额、税号等关键字段。
3. 自动识别发票类型（增值税普票/专票/电子发票）并按费用类别初步归类。
4. 识别结果自动写入标准报销台账 Excel，列名与公司报销模板对齐，可直接导入 OA。
5. 识别后做校验：金额合法性、日期格式与范围检查，异常条目单独标记待人工核对。

**可执行提示词（5 条）**

1. "识别这张发票图片 D:\报销\发票.jpg，提取发票号、开票日期、价税合计金额、销售方名称，填入报销表模板。"
2. "批量识别 D:\报销发票\ 目录下所有 JPG/PNG/PDF 发票，提取发票号、日期、金额、税额、销售方、类别，输出成 Excel 报销台账。"
3. "把识别出的发票按『交通、餐饮、办公、其他』四类归类，金额保留两位小数，生成月度报销汇总表。"
4. "检查这批发票里金额为负数或日期超出本月范围的记录，单独列一个工作表标黄，方便我人工核对。"
5. "每月月底自动扫描 D:\报销发票\ 文件夹，识别新增发票并更新报销台账，生成当月报销清单发给我。"

**操作步骤（6 步）**

1. 把需要报销的发票截图统一放到 D:\报销发票\ 文件夹。
2. 向 Workbuddy 发送指令：「帮我把 D:\报销发票\ 文件夹里的发票批量识别，提取发票号、开票日期、金额、销售方，整理成报销台账 Excel。」
3. Workbuddy 会确认输出格式：台账列名、保存路径、是否按月份/类别归档，按需补充（如"保存到 D:\报销台账\，按月份分表"）。
4. 确认后，Workbuddy 自动完成识别、校验、生成台账，你无需手动安装识别软件或写脚本。
5. 打开生成的台账检查字段准确性，有识别错的地方直接指出来让 Workbuddy 修正。
6. 想定时处理就告诉 Workbuddy：「每周五 17:00 自动扫描新增发票，更新台账并发我当周报销清单。」以后新增发票只需说「更新报销台账」。

### 18. 自动记账，将支付宝和微信账单的导出文件自动分类统计、生成月度消费报告。

**细分能力点（5 条）**

1. 支持解析支付宝、微信导出的账单文件（CSV/Excel 常见格式），自动识别列名与编码。
2. 统一字段结构：交易时间、交易类型、金额（正负号）、收付款方、商品说明、支付渠道。
3. 自动打消费分类标签（餐饮、交通、购物、居住、娱乐、转账、退款等），分类规则可自定义。
4. 合并去重：同一笔交易在微信、支付宝重复出现时按金额+时间去重，退款自动冲抵支出。
5. 按月/类别/渠道三维统计，生成月度消费报告与饼图、柱状图、周趋势图。

**可执行提示词（5 条）**

1. "解析 D:\账单\支付宝-2026年08月.csv 和 微信支付账单(2026-08).xlsx，合并后按类别统计 8 月消费总额。"
2. "把支付宝账单里的商家名按『餐饮、交通、购物、居住、娱乐』等类别自动分类，输出分类结果表。"
3. "生成 2026 年 8 月消费报告：总支出、各分类金额和占比、环比上月变化，用饼图和柱状图展示。"
4. "找出同一笔在支付宝和微信里重复记账的交易（金额相同且时间相差 5 分钟以内），去重后只保留一条。"
5. "把上个月支出按周汇总，标出单笔超过 1000 元的大额支出，生成提醒清单发给我。"

**操作步骤（6 步）**

1. 从支付宝和微信分别导出账单文件（支付宝：账单页→开具交易流水证明→导出 CSV；微信：钱包→账单→下载账单→发到邮箱），放到 D:\账单\。
2. 向 Workbuddy 发送指令：「解析我支付宝和微信的 8 月账单，合并去重后按类别统计，生成月度消费报告。」
3. Workbuddy 会确认账单文件位置、分类规则、报告格式，按需补充（如"外卖和餐饮单独统计"）。
4. 确认后，Workbuddy 自动完成解析、分类、去重、统计与图表生成，你无需写任何代码。
5. 查看生成的消费报告，对分类不准确的地方告诉 Workbuddy（如"把这笔归到交通"），它会记住规则。
6. 想每月自动出报告，告诉 Workbuddy：「每月 1 号自动分析上个月账单，生成消费报告发我。」

### 53. 解析银行流水表格，自动区分工资、消费、转账分类统计。

**细分能力点（5 条）**

1. 支持招商银行、工商银行、建设银行等主流银行导出的流水（Excel/CSV/PDF 均可解析）。
2. 自动识别流水字段：交易日期、收入、支出、余额、对方户名、摘要/附言。
3. 智能分类：工资（固定日期入账、摘要含"代发"）、消费（商户刷卡/扫码）、转账（本人他卡或转他人）。
4. 工资按月汇总核对，拆分应发工资与社保、公积金、个税等代扣项目。
5. 输出月度/年度收支分类统计表与图表，支持与记账 App 数据交叉比对。

**可执行提示词（5 条）**

1. "解析招商银行 2026 年 1-8 月流水表 D:\流水\交易流水.xlsx，把每一笔分为工资、消费、转账、利息、其他五类并统计。"
2. "从流水里识别工资记录（每月固定日期入账、摘要含代发工资），统计每月实发工资，并列出社保、公积金、个税代扣金额。"
3. "把转给本人另一张卡的转账和转给他人的转账分开统计，转给他人的按月份汇总总额。"
4. "生成 2026 年消费分类统计图，把刷卡消费按商户类型（超市、餐饮、加油站、网购）细分。"
5. "把流水里的收入、支出、结余做成月度收支表，和我记账 App 的数据对比，不一致的列出来。"

**操作步骤（6 步）**

1. 在手机银行/网银导出流水（Excel/CSV 优先，导出时勾选含摘要/附言），放到 D:\流水\。
2. 向 Workbuddy 发送指令：「解析这份银行流水，把每笔分为工资、消费、转账、利息、其他五类，生成分类统计。」
3. Workbuddy 会确认分类规则和统计口径，按需补充（如"工资按摘要含代发识别"）。
4. 确认后，Workbuddy 自动完成流水解析、分类、月度统计和图表生成。
5. 核对统计结果与银行余额是否一致，不一致告诉 Workbuddy 排查原因。
6. 以后每月导出新流水，直接说「更新流水分析」，Workbuddy 会增量处理并对比上月。

### 71. 自动汇总各部门报销单据，核算总金额生成报销汇总单。

**细分能力点（5 条）**

1. 按部门文件夹批量读取统一模板的报销单据（Excel/CSV），支持递归遍历子目录。
2. 按部门、费用类别（差旅、餐饮、办公、通讯）分组核算单据数与金额。
3. 自动校验：发票号是否重复、单笔金额是否超标准、报销日期是否在当月，违规项标出。
4. 生成报销汇总单：总金额、各部门小计、单据数、报销人次，交叉统计部门×类别。
5. 输出 Excel 汇总单并支持转成 Word/PDF 打印版，供财务负责人签字。

**可执行提示词（5 条）**

1. "汇总 F:\报销单\各部门\ 文件夹下各部门提交的 Excel 报销单，核算每部门总金额和单据数。"
2. "把所有报销单据按部门分组，列出部门、报销人、单据数、金额小计、占比，生成一张汇总单。"
3. "检查各部门报销单里发票号是否重复、单笔金额是否超过 5000 元标准，超标的标红并列出问题清单。"
4. "生成 2026 年 8 月报销汇总单 Excel，包含总表、按部门 Sheet、按类别 Sheet，金额自动求和。"
5. "把各部门报销汇总单转成 Word 版（含表格和合计行），方便财务负责人签字打印。"

**操作步骤（6 步）**

1. 让各部门按统一模板（部门、报销人、日期、类别、金额、发票号、备注）填好 Excel，放到 F:\报销单\各部门\ 下对应的部门文件夹。
2. 向 Workbuddy 发送指令：「汇总各部门报销单，按部门核算金额和单据数，生成汇总单，并校验重复发票和超标准金额。」
3. Workbuddy 会确认模板字段、校验规则（如单笔上限 5000 元）、输出格式，按需补充。
4. 确认后，Workbuddy 自动遍历文件夹、汇总统计、执行校验并生成汇总单。
5. 查看问题清单，对重复发票、超标项逐一处理；需要 Word 版就直接说「转成 Word 打印版」。
6. 以后每月末，把各部门新单据放进文件夹，说「更新本月报销汇总」，Workbuddy 自动重算。

### 75. 自动统计外卖、打车消费，生成月度生活开销分布图。

**细分能力点（5 条）**

1. 自动收集美团、饿了么、滴滴等平台的外卖与打车订单记录（导出或批量整理）。
2. 按平台、月份统计外卖与打车消费金额和订单数，计算平均单均价格。
3. 识别高频商家、高频路线（起点-终点组合），生成 Top 消费对象榜单。
4. 按周/日对比消费趋势，标记消费异常偏高的日期便于自查。
5. 生成月度生活开销分布图（外卖 vs 打车占比饼图 + 每日支出趋势图）并输出报告。

**可执行提示词（5 条）**

1. "统计 2026 年 8 月美团外卖支出，按周汇总，算出平均每单价格，列出消费最多的前 3 家店。"
2. "解析滴滴出行订单明细 D:\账单\滴滴-2026-08.xlsx，按打车类型（快车、专车、拼车）统计费用和订单数。"
3. "把外卖和打车账单合并，生成 8 月生活开销分布图：外卖 vs 打车占比饼图 + 每日支出趋势图。"
4. "对比 7 月和 8 月的外卖支出，找出涨幅超过 30% 的类别，分析是否集中在周末或加班日。"
5. "设置提醒：当本月外卖 + 打车累计超过 1000 元时，推送一条月度预警和分类消费明细。"

**操作步骤（6 步）**

1. 导出订单数据：美团（钱包→账单）、滴滴（钱包→账单）导出 Excel/CSV，放到 D:\账单\。
2. 向 Workbuddy 发送指令：「解析我的外卖和打车账单，统计月度支出，生成消费分布图。」
3. Workbuddy 会确认账单文件、分类方式（商家/打车类型）、图表形式，按需补充。
4. 确认后，Workbuddy 自动统计总支出、订单数、单均价，识别高频商家并生成分布图。
5. 查看图表，想深入分析就说「对比上月涨幅」或「找出消费最高的前 3 家店」。
6. 设阈值提醒：「外卖+打车月累计超 1000 元时提醒我」，Workbuddy 会持续盯着账单。
