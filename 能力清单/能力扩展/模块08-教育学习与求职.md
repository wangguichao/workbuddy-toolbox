### 4. 将你的简历每天投递给100个hr

**细分能力点（5 条）**

1. 自动解析简历 PDF/Word，提取教育背景、工作经历、技能关键词等结构化字段。
2. 根据简历关键词与目标岗位说明做匹配打分，自动筛选高匹配岗位生成投递队列。
3. 支持对接招聘平台（Boss直聘、前程无忧、智联等）自动填写在线简历与申请表单。
4. 内置投递节奏控制：设置每日上限、投递间隔，避免触发平台反垃圾机制。
5. 自动生成投递日志与进度看板：已投、已读、被查看、面试邀约，按周生成复盘报表。

**可执行提示词（5 条）**

1. "解析 D:\求职\我的简历.docx，提取教育背景、工作经历、技能关键词，整理成结构化文本输出。"
2. "根据简历里的『Python后端开发』『Django』『MySQL』关键词，帮我搜索并筛选 100 个高匹配岗位，按匹配度从高到低排序。"
3. "为每个目标岗位生成定制化求职信，开头插入公司名称和岗位职责关键词，控制在 100 字以内。"
4. "把筛选出的 100 个岗位导出成 Excel，包含公司、职位、薪资范围、工作地点、匹配理由，投递前逐条核对。"
5. "每天上午 9 点自动投递 100 个岗位，投递间隔 60 秒，完成后把投递结果同步到日志表，投满后暂停并生成日报。"

**操作步骤（8 步）**

1. 用 Word 或在线工具把简历排版规范，重点技能词在显眼位置，便于机器解析。
2. 安装 Python，执行 `pip install python-docx pypdf2 pandas openpyxl`，准备解析与表格处理环境。
3. 用 python-docx / PyPDF2 读取简历，提取姓名、城市、工作年限、技能、期望薪资等字段。
4. 优先使用招聘平台的官方开放 API 或企业版批量投递功能（合规方式）；没有 API 的平台采用模拟真实操作的半自动方式，每次投递间隔随机 60~120 秒，切勿高频并发。
5. 用 pandas 维护岗位候选表，设置硬性过滤条件（城市、薪资下限、排除外包/派遣），计算关键词匹配分。
6. 逐条生成定制求职信，写入投递备注栏，提高已读与回复率。
7. 用 openpyxl 维护投递日志（平台、公司、职位、投递时间、状态），每天结束自动汇总。
8. 每周复盘面试邀约率，把零回复岗位的关键词做减法，反向优化简历与筛选条件，再调整次日投递名单。

### 12. 出一张小学数学试卷

**细分能力点（5 条）**

1. 支持指定年级、学期、单元与难度生成对应题型，题目贴合课标。
2. 题型覆盖口算、填空、选择、判断、脱式计算、应用题，分值可自定义。
3. 自动生成标准答案与分步解析，方便家长批改和学生自查。
4. 输出标准 A4 排版的 Word 或 PDF，含姓名、班级、得分栏、题号区。
5. 支持一键生成 A/B 卷、多轮随机换题，以及基于错题生成强化卷。

**可执行提示词（5 条）**

1. "出一张三年级下册数学期末模拟卷，覆盖两位数乘除法、分数初步、长方形面积，难度中等，总分 100 分，附答案。"
2. "生成 20 道 100 以内加减法口算题，结果不出现负数，排列成 4 行 5 列，等号后留空。"
3. "把 5 道应用题改成生活化场景：超市购物找零、平均分糖果、课桌排座位，每题附分步解析。"
4. "把这份试卷导出成 Word，A4 竖版，标题居中，每题留答题空，结尾放家长签字栏。"
5. "根据这份试卷的错题分布，再生成 10 道同类强化题，难度逐题递进，并附讲解思路。"

**操作步骤（7 步）**

1. 明确年级、教材版本（人教版/北师大版/苏教版）、单元范围与难度目标，写入需求清单。
2. 让 AI 生成题目初稿，人工核对知识点归属与计算正确性，防止超纲或数值算错。
3. 用 pandas / 简单脚本校验每道题的答案可解性（如口算题代入验算）。
4. 用 python-docx 生成试卷 Word：设置 A4 页边距、标题居中、小题自动编号、答题留白行。
5. 单独生成答案页，解析分步书写，与试卷分开以便先做题后对答案。
6. 用 Word 的"另存为 PDF"或 docx2pdf 导出 PDF，打印前预览检查排版错位、换页截断。
7. 把学生做错的题目单独提取，调高同类题占比再生成一份强化卷。

### 19. 填报高考志愿，将位次、省份、文理科告诉workbuddy，它会帮你筛选匹配的学校和专业，生成多档志愿方案

**细分能力点（5 条）**

1. 支持输入位次、省份、科类（文科/理科）或新高考选科组合，作为核心筛选依据。
2. 抓取目标院校专业近三年录取位次、分数、招生计划，建立院校-专业数据库。
3. 采用"冲、稳、保"三档策略生成多档志愿方案，每档给出录取概率区间。
4. 结合院校层次、城市、专业热度、选科要求做多维度匹配说明。
5. 输出结构化 Excel 志愿表，供填报系统逐一对照录入，并标注需要人工核验项。

**可执行提示词（5 条）**

1. "我是 2026 年广东物理类考生，省位次 18000，帮我筛选『冲、稳、保』三档各 15 所院校专业组。"
2. "抓取近三年『计算机科学与技术』专业在广东省的最低录取位次与平均分，整理成对比表格。"
3. "按我的偏好（城市：广州/深圳/杭州；专业：计算机类；院校：双一流）生成 45 个志愿初筛表，标注选科限制。"
4. "把冲稳保方案导出成 Excel：含院校、专业组、上年位次、录取概率区间、理由，方便对照填报。"
5. "逐条提醒我核对 2026 年招生计划、体检要求、单科限制与《招生章程》，标注不能盲报的专业组。"

**操作步骤（8 步）**

1. 收集本人信息：位次、省份、科类/选科组合、意向城市、专业方向、是否服从调剂，整理成一份需求清单。
2. 抓取本省教育考试院公布的一分一段表，把位次换算成往年等效分（注意以官方公布为准）。
3. 合规抓取院校数据：优先使用教育部阳光高考平台、省考试院官网、掌上高考等公开渠道，用 requests + BeautifulSoup 解析页面，请求间隔加 1~2 秒延迟避免被封。
4. 用 pandas 把各院校专业近三年位次、分数、招生人数整理成统一结构，缺失年份做标记不臆造。
5. 按位次匹配策略分档：冲（等效分略高于往年录取线）、稳（基本持平）、保（明显低于，留 20% 以上余量）。
6. 过滤掉选科要求、体检限制、单科要求不满足的专业组，再用 python-docx/openpyxl 生成志愿表 Excel。
7. 强调人工复核：志愿填报数据以当年省考试院公布的招生计划为准，抓取结果只做参考，切勿直接照抄。
8. 与家人、班主任讨论后调整院校顺序与调剂策略，在正式填报截止前锁定最终方案。

### 29. 生成初高中英语单词默写表，附带音标、释义、填空题型

**细分能力点（5 条）**

1. 支持导入单词书/考纲词表（如高考 3500 词、中考 1600 词）批量生成默写表。
2. 自动为每个单词补全音标、词性、中文释义，支持中英对照。
3. 生成多种默写题型：英译汉、汉译英、首字母填空、语境填空，可自由组合。
4. 按单元/批次切分，支持每天固定词量（如每天 20 词）形成复习计划。
5. 导出可打印 Word/PDF，答案单独成页，并自动沉淀错词生成"错词本"。

**可执行提示词（5 条）**

1. "从《高考英语3500词》词表生成第 1~50 个单词的默写表，每行含单词、音标、词性、中文释义。"
2. "按单元 1 的单词生成英译汉 20 题、汉译英 20 题，顺序打乱，答案单独一页。"
3. "用这些单词出 10 道语境填空题，把目标词挖空，给出句子中文翻译提示。"
4. "把单词表按每天 20 个切分成 5 天复习计划，导出成 Word，标明天数和单元名。"
5. "把上周默写错的 30 个词生成加强默写表，错 2 次以上的词各重复出 3 遍，附辨析要点。"

**操作步骤（7 步）**

1. 准备词表：从教材附录或考纲 Excel/CSV 获取单词列表，确保单词、音标、释义字段完整。
2. 用 pandas / openpyxl 读取词表并清洗：去重、删除空行、统一音标格式。
3. 补全缺失音标与释义，可借助在线词典接口（如有道/百词斩公开接口）批量查询，注意接口调用频率。
4. 编写 Python 脚本随机打乱单词顺序，按题型模板生成题面（英译汉、汉译英、填空）。
5. 用 python-docx 生成默写表 Word：设置中英文字体、行间距，每题后留空白行，答案页单独一节。
6. 导出 PDF 打印，首次打印一页样本核对音标符号与排版是否正常。
7. 每次默写后把答错单词登记进错词本（Excel），每周末从错词本重新组卷生成强化表。

### 50. 生成中小学寒暑假作业练习题，附带标准答案与解析

**细分能力点（5 条）**

1. 支持按年级、学科、教材版本与知识点范围批量生成练习题。
2. 题型覆盖计算、填空、选择、判断、应用、阅读理解，难度可分级。
3. 自动生成标准答案与分步解析，标注知识点与解题思路。
4. 支持按天/周拆分作业量，生成假期作业日历与进度表。
5. 输出 A4 排版的 Word/PDF，含班级、姓名、日期、家长签字栏。

**可执行提示词（5 条）**

1. "生成 20 道五年级数学寒假作业题，覆盖小数乘除法、多边形的面积，难度中等，附标准答案和解析。"
2. "把一年级语文暑假作业拆成 30 天，每天 10 分钟量，内容含拼音、生字、组词、一句话写话。"
3. "出 15 道『鸡兔同笼』变式应用题，难度递进，第 1 题最简单、最后 2 题偏难，附图解解析。"
4. "把整套作业导出成 Word：第一页写班级、姓名、日期，每章标题加粗，结尾放家长签字栏。"
5. "根据这周做错的题目生成 10 道同类巩固题，把错误率最高的题型多出 3 道。"

**操作步骤（7 步）**

1. 明确年级、学科、教材版本、假期时长与每日建议时长，形成作业规划表。
2. 让 AI 按知识点生成题目初稿，家长先审核一遍，剔除超纲、表述不清或答案有误的题。
3. 按题型分类组织，控制总题量与答题时间在每日计划内，难度分布"基础:中等:拔高 ≈ 6:3:1"。
4. 用 python-docx 生成作业 Word：设置 A4 版式、大题标题、题号、答题留白，选择题保留选项。
5. 单独生成答案与解析页，每题标注所属知识点，方便辅导时讲解。
6. 导出 PDF 预览确认排版，再按天拆分文件命名（如 07月15日-语文.docx），供打印装订。
7. 作业完成后统计错题分布，把高频错题生成假期末"巩固收尾卷"。

### 69. 抓取考研院校历年分数线，整理对比表格方便择校

**细分能力点（5 条）**

1. 支持抓取目标院校历年复试分数线、录取最低分/平均分与国家线。
2. 按院校、专业、年份三个维度整理成结构化对比表格。
3. 自动计算分数趋势、涨幅与波动区间，辅助判断上岸难度。
4. 结合报录比、招生人数等指标生成多校横向对比与择校建议。
5. 输出 Excel 对比表并绘制分数趋势图（折线图），便于直观比较。

**可执行提示词（5 条）**

1. "抓取 2021-2026 年考研『计算机技术』专业学硕国家线，整理成表格并标注单科线。"
2. "抓取北京大学、上海交通大学、浙江大学计算机专硕近三年复试分数线与录取平均分，做横向对比。"
3. "把分数线按年份画成折线图，标注逐年涨幅，保存成 PNG 图片到 D:\考研择校\。"
4. "结合各校报录比与招生人数，评估 380 分报考这几所学校的上岸概率，给出冲稳保择校建议。"
5. "把抓取结果导出成 Excel：院校、专业、年份、复试线、录取平均分、涨幅、报录比，按院校分组。"

**操作步骤（8 步）**

1. 列出目标院校与专业清单（建议 10~20 所，含一个保底校），整理成表格。
2. 安装 Python，执行 `pip install requests beautifulsoup4 pandas openpyxl matplotlib`。
3. 合规抓取数据：优先用研招网、院校研究生院官网、省教育考试院公布的历年复试线，用 requests 获取页面，BeautifulSoup 解析表格。
4. 抓取时请求间隔 1~2 秒，设 UA 头；遇到反爬/验证码时改用官网公布的 PDF/Excel 附件下载解析，不要暴力爬取。
5. 用 pandas 清洗数据：统一年份与分数格式，缺失项标记 NaN，不凭空补值。
6. 计算每个专业的均值、最高分、近三年涨幅与波动幅度，用 matplotlib 画折线趋势图。
7. 用 openpyxl 生成对比 Excel，按院校分组，Sheet 间设"对比总表"与"各校明细"。
8. 最终以各院校研究生院官网当年最新文件为准人工复核一遍，避免爬取错版本或旧数据误导择校。

### 94. 抓取各类考试真题，自动分章节整理成套模拟试卷

**细分能力点（5 条）**

1. 支持抓取公开真题网页/PDF（中考、高考、考研、资格考试等）并按学科归类。
2. 自动识别题目所属章节/知识点，打上章节标签。
3. 按章节重组题库，支持随机抽题生成套模拟卷，控制题型与分值比例。
4. 自动生成答案与解析，标注题目难度等级（基础/中等/拔高）。
5. 导出可打印的 Word/PDF 试卷与配套答案页。

**可执行提示词（5 条）**

1. "抓取近 5 年中考数学真题，按『函数』『几何』『概率统计』三个章节分文件夹整理。"
2. "从这份《经济法基础》真题 PDF 里提取单选、多选、判断三类题型，统计各章节分值占比。"
3. "把『函数』章节的历年真题抽 15 道组成一套模拟卷，题型分布按中考真题比例，附答案。"
4. "把整理好的题库导出成 Word 试卷：格式含题号、分值、答题区，答案单独成页。"
5. "给每道题打上难度标签（基础/中等/拔高），再按难度分层生成三套分层练习卷。"

**操作步骤（8 步）**

1. 确定科目与真题来源，优先使用教育部/省教育考试院官网、出版社官网等公开渠道，注意版权合规，仅做个人学习用途。
2. 用 requests 下载真题 PDF 或网页，批量命名（科目-年份-地区.pdf）存入统一文件夹。
3. 用 pdfplumber / PyPDF2 提取 PDF 文本；扫描版先做 OCR（如 PaddleOCR）再提取，避免乱码。
4. 用关键词与正则识别章节标签（如"一、选择题""（二）函数"），把题目切分到"题目、选项、答案"字段。
5. 用 pandas 建立题库：题目、章节、年份、来源、难度、答案、解析列，去重相同题目。
6. 按目标试卷的结构比例随机抽题组卷（如选择 30%、填空 20%、解答 50%），保证不重复抽同一章节过多。
7. 用 python-docx 生成试卷 Word 与答案页，设置版式后导出 PDF，打印前抽查页码与题号连续性。
8. 人工核对抽出的题目完整性（图片题、公式题是否丢失），有缺失的题打标记补录，再正式使用。
