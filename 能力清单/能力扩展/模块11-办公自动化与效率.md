### 24. 自动生成每日工作日报，整合当日待办、完成事项、明日计划

**细分能力点（5 条）**

1. 支持从 Excel/CSV 任务清单或 Markdown 待办文件中读取当日待办，自动标记完成状态。
2. 集成 Windows 日历（Outlook/系统日历）读取当天会议，自动并入"会议/沟通"板块。
3. 自动统计当日完成事项数量、未完成事项及原因，计算当日完成率。
4. 依据项目排期表与剩余待办，自动生成明日计划（按优先级排序，可引用对应文件路径）。
5. 按统一模板导出日报（Markdown/Word/Excel 均可），自动按日期归档到指定目录并可选发送邮件。

**可执行提示词（5 条）**

1. "读取 D:\工作日志\任务清单.xlsx 里今天是 2026-08-19 的待办，标出已完成和未完成，生成今天的日报草稿。"
2. "把今天 8:00~18:00 的日历会议和 D:\工作日志\今日记录.txt 里的完成事项合并，整理成一份日报。"
3. "按模板生成日报：今日完成、今日未完成及原因、明日计划（按优先级排序），保存到 D:\工作日志\日报\，文件名 2026-08-19.md。"
4. "结合 D:\项目A\排期.xlsx 的进度和今天遗留的待办，生成明天 5 条工作计划，按紧急重要排序。"
5. "设置每天 17:30 自动生成当日日报，读取任务清单最新状态，按日期命名保存，并统计当天完成率。"

**操作步骤（6 步）**

1. 提前把当天任务进度更新到 D:\工作日志\任务清单.xlsx，或直接把今天完成了什么、遗留什么都告诉 Workbuddy。
2. 向 Workbuddy 发送指令：「读取我的任务清单，统计今天 2026-08-19 已完成和未完成的事项，生成今日工作日报。」
3. Workbuddy 会确认日报内容：是否并入日历会议、明日计划怎么排序、保存路径和格式，按需补充（如"并入今天 8:00~18:00 的会议，明日按优先级排序"）。
4. 确认后 Workbuddy 自动完成读取、完成率统计、模板排版和保存，你无需安装任何软件或写脚本。
5. 打开 D:\工作日志\日报\ 检查生成的日报，漏项或排序不对的地方直接指出来让 Workbuddy 修正。
6. 想每天自动生成就说：「每天 17:30 自动生成当日日报，保存到 D:\工作日志\日报\，完成后发我。」改时间或停用也直接对话调整。

### 41. 自动生成月度考勤表，读取打卡数据计算迟到、加班时长

**细分能力点（5 条）**

1. 支持多来源打卡数据：考勤机导出的 Excel/CSV、钉钉/企业微信导出的打卡记录，统一字段读取。
2. 按预设上下班规则（如 9:00~18:00）自动判定每日迟到、早退、缺卡、旷工。
3. 按工作日/周末/法定节假日分类计算加班时长，支持 1.5 倍/2 倍/3 倍计薪规则。
4. 生成月度考勤汇总：每人出勤天数、迟到次数与分钟数、加班总时长、异常记录清单。
5. 用条件格式高亮异常（迟到/缺卡/超长加班），输出按日明细与按月汇总两个 Sheet，并可导出工资核算用数据。

**可执行提示词（5 条）**

1. "读取 D:\考勤\2026年8月考勤.xlsx，上班 9:00、下班 18:00，计算每人每天的迟到、早退分钟数，保存为按日明细。"
2. "计算 8 月加班：工作日 18:00 后、周末全天都算加班，工作日按 1.5 倍、周末按 2 倍计，汇总到每个员工名下。"
3. "把 8 月考勤按员工汇总成月度考勤表：应出勤天数、实际出勤、迟到次数与分钟、加班总时长、异常条数，导出到 D:\考勤\统计\。"
4. "对比 D:\考勤\8月排班表.xlsx 和打卡记录，把缺卡、漏打卡的人员和日期标红列出来。"
5. "设置每月 1 日 9:00 自动读取上月考勤数据，生成考勤统计表并发到我的企业微信。"

**操作步骤（6 步）**

1. 把考勤机/钉钉/企业微信导出的打卡记录统一放到 D:\考勤\，告诉 Workbuddy 文件位置和上下班时间。
2. 向 Workbuddy 发送指令：「读取 8 月打卡记录，按 9:00 上班、18:00 下班判定迟到早退，统计加班，生成月度考勤表。」
3. Workbuddy 会确认考勤规则：迟到/早退怎么算、加班计薪倍数、是否按排班核对缺卡，按需补充（如"工作日 18:00 后算加班，周末全天算，1.5 倍/2 倍计"）。
4. 确认后 Workbuddy 自动完成判定、加班计算、异常识别和表格生成，你无需配置任何环境或写脚本。
5. 打开生成的考勤表抽查 2~3 名员工与原始记录核对，有出入就让 Workbuddy 调整规则重新计算。
6. 想按月自动统计就说：「每月 1 日 9:00 自动读取上月考勤并生成统计表，发到我的企业微信。」改规则或停用直接对话即可。

### 65. 批量生成会议纪要模板，录音转文字后自动提炼重点

**细分能力点（5 条）**

1. 支持常见音频格式批量转文字：mp3、wav、m4a、aac，可用 OpenAI Whisper 本地离线识别，也可走云转写接口。
2. 自动区分说话人/会议角色（可选），提取会议议题、关键结论、决策项。
3. 自动提炼行动项：每条带负责人、截止时间、任务描述，便于跟进闭环。
4. 按统一模板批量生成会议纪要（议题/结论/行动项/风险/待确认），输出 Markdown 或 Word。
5. 按"日期-主题"自动归档到会议纪要目录，新录音放入监听文件夹后自动触发转写与纪要生成。

**可执行提示词（5 条）**

1. "把 D:\会议录音\20260819-项目评审.mp3 转成文字，提炼会议结论、行动项（负责人+截止时间）和风险点，生成会议纪要。"
2. "批量转写 D:\会议录音\ 下所有音频，每个音频生成一份纪要，保存到 D:\会议纪要\，文件名与录音名一致。"
3. "从这段录音中提取所有待办事项，输出表格：任务、负责人、截止日期、优先级，提到名字和时间的人都要对应上。"
4. "按模板生成会议纪要：一、会议信息（时间/参会人/主题）；二、议题与结论；三、行动项；四、风险与待确认；导出为 Word 保存到 D:\会议纪要\。"
5. "建立一个监听流程：我把录音拖进 D:\会议录音\ 后自动转写并生成纪要草稿，完成后在桌面弹窗提醒我。"

**操作步骤（6 步）**

1. 把录音按"日期-主题"命名（如 20260819-项目评审.mp3）放入 D:\会议录音\。
2. 向 Workbuddy 发送指令：「把 D:\会议录音\20260819-项目评审.mp3 转成文字，提炼会议结论和行动项，生成会议纪要。」
3. Workbuddy 会确认纪要格式：是否需要参会人、行动项是否要负责人和截止时间、导出 Word 还是 Markdown，按需补充。
4. 确认后 Workbuddy 自动完成转写、重点提炼和纪要排版，你无需安装转写软件或写脚本。
5. 打开纪要检查结论和行动项是否准确，遗漏或出错的地方直接指出让 Workbuddy 修正。
6. 批量或自动处理：说「把 D:\会议录音\ 下所有录音批量生成纪要」，或「我拖入新录音就自动转写生成草稿并弹窗提醒我」。

### 100. 整合全部自动化任务，制作可视化控制面板，一键启停各类批量处理流程

**细分能力点（5 条）**

1. 把日报、考勤、会议纪要、数据抓取等自动化脚本统一注册成任务清单，集中管理。
2. 可视化面板展示每个任务的运行状态（运行中/空闲/失败）、最近运行时间、运行结果摘要。
3. 支持一键启动、停止、重跑单个任务，以及一键全部停止（紧急熔断）。
4. 支持任务参数可视化配置（如日报时间、考勤文件路径、监控间隔），免改代码即调整。
5. 记录运行日志与历史（成功/失败/耗时），面板上可查看最近 N 条日志，失败自动红标并可选推送提醒。

**可执行提示词（5 条）**

1. "帮我搭建一个本地控制面板，统一展示日报、考勤、会议纪要、价格监控四个任务的运行状态和最近一次运行时间。"
2. "在控制面板加一个'全部停止'按钮，点击后立即终止所有正在运行的任务，并显示当前已停止的任务列表。"
3. "把每个任务的参数（日报生成时间、考勤文件路径、监控间隔）整理成可视化表单，修改保存后重启对应任务即生效。"
4. "为每个任务显示最近 20 条运行日志，失败的任务用红色标出，面板顶部显示'今日成功 X / 失败 Y'统计。"
5. "面板增加手动触发按钮：点'运行日报'立即执行日报、点'运行考勤'立即生成考勤表，运行中显示转圈动画。"

**操作步骤（7 步）**

1. 先告诉 Workbuddy 你有哪些常跑的自动化任务（日报、考勤、会议纪要、价格监控等）和各自执行频率。
2. 向 Workbuddy 发送指令：「把日报、考勤、会议纪要、价格监控这些任务统一管理起来，做一个可视化控制面板，能看运行状态、随时启停。」
3. Workbuddy 会确认面板需求：仅本机使用还是多设备访问、需要展示哪些信息（状态/最近运行时间/日志）、参数怎么配置，按需回答。
4. 确认后 Workbuddy 自动搭建面板并接入全部任务，完成后告诉你访问方式和用法，你无需安装环境或写代码。
5. 日常管理都用对话完成：说"把考勤任务改成每月 1 日 9 点运行"或"停掉价格监控任务"，Workbuddy 同步更新面板配置。
6. 想手动控制就说"立即运行一次日报"或"全部停止"，面板上的状态与日志自动更新，失败任务标红并可选推送提醒。
7. 面板由 Workbuddy 统一维护，以后增删任务、调整参数、查看历史日志都直接对话，无需手动改任何脚本。
