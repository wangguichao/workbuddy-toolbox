# 办公自动化与效率（模块 11）
该模块把以下能力扩展为可直接参考的子项、提示词和操作步骤。原始条数 4，共 60~80 个扩展条目。

### 24. 自动生成每日工作日报，整合当日待办、完成事项、明日计划

**细分能力点（5 条）**

1. 支持从 Excel/CSV 任务清单或 Markdown 待办文件中读取当日待办，自动标记完成状态。
2. 集成 Windows 日历（Outlook/系统日历）读取当天会议，自动并入"会议/沟通"板块。
3. 自动统计当日完成事项数量、未完成事项及原因，计算当日完成率。
4. 依据项目排期表与剩余待办，自动生成明日计划（按优先级排序，可引用对应文件路径）。
5. 按统一模板导出日报（Markdown/Word/Excel 均可），自动按日期归档到指定目录并可选发送邮件。

**可执行提示词（5 条）**

1. "读取 D:\工作日志\任务清单.xlsx，统计今天是 2026-08-19 的待办里哪些已完成、哪些未完成，生成今天的日报草稿。"
2. "查看我 Outlook 日历今天 8:00~18:00 的所有会议，连同 D:\工作日志\今日记录.txt 里的完成事项，整理成一份日报。"
3. "按这个模板生成日报：一、今日完成（列事项+耗时）；二、今日未完成及原因；三、明日计划（按优先级排序）；保存到 D:\工作日志\日报\2026-08-19.md。"
4. "根据 D:\项目A\排期.xlsx 的进度，结合今天遗留的待办，帮我生成明天的 5 条工作计划，按紧急重要排序。"
5. "设置每天 17:30 自动生成当日日报，读取任务清单的更新状态，保存到 D:\工作日志\日报\，文件名带当天日期，同时把完成率统计出来。"

**操作步骤（6 步）**

1. 安装 Python 及 `pip install openpyxl python-docx schedule pandas`，Windows 环境直接运行。
2. 规划日报数据源：任务清单统一放一个 Excel（列：日期、任务、优先级、状态、耗时、备注），每天用待办软件或手动更新"状态"列。
3. 编写主脚本用 openpyxl/pandas 读取清单，按当天日期筛选，用条件 `状态='已完成'` 分出完成与未完成，统计完成率。
4. 用 `schedule` 设置 17:30 定时触发；如需读日历，用 `win32com.client.Dispatch("Outlook.Application")` 拉取当天会议议程并入日报。
5. 用字符串模板或 python-docx 按"今日完成 / 今日未完成 / 明日计划"三段生成日报，文件名用 `%Y-%m-%d` 格式，写入 `D:\工作日志\日报\`。
6. 用 Windows 任务计划程序设置开机自启并保持 Python 进程常驻，跑一周核对每日生成时间与内容是否准确，再决定是否加邮件自动发送。

### 41. 自动生成月度考勤表，读取打卡数据计算迟到、加班时长

**细分能力点（5 条）**

1. 支持多来源打卡数据：考勤机导出的 Excel/CSV、钉钉/企业微信导出的打卡记录，统一字段读取。
2. 按预设上下班规则（如 9:00~18:00）自动判定每日迟到、早退、缺卡、旷工。
3. 按工作日/周末/法定节假日分类计算加班时长，支持 1.5 倍/2 倍/3 倍计薪规则。
4. 生成月度考勤汇总：每人出勤天数、迟到次数与分钟数、加班总时长、异常记录清单。
5. 用条件格式高亮异常（迟到/缺卡/超长加班），输出按日明细与按月汇总两个 Sheet，并可导出工资核算用数据。

**可执行提示词（5 条）**

1. "读取 D:\考勤\2026年8月考勤.xlsx，每天上班时间是 9:00、下班是 18:00，计算每个员工每天的迟到分钟数和早退分钟数，保存为明细 Sheet。"
2. "计算 8 月加班时长：工作日 18:00 之后算加班、周末全天算加班，工作日按 1.5 倍、周末按 2 倍计，汇总到每个员工名下。"
3. "把 8 月考勤按员工汇总成一张月度考勤表：应出勤天数、实际出勤、迟到次数/分钟、加班总时长、异常条数，导出到 D:\考勤\统计\。"
4. "对比 D:\考勤\8月排班表.xlsx 和打卡记录，把缺卡、漏打卡、上班没打卡的人员和日期标红列出来。"
5. "设置每月 1 日 9:00 自动读取上月考勤数据，生成本月考勤统计表并发送到我的企业微信。"

**操作步骤（6 步）**

1. 统一数据源：从考勤机/钉钉/企业微信导出打卡记录为 Excel/CSV，确保包含"日期、员工、上班打卡时间、下班打卡时间"四列。
2. 安装 Python 及 `pip install pandas openpyxl`，编写脚本用 pandas 读取，日期与时间列用 `pd.to_datetime` 统一格式。
3. 定义判定规则：`迟到 = 上班打卡时间 > 9:00`，分钟数按差值计算；缺卡判断为打卡时间为空；周末按 Excel 的 `weekday()` 或 pandas 的 `dt.dayofweek` 判断。
4. 定义加班规则：工作日 `下班打卡 - 18:00` 为正才算加班，周末 `下班打卡 - 上班打卡` 减 1 小时休息为加班；法定节假日名单维护在一个配置 Excel 里。
5. 用 openpyxl 生成两个 Sheet：`按日明细`（每人每天一行）与 `按月汇总`（每人一行），用 `Fill` 给迟到/缺卡/异常行加黄色或红色高亮。
6. 抽查 3~5 名员工与原始考勤记录逐条核对，确认迟到、加班计算无误后再推广全月批量处理，并设为每月定时运行。

### 65. 批量生成会议纪要模板，录音转文字后自动提炼重点

**细分能力点（5 条）**

1. 支持常见音频格式批量转文字：mp3、wav、m4a、aac，可用 OpenAI Whisper 本地离线识别，也可走云转写接口。
2. 自动区分说话人/会议角色（可选），提取会议议题、关键结论、决策项。
3. 自动提炼行动项：每条带负责人、截止时间、任务描述，便于跟进闭环。
4. 按统一模板批量生成会议纪要（议题/结论/行动项/风险/待确认），输出 Markdown 或 Word。
5. 按"日期-主题"自动归档到会议纪要目录，新录音放入监听文件夹后自动触发转写与纪要生成。

**可执行提示词（5 条）**

1. "把 D:\会议录音\20260819-项目评审.mp3 转成文字，提炼会议结论、行动项（负责人+截止时间）、风险点，生成一份会议纪要。"
2. "批量转写 D:\会议录音\ 文件夹下所有音频文件，每个音频生成一份纪要，保存到 D:\会议纪要\，文件名用录音名。"
3. "从这段录音里提取所有待办事项，输出表格：任务描述、负责人、截止日期、优先级，凡提到名字和时间的人都要对应上。"
4. "按模板生成会议纪要：一、会议信息（时间/参会人/主题）；二、议题与结论；三、行动项；四、风险与待确认；导出为 Word 保存到 D:\会议纪要\。"
5. "建立一个监听流程：我把录音文件拖进 D:\会议录音\ 后，自动转写并生成纪要草稿，完成后在桌面上弹出通知告诉我。"

**操作步骤（6 步）**

1. 安装 Python，并安装 Whisper：`pip install openai-whisper`（离线转写，中文用 `base` 或 `small` 模型，准确率与速度平衡），或用云转写 API 省算力。
2. 统一录音命名：`日期-主题.mp3`，如 `20260819-项目评审.mp3`，便于纪要文件按同名归档。
3. 编写批量转写脚本：遍历目录下音频，`whisper.load_model("small")` 调用 `model.transcribe()`，输出带时间戳的文本，逐文件保存 `转录文本\xxx.txt`。
4. 调用 AI 提炼重点：把转录文本发给大模型（DeepSeek/通义/本地模型），prompt 要求输出"议题、结论、行动项（负责人+截止时间）、风险"，或写正则关键词规则先粗提取。
5. 用 python-docx 生成纪要 Word：套用公司模板样式，填入会议信息、议题结论、行动项表格（任务/负责人/截止时间/状态）。
6. 用 `watchdog` 库监听 `D:\会议录音\` 新文件自动触发转写，Windows 任务计划程序开机自启；先用 2~3 段真实录音验证转写准确率，再全量处理。

### 100. 整合全部自动化任务，制作可视化控制面板，一键启停各类批量处理流程

**细分能力点（5 条）**

1. 把日报、考勤、会议纪要、数据抓取等自动化脚本统一注册成任务清单，集中管理。
2. 可视化面板展示每个任务的运行状态（运行中/空闲/失败）、最近运行时间、运行结果摘要。
3. 支持一键启动、停止、重跑单个任务，以及一键全部停止（紧急熔断）。
4. 支持任务参数可视化配置（如日报时间、考勤文件路径、监控间隔），免改代码即调整。
5. 记录运行日志与历史（成功/失败/耗时），面板上可查看最近 N 条日志，失败自动红标并可选推送提醒。

**可执行提示词（5 条）**

1. "帮我用 Flask 写一个本地控制面板，展示日报、考勤、会议纪要、价格监控这四个任务的运行状态和最近一次运行时间。"
2. "给控制面板加一个'全部停止'按钮，点击后立刻终止所有正在运行的批量处理脚本，并显示当前哪些任务已停止。"
3. "把每个自动化脚本的参数放到 D:\自动化\config.json 里，控制面板上做一个表单，改完参数保存后点'重启任务'生效。"
4. "为每个任务显示最近 20 条日志，失败的任务用红色标出来，并在面板顶部显示'今日任务成功 X / 失败 Y'的统计。"
5. "面板增加手动触发按钮：点'运行日报'就立即执行日报脚本，点'运行考勤'就立即生成月度考勤表，运行中显示转圈动画。"

**操作步骤（7 步）**

1. 整理所有自动化脚本，统一放到 `D:\自动化\scripts\`，每个脚本都封装成"函数入口 + `if __name__=="__main__"`"，保证可被单独执行。
2. 建立任务注册表 `D:\自动化\tasks.json`：每项含任务名、脚本路径、参数、定时规则、启用开关，控制面板据此生成列表。
3. 安装 `pip install flask schedule`，用 Flask 创建本地 Web 应用（路由：首页看板、任务详情、日志页、配置页）。
4. 用 `subprocess.Popen` 以子进程方式启动/停止脚本，管理 `running_task` 字典记录每个任务的进程句柄，`terminate()` 实现一键停止，紧急熔断按钮遍历所有进程终止。
5. 配置页用表单读取 `tasks.json` 参数，保存后校验 JSON 合法性，重启对应任务进程使参数生效；定时调度用 `schedule` 与任务计划程序双保险。
6. 日志统一写入 `D:\自动化\logs\任务名.log`，面板用 `tail` 读取最近 N 行展示；`run` 结果成功写 `success`、失败捕获异常写 `error` 并标红。
7. 浏览器打开 `http://127.0.0.1:5000` 使用面板；用 Windows 任务计划程序设为开机自启并保持后台运行，局域网内可改 `host="0.0.0.0"` 供其他设备访问（需注意防火墙与内网安全）。
